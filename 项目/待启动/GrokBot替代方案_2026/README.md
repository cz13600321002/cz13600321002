## 要解决的问题

Grok Bot 周额度按智能体步数和 token 计算，长任务和常驻 Routine 很容易用完。套餐与 SuperGrok 授权还不叠加。需要的不是再找一个同样吃配额的全能 Bot，而是把原工作拆成可替代课题。

## 怎么找课题（一句话）

先盘点 Grok Bot 实际做过的事，按「检索写作 / 文档流水线 / 定时 / 登录操作 / 改仓库」分类，用「价值×频率×替代容易度÷额度吞噬」排序。指数高且不需要登录外部网站的，优先迁出。
