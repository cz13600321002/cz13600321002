# 实验 SOP（PVC 卷材贴膜水煮）

**所属项目：** PVC卷材贴膜水煮_2026  
**对应方案：** `文档/方案/20260905_PVC膜与金属板增塑剂影响克服方案.md`  
**版本：** V1.1  
**日期：** 2026-09-05  

未勾完 `开工检查单.md` 不准开始第 7 节。G1 未签字不准配高羟值共混。

---

## 1. 目的

在 **PMT 232℃、胶已交联、软膜不进炉** 的前提下，用同一锅水煮比较：

- H0 硬质（现用贴辊带温）
- H1-L0 软质（现用贴辊带温）
- H1-L1 软质（贴辊 ≤100℃）
- 仅当 L1 仍大面积 M：H1-G1

用失效面区分油到金属（M）、贴不湿（V）、胶被泡软（C）。

---

## 2. 适用范围

软质 / 硬质 PVC 贴已涂聚酯封闭胶的铝或冷轧钢。实验室烘箱模拟或线上下来的小板均可，规则相同。

---

## 3. 职责

| 角色 | 职责 |
|------|------|
| 操作人 | 按本 SOP 做，当时填记录 |
| 复核 | 核对 PMT、贴辊 ℃、养满 24 h、失效面 |
| 技术负责人 | 过门、是否开 G1、签发工艺卡 |

---

## 4. 安全

- 碱脱脂、IPA、聚酯溶剂、MEK：通风、手套、护目镜。  
- 232℃ 板：戴高温手套，禁止裸手。  
- 水煮：试样用夹具，禁止手持入锅。  
- 软膜、溶剂桶 **不准进 232℃ 烘道**。

---

## 5. 设备

| 名称 | 要求 |
|------|------|
| 烘箱或卷材烘道 | 能把 **板温** 做到 232℃（热电偶贴板，不看炉表） |
| 接触热电偶 | 测贴辊处金属板温 |
| 压机或贴辊 | 能重复 0.3～0.6 MPa（与现场同一档，记下） |
| 水煮锅 | 去离子水，稳 **100±2℃**，试样竖放不贴壁 |
| 拉力机 | 180°，**100 mm/min** |
| 裁刀 | **25 mm** 宽 |
| 线棒 / 涂布器 | 干膜与现用卷材同一目标，**不要加厚** |
| MEK + 无尘布 | 出炉轻擦 20 次 |

没有 ATR 不挡开工。用水膜 + 失效面即可。

---

## 6. 环境

- 制样与剥离：23±2℃，50±10%RH，记下实际值。  
- 养护：**23℃ / 50%RH，满 24 h**。未满不得水煮、不得报验收。

---

## 7. 操作

### 7.1 金属（与硬质同一套，本轮不改）

1. 碱脱脂至水膜连续 ≥30 s → 水洗近中性 → IPA 单向擦，晾干。  
2. 戴手套，**2 h 内**涂现用聚酯封闭胶。有锈、有指纹 → 作废。  
3. 干膜按现用卷材，写入记录。禁止为了水煮加厚。

### 7.2 烘烤（胶交联）

1. 热电偶贴 **金属板**，升到 **PMT 232℃**（按现用卷材到达时间，实验室记下分钟）。  
2. 出炉。**此时板上没有 PVC。**  
3. 立即做 MEK 轻擦 20 次（见 `MEK擦拭记录.md`）。掉了：停，校炉，不贴膜。  
4. 硬质、软质用同一炉曲线。

### 7.3 贴辊温度

1. 用接触热电偶测 **将要进贴辊的金属板温**，不抄炉子 232。  
2. **L0：** 现用带温，写出 ℃。  
3. **L1：** 凉到 **≤100℃** 再贴。压力、时间与 L0 相同。  
4. 同炉硬质 H0 跟 L0 带温贴。  
5. 禁止预热软 PVC。需要擦膜时：IPA 单向 ×2，晾 ≥5 min，**5～10 min 内冷膜贴热板**；擦完再烤软膜 = 作废。

### 7.4 贴合

1. 线压 0.3～0.6 MPa（与现场同一档），记下秒数。  
2. 贴后自然凉 ≥30 min，再放入 23℃/50%RH。  
3. 收卷或堆垛时板还很烫：在记录里写收卷板温。热卷会继续赶油。

### 7.5 干态剥离（满 24 h）

1. 裁 **25 mm**。  
2. 180°，**100 mm/min**。  
3. 写剥力与失效面：金属光 = M；膜面光滑 = V；胶自己裂 = C；膜被拉坏 = P；混 = X。

### 7.6 水煮（验收）

1. 确认该片已养满 24 h。  
2. 去离子水 **100±2℃ × 60 min**。竖放，互不叠、不贴壁。硬质与软质同锅。默认 **不封边**。  
3. 取出，自来水淋凉，吸干。  
4. 目视自发揭面积 ____%。**≥10% → 该片失败**，仍拍照、写失效面。  
5. **30 min～1 h 内** 做 180° 剥离。超时：该水煮行作废，另煮一片，禁止隔夜再剥当水煮数据。  
6. 金属面：光亮 / 残胶 / 锈印 / 水斑。

### 7.7 G1（仅过门判定写「开 G1」之后）

1. 按 `G1配比计算表.md` 称料。低羟值（240+822）固体留 70%，拿出的 30% 换成 **710**。  
2. NCO 与 G0 **同一牌号**（3175 或 HY-1070/TS3102，不混）。按共混 **总羟值** 重算。3175 用 EW 380；HY-1070 用 EW **408**（TDS：固含 70%，NCO 理论 10.3%）。  
3. 溶剂、催化剂、固含调节 **与 G0 同一做法**，只改聚酯比和 NCO 量。  
4. PMT 仍 232℃。贴辊跟已做过的 L1。  
5. 必须带硬质对照（G1 胶）。硬质掉 → 停。  
6. 出炉 MEK 20 次应更抗擦。软质干态变 V：退回 30% 或贴辊略高于 L1，**不要加厚、不要先改 50/50**。

### 7.8 耐热辅检（不替代 7.6）

水煮过门仍按 7.6。怕隔天再掉时，**另裁平行片**做 **70℃ × 24 h** 干剥（先养满 24 h 再进烘箱）。客户要出厂外观时按 GB/T 18847 耐热水，不要用 80℃/2 h 外观顶替本项目水煮。四种「热」怎么选：`耐热测试方法.md`。

---

## 8. 停止条件

| 看到 | 动作 |
|------|------|
| H0 水煮也大面积 M | 整炉作废。先查是否未养 24 h、PMT 是否没到 232 |
| MEK 20 次掉 | 不贴膜，校炉 |
| 软膜进过烘道 | 该炉作废 |
| L1 干态大面积 V | 贴辊回到 L0 与 100℃ 之间，重做 L1；先不要 G1 |
| 只换了聚酯、NCO 没加 | 胶作废，不准上板 |
