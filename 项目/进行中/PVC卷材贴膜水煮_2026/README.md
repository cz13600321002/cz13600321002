# PVC 卷材贴膜水煮

**本目录是这条线的唯一入口。本对话只做软质 PVC 卷材贴膜水煮。**

---

## 已锁定

| 项 | 规定 |
|----|------|
| 膜 | 软质水煮后胶连膜从金属揭；硬质同胶同金属没有问题。**膜改不了。膜上处理剂不可行。** |
| 胶 | 聚酯：SK **ES-240**、东洋纺 **822**、SK **ES-710**（高羟值只认 710）。NCO：科思创 **BL 3175 SN**，本厂另配套 **TS3102** 作替代。一炉只用一支 NCO，不对换克数。 |
| 烘 | 卷材，**板温 232℃**，贴膜前已交联。软膜不进炉。 |
| 主路线 | 先 L1 贴辊板温 **≤100℃**；不够再 G1 |
| G1 | 高羟值聚酯先替 **30%** 低羟值；封闭 NCO **按共混总羟值重算** 到 NCO/OH **1.10～1.20**。不先全代。只换聚酯不加 NCO 禁止。 |
| 验收 | 养满 24 h → **100±2℃ × 60 min** → 30 min～1 h 内 180° 剥；**25 mm × 100 mm/min** |
| 过门 | 不自发揭（≥10% 失败）；软质剥力 ≥ 同炉硬质 H0 的 90%；金属不得大面积光板 |

---

## 先做哪一步

1. 填 [基材鉴定表](基材鉴定表.md)、[开工检查单](开工检查单.md)。羟值 / 封闭 NCO 当量未知就写「未知」，**不准先配 G1**。
2. 测现在的贴辊板温，填 [L0 贴辊测温](L0贴辊测温.md)。没写出 L0 的 ℃，L1 不算数。
3. 按 [实验 SOP](实验SOP.md) 做 **H0 + H1-L0 + H1-L1**。当时填 [试验记录表](试验记录表.md)。
4. 用 [过门判定](过门判定.md) 看 L1。过了就填 [工艺卡](工艺卡.md)，**不要开 G1**。
5. L1 仍是大面积 M，才按 [G1 配比计算表](G1配比计算表.md) 配胶，再做 H1-G1（硬质对照必须同炉）。

## 本目录关掉

改膜、膜上处理剂、软膜进 232℃ 炉、150℃ 补交联、换腈胶、加厚面胶挡油、硬质已过还改金属、未养 24 h 就煮、只换聚酯不加 NCO、一上来 100% 高羟值。

其他产线的配方不要套进来。
