# PVC 卷材贴膜水煮（与 PE 案例分开）

**本目录是 PVC 的唯一入口。不要在这个对话或这个项目里继续改 PE / TPU / TPE。**

PE 走：`项目/进行中/PE基材附着力测试_2026/`

---

## 已锁定（开新对话时先读这几行）

| 项 | 规定 |
|----|------|
| 膜 | 软质 PVC 水煮从金属揭；硬质没有问题。**膜改不了。膜上处理剂不可行。** |
| 胶 | 聚酯 + 封闭型异氰酸酯 |
| 烘 | 卷材，**板温 232℃**，贴膜前已交联。软膜不进炉。 |
| 主路线 | L1 贴辊 ≤100℃ → 不够再 G1 |
| G1 | 高羟值聚酯先替 **30%** 低羟值；封闭 NCO **按总羟值重算** 到 NCO/OH 1.10～1.20。不先全代。只换聚酯不加 NCO 禁止。 |
