# PVC 覆膜钢板的耐热测试方法

**所属项目：** PVC卷材贴膜水煮_2026  
**版本：** V1.0  
**日期：** 2026-09-05  

「耐热」在卷材覆膜里至少有四种意思。混用会把 **工艺烘烤**、**产品出厂**、**本项目水煮验收** 和 **增塑剂第二波** 搅在一起。本页只写 PVC 覆膜钢板 / 钢带，不写其他产线。

---

## 0. 先分清四种「热」

| 名称 | 实际在测什么 | 温度 / 时间 | 本项目算不算验收 |
|------|----------------|-------------|------------------|
| 工艺热（PMT） | 封闭异氰酸酯解开、聚酯交联 | 板温 **232℃**，板上 **还没有软 PVC** | 工艺锁死。**不是**产品耐热 |
| 贴辊热 | 出炉板还带多少温去贴膜 | L0 = 现用；L1 **≤100℃** | 工艺。不抄炉子 232 |
| 热水 / 沸水 | 热 + 水一起拆界面 | 见第 1、2 节 | **水煮 100±2℃ × 60 min + 剥离 = 验收** |
| 干热老化 | 只有热、没有水；赶增塑剂 | 本项目 **70℃ × 24 h** | **辅检**，防隔天假合格。不过门不算失败，但要记 |

软质 PVC 的使用上限通常在 **70～80℃** 一带（增塑后更低）。**贴好膜的板不准再进 232℃ 炉，也不准拿 150℃「补交联」。**

---

## 1. 本项目必须做

### 1.1 水煮 + 180° 剥离（验收，已锁定）

| 项 | 规定 |
|----|------|
| 养护 | **23℃ / 50%RH，满 24 h**。未满作废 |
| 介质 | 去离子水（或蒸馏水），**100±2℃** |
| 时间 | **60 min** |
| 放置 | 竖放，互不叠、不贴壁；默认 **不封边** |
| 出锅 | 自来水淋凉，吸干 |
| 外观 | 自发揭面积 **≥10% = 该片失败** |
| 剥离 | 出锅后 **30 min～1 h 内**；**25 mm × 100 mm/min**（GB/T 2790） |
| 对照 | 同炉硬质 H0；软质剥力 ≥ H0 的 **90%**；金属不得大面积光板 |
| 失效面 | 必须写 M / V / C / P / X |

操作细节以 `实验SOP.md` 第 7.6 节为准。本方法不改这条。

**和国标出厂耐热水的差别（不要互相顶替）：**

| | 本项目水煮 | GB/T 18847-2026 耐热水性 |
|--|------------|--------------------------|
| 水温 / 时间 | **100±2℃ × 60 min** | 室内 **80±2℃ × 2 h**；室外 **98±2℃ × 2 h** |
| 判定 | 自发揭 + **定量剥离** + 失效面 | **只看外观**（收缩、裂纹、鼓泡、剥落、变色） |
| 边部 | 不封边，切口也算 | 距边 **≤10 mm** 开胶可忽略 |
| 用途 | 本现场软质金属侧揭 | 建筑装饰覆膜板 **出厂检验** |

18847 的 80℃/2 h **过了，不能宣称本项目过了**。本项目过了，出厂仍应按客户指定的 18847 档再做外观。

### 1.2 70℃ × 24 h 干热（辅检，已锁定）

方案里的「增塑剂第二波」：下机当时像粘住，隔天或加热后再掉。水煮过了仍要做这一档，防止只报 24 h。

| 项 | 规定 |
|----|------|
| 试样 | 与水煮 **同一炉、同一贴辊档** 的平行片。**不要用水煮过的片再烤** |
| 养护 | 贴后先在 23℃/50%RH 养满 **24 h**，再进烘箱 |
| 设备 | 鼓风烘箱。热电偶放在试样附近，**看箱内空气温，不看炉表** |
| 条件 | **70±2℃ × 24 h**，试样平放或挂放，膜面向上，互不叠压 |
| 出箱 | 取出，在 23℃/50%RH 放 **1～2 h** 再剥。禁止烫手就剥 |
| 测定 | 目视起皱 / 收缩 / 鼓泡 / 变色；再 **25 mm × 100 mm/min** 180° 剥 |
| 怎么比 | 与同炉 **未烤** 的 24 h 干剥比；再与同炉硬质比 |
| 过门 | **不替代水煮**。软质若相对未烤干剥掉很多、或变成大面积 M，写入记录，过门仍看水煮 |

**70℃ 不是交联温度。** 胶已经在 232℃ 交过。这一档只赶软膜里的油。

另做一档 **23℃ / 50%RH × 72 h** 干剥（不加热），与 70℃ 对照：72 h 掉而 70℃ 不掉 → 更像时效；两边都掉且是 M → 油在走。

## 2. 产品标准方法（客户 / 出厂）

以下按标准原文操作。本项目 **不把它们的外观合格写成牛顿指标**。

### 2.1 GB/T 18847-2026 耐热水性（第 7.17 节）

**2026-12-01 实施**，代替 GB/T 18847-2002。建筑装饰用覆膜金属板的 **出厂检验项目** 含外观、尺寸、膜厚、密合性、**耐热水性**。

1. 试样先在 **23±2℃、（50±10）%RH** 放置至少 **24 h**。距产品边部 **>50 mm** 取样，表面平整、无损伤、无毛刺。  
2. 浸没在 **蒸馏水** 中恒温 **2 h**。试样互不移动、互不接触。  
   - 室内用（代号 N）：**80±2℃**  
   - 室外用（代号 W）：**98±2℃**  
3. **仍泡在该水里** 自然凉到室温，再取出擦干。不要捞出来吹冷风急冷。  
4. 目视：收缩、裂痕、裂纹、鼓泡、剥落、变色。距边 **≤10 mm** 的开胶忽略。  
5. 复检：该项不合格可抽双倍；仍不合格则该批判不合格。

家电内板若合同写「按 18847」，先问清按 **室内 80℃** 还是 **室外 98℃**。没写用途时，**不要擅自用 80℃ 代替 98℃**。

### 2.2 GB/T 18847-2026 耐湿热性（第 7.21 节）

型式检验（正常生产约每三年一次，与盐雾、氙灯老化同档）。

| 项 | 规定 |
|----|------|
| 方法 | GB/T 1740 |
| 温度 | **47±1℃** |
| 湿度 | **（96±2）%RH** |
| 试样 | 背面及四周 **封闭** |
| 判定 | 全部试样不次于 **1 级** |

这是潮湿热空气，**不是沸水**。过了湿热箱 ≠ 过了本项目水煮。

### 2.3 JIS K 6744 耐沸腾水性（第 9.4 节）

GB/T 18847-2002 非等效采用 JIS K 6744。日本 PVC 被覆金属板的型式试验：

| 项 | 规定 |
|----|------|
| 试样 | 约 **50 mm × 100 mm** 以上，**2 片** |
| 水 | **离子交换水**；杯底放 2～3 粒瓷碎片 |
| 沸腾 | 小泡约 **每秒 2～3 个**（缓沸，不要猛滚把试样撞碎） |
| 浸没 | 互不接触；下端离杯底 **≥20 mm** |
| 时间 | **60 min** |
| 冷却 | 提出后浸 **常温水 5 min**，轻洗，干燥 |
| 观察 | 去掉端部 **10 mm**；不得有裂纹、皱、明显变退色、被覆收缩或剥离 |

时间与本项目水煮相同，**判定只有外观**。本项目在同样 60 min 之后还要剥，所以 **更严**。对日客户可先按 9.4 做外观，再按本项目剥同一锅的平行片（不要把外观片撕了当唯一数据）。

### 2.4 GB/T 18847-2002 耐沸水性（仍有效至 2026-11-30）

旧版 PVC 覆膜金属板常用：**约 20 mm × 100 mm**，软化水缓沸 **60 min**，取出自来水冷却、干燥，**目视面膜**。2026-12-01 起新合同应改走 2.1。旧合同未改口前，仍可按 2002 做，记录里写清「2002 耐沸水」还是「2026 耐热水」。

## 3. 可选对照（不替代第 1 节）

| 方法 | 条件 | 何时做 | 不要当成 |
|------|------|--------|----------|
| 40℃ 去离子水 24 h 后再剥 / 划格 | 湿预筛 | 金属或胶批次怀疑时 | 水煮验收 |
| GB/T 13448-2019 第 22 章 耐干热 | 彩涂用烘箱干热；标准推荐两档常用温度，**以标准正文为准** | 客户点名「按彩涂干热」 | 卷材 PMT；软 PVC 贴合板的使用上限 |
| 氙灯老化（18847 第 7.20 节） | 黑标 **65±3℃**，湿度 **（65±5）%** | 室外耐候型式检验 | 本项目增塑剂水煮 |

彩涂耐干热常用 90℃ 或更高。**软质 PVC 覆膜板不要先拿 120℃ 长时间烤**——膜会缩、增塑剂会狂跑，分不清是胶坏了还是膜先毁了。若必须做，先用 **70℃**（第 1.2 节），客户坚持更高温度再单开，并带硬质对照。

## 4. 实验室怎么排

```
同炉：H0 硬质 + 软质（L0 或 L1）
        │
        ├─ 片 A：养 24 h → 干剥
        ├─ 片 B：养 24 h → 水煮 100±2℃ × 60 min → 30 min～1 h 内剥   ← 验收
        ├─ 片 C：养 24 h → 70℃ × 24 h → 凉 1～2 h → 干剥           ← 辅检
        └─ 片 D（可选）：养 72 h → 干剥
客户要出厂报告时，另裁片做 18847 耐热水（80℃ 或 98℃ × 2 h，只看外观）。
```

水煮、70℃、18847 **各用各的片**。一片不可先煮再烤、也不可先烤再煮还报「水煮」。

- 实测温度、时间、水质
- 养满 24 h：是 / 否
- 外观 +（若做了）剥力与失效面
- 用的是不是平行片（不是煮过再烤）

## 6. 禁止

| 禁止 | 原因 |
|------|------|
| 软膜或贴好膜的板进 **232℃** 炉 | 膜毁，数据作废 |
| 150℃「补交联」 | 胶已在贴前交联；再烤只赶油、毁膜 |
| 把 **80℃ × 20 min** 当卷材烘胶 | 其他产线的烘胶，不是本炉 |
| 用 18847 **80℃/2 h 外观** 代替本项目水煮剥 | 现场失败模式是软质 **M**，外观可能还看不太出 |
| 用 70℃ 干热代替水煮过门 | 干热没有水，拆不开本现场那种界面 |
| 未养 24 h 就煮、就烤 | 硬质也可能被带掉 |
| 出锅超过 1 h 再剥仍报水煮 | 该行作废 |
| 未鉴定膜 phr、金属厚度就写牛顿合格线 | 只报相对 H0 的 % 和失效面 |

## 7. 一句话选用

- **本现场软质从金属揭** → 只认第 1.1 节水煮剥。  
- **怕隔天再掉** → 加第 1.2 节 70℃ 和第 1.2 节 72 h。  
- **出厂 / 建筑合同** → 第 2.1 节（2026-12-01 后）或第 2.4 节（旧合同）。  
- **对日规格** → 第 2.3 节外观 + 本项目平行片剥离。  
- **室外耐久** → 第 2.2 节湿热 + 氙灯；仍不替代水煮。
