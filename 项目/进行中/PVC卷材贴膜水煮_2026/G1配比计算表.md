## 3. G1 怎么改聚酯

低羟值拿出 **30%** 换成 710。240 与 822 **按 G0 固体比同比例减**，避免只砍一支把 Tg 拉偏。

```
Δ = 0.30 × m_低0
m_2401 = m_2400 × 0.70
m_8221 = m_8220 × 0.70
m_7101 = m_7100 + Δ
```

| 聚酯 | G1 固体 g | G1 供应 g = 固体 / (固含/100) |
|------|-----------|------------------------------|
| 240 | | |
| 822 | | |
| 710 | | |
| 合计 | 仍 = m_聚酯固体 | |

核对：m_7101 − m_7100 必须等于 0.30 × m_低0。

## 4. 总羟值 → 本炉这一支 NCO

```
n_OH (mol) = (m_240×3 + m_822×3 + m_710×25) / 56100
n_NCO = n_OH × r
W_NCO供应 (g) = n_NCO × EW_NCO
```

r 取 1.10～1.20。G0 书面 NCO/OH 已在此区间则用 **同一个 r**；否则 G1 用 **1.15**。
