## 2. 公式（固体质量，克）

羟值摩尔：

```
n_OH (mol) = Σ [ m_固体聚酯 (g) × OH (mg KOH/g) ] / 56100
```

G1 固体比（先 30%，不要改成 50 或 100）：

```
m_低 + m_高 = m_聚酯固体
m_高 = 0.30 × m_聚酯固体
m_低 = 0.70 × m_聚酯固体
```

供应质量：

```
W_供应 = m_固体 / (固含% / 100)
```

NCO 摩尔与投料：

```
n_NCO = n_OH × r          r 取 1.10～1.20，默认 1.15
m_NCO固体 = n_NCO × EW_NCO
```

G0 若已有书面 NCO/OH，且落在 1.10～1.20，G1 用 **同一个 r**。G0 的 r 不在此区间：先把 G0 的实际 r 写在备注，G1 仍落在 1.10～1.20。
