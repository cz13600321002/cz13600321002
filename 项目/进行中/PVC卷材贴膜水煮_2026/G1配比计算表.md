## 3. G1 怎么改聚酯

低羟值拿出 **30%** 换成 710。240 与 822 **按 G0 固体比同比例减**，避免只砍一支把 Tg 拉偏。

```
Δ = 0.30 × m_低0
m_2401 = m_2400 × 0.70
m_8221 = m_8220 × 0.70
m_7101 = m_7100 + Δ
```

| 聚酯 | G1 固体 g | G1 供应 g = 固体 / (固含/100) |
|------|-----------|------------------------------|
| 240 | | |
| 822 | | |
| 710 | | |
| 合计 | 仍 = m_聚酯固体 | |

核对：m_7101 − m_7100 必须等于 0.30 × m_低0。

## 4. 总羟值 → 本炉这一支 NCO

```
n_OH (mol) = (m_240×3 + m_822×3 + m_710×25) / 56100
n_NCO = n_OH × r
W_NCO供应 (g) = n_NCO × EW_NCO
```

r 取 1.10～1.20。G0 书面 NCO/OH 已在此区间则用 **同一个 r**；否则 G1 用 **1.15**。

## 5. 演算例（假定 G0 固体 50/25/25，**不是本厂配方**）

假定：聚酯固体 100 g；G0 = 710 50 g + 240 25 g + 822 25 g；r = 1.15；OH 3 / 3 / 25；EW 380。

| | G0 | G1（低羟值各留 70%） | 禁止：G1 聚酯 + G0 的 NCO 克数 |
|--|----|----------------------|------------------------------|
| 710 / 240 / 822 固体 | 50 / 25 / 25 | **65 / 17.5 / 17.5** | 65 / 17.5 / 17.5 |
| n_OH | (50×25+25×3+25×3)/56100 = **0.02496** | (65×25+17.5×3+17.5×3)/56100 = **0.03084** | 0.03084 |
| W_NCO 供应（3175，EW=380） | 0.02496×1.15×380 = **10.91 g** | **13.48 g** | 10.91 g |
| NCO/OH | 1.15 | 1.15 | **0.93 ← 欠交联，禁止** |

TS3102：把上表 380 换成它的 EW，克数会变。没有 EW 不要称。  
若有人把 G0 当成「只有 240+822、没有 710」：100 g 低羟值、G1 = 70 低 + 30 的 710，n_OH 从 0.00535 升到 0.01711，3175 从 2.34 g 升到 7.48 g。没有 G0 三格实测比，不要用这一行称料。

## 6. 混合
