# 实验标准作业程序（SOP）

**文件名称：** 未电晕 PE 基材涂布附着力测试 SOP  
**所属项目：** PE基材附着力测试_2026  
**对应方案：** `文档/方案/20260904_PE免电晕高粘合牢度方案.md`（主路线）；测试细则见 `文档/方案/20260902_PE基材未电晕附着力测试方案.md`  
**版本：** V1.1  
**日期：** 2026-09-04  

---

## 1. 目的

在 **禁止电晕** 的 PE 基材上，按规定涂布并 **80℃ × 20 min** 烘烤后，用可复现的方法测定涂层附着力，并区分界面失败与成膜失败。

## 2. 适用范围

- 未电晕 LDPE / LLDPE / HDPE 薄膜或片材
- 溶剂型或水性底涂 + 面涂，或单涂
- 实验室线棒涂布

## 3. 职责

| 角色 | 职责 |
|------|------|
| 操作人 | 按本 SOP 执行并填写记录表 |
| 复核人 | 核对基材判定、烘箱曲线、胶带牌号、计算结果 |
| 技术负责人 | 签发合格/不合格结论 |

## 4. 安全

- IPA、芳烃类 CPO 溶剂：通风橱，戴手套与护目镜。
- 烘箱：禁止烘易燃溶剂未表干的厚湿膜；溶剂型须表干后再入炉。
- 达因笔液体按危化品存放，测试废液单独收集。

## 5. 仪器与材料

| 名称 | 规格要求 |
|------|----------|
| 强制对流烘箱 | 可稳定 80±2℃ |
| 热电偶 + 记录 | 可贴膜面 |
| 玻璃板 | 洁净，大于试样 |
| 线棒 | 6#、9#、12#（或项目指定） |
| 达因笔 | 30、32、34、36、38、40、42 dyn/cm |
| 接触角仪 | 可选；无则达因+台账双控 |
| 划格器 | 1 mm 间距，符合 GB/T 9286 |
| 胶带 | **3M 610**（或方案锁定牌号），25 mm 宽 |
| 压辊 | 硬度与质量固定，用于贴胶带 |
| 异丙醇 | 分析纯，无尘布 |
| 毫米格纸 | 20 mm 宽或透明方格片 |
| 千分尺 / 测厚仪 | 基材与干膜 |
| 相机 | 测试前后拍照 |

## 6. 环境

- 涂布与测试：23±2℃，50±10%RH，记录实际值。
- 正式养护：23±2℃，50±5%RH，24 h（及 72 h）。
- 温湿度超差须在记录表注明，不擅自改判定。

## 7. 操作步骤

### 7.1 基材接收与未电晕确认

1. 记录牌号、批次、厚度、是否声称电晕、是否含爽滑剂。
2. 在样卷 **边缘** 裁 50 mm × 50 mm 做达因：从 30 dyn 起测，2 s 内成连续液膜为通过该档；收缩成珠则未达到。
3. **未电晕接收标准：最高通过档 ≤34 dyn/cm。**
4. 有接触角仪时，水滴静滴 n=5，平均值 ≥90°。
5. 达因/接触角测试面 **不得进入涂布区**。
6. 判定失败：停做，换卷或报告技术负责人。

### 7.2 裁样与清洁

1. 涂布样 150 mm × 200 mm，每条件至少 3 片。
2. 无尘布蘸 IPA，单向擦 2 遍，晾干 ≥5 min。
3. 1 h 内涂布。

### 7.3 底涂（主方案：PE 型 CPO + EAA）

1. 确认 CPO 为 **PE / polyethylene** 型，不是 PP 保险杠料。
2. 按 `20260904_PE免电晕高粘合牢度方案.md` 配到 **8% 固含**（CPO:EAA = 70:30），200 目过滤；析胶禁止使用。
3. 线棒一次刮涂，**干膜目标 0.5～1.5 μm**；可见厚边、发白、流挂作废。
4. 室温表干 **8～10 min**，必须干透再面涂（水性可延长至表面不黏）。

无底涂的 N0 / P0 跳过本步。

### 7.4 面涂或单涂

1. 同样一次刮涂，记录棒号。
2. 溶剂型：通风处表干至无明显湿光后入炉。
3. 水性：允许带微湿入炉，但禁止流淌积液。

### 7.5 烘烤（强制）

1. 烘箱空载稳定在 80±2℃。
2. 试样四角胶带固定在玻璃板上，涂层面朝上。
3. 陪试样贴热电偶于膜面。
4. 放入中心区，**关门开始计时 20 min，中途不开门。**
5. 记录入炉 5 min 膜温；应 ≥75℃。
6. 到时连板取出，室温冷却 ≥30 min。

膜温不合格：该炉全部作废。

### 7.6 养护

- 30 min 冷却后可做 **快速筛**（记录但不验收）。
- 移入标准环境 **24 h** 后做正式测试。
- 关键样再养至 **72 h** 复测。

### 7.7 胶带法（薄膜主方法）

依据 GB/T 13217.7-2023 手工剥离法，本实验室细化如下：

1. 在涂层完好区贴 3M 610，长度 ≥50 mm，无气泡。
2. 压辊往返 3 次，静置 5 min。
3. 手持胶带自由端，约 180° 快速匀速揭除。
4. 揭后用毫米格纸统计被揭涂层面积，计算附着牢度。
5. 每片测 2 个点，取平均；3 片再平均。
6. 拍照：揭前网格位置、揭后、胶带黏面。
7. 填写失效模式：A / C / T / M / I。

### 7.8 划格法（片材主方法，薄膜可辅做）

依据 GB/T 9286-2021：

1. 干膜厚度选择刀距（默认 ≤60 μm 用 1 mm）。
2. 切 6 道，垂直再切 6 道，切透至基材。
3. 软刷轻扫碎屑，贴胶带，压实，5 min 后揭除。
4. 按 0～5 级评级，拍照。
5. 薄膜若基材被刀带起，该点作废，改以胶带法为准。

### 7.9 结束

1. 废液、废膜按实验室规定收集。
2. 记录表当日完成计算与签字。
3. 原始照片文件名：`日期_配方_条件_样号_揭前/揭后.jpg`。

## 8. 合格判定（24 h）

| 方法 | 合格 | 目标 |
|------|------|------|
| 胶带牢度 | ≥90% | ≥95% |
| 划格 | ≤1 级 | 0 级 |
| 72 h | 较 24 h 下降 ≤5 个百分点 | 不下降 |

未电晕确认失败或膜温失败时，**不给涂层合格结论**。

## 9. 偏差处理

| 情况 | 处理 |
|------|------|
| 涂布有缩孔、漏底 | 作废重涂 |
| 烘箱开门、停电 | 整炉作废 |
| 胶带气泡、折叠 | 该点作废，同片另选区补测 1 次 |
| 换操作人 | 先做 6 片方法比对 |
| 换胶带批号 | 与旧批桥接 6 片，差异＞5% 须报告 |
