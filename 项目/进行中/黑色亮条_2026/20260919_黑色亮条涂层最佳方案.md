# 黑色亮条（双涂）B-588 综合最佳方案

**状态：研发筛选起点 / 待验证。不是量产定型配方。**  
**编制日期：** 2026-09-19  
**版本：** V1.0  
**综合来源：** Codex 方案对话、客户 25.5.29 性能要求、实验室扫描记录、日记录中 TS-3127×08-11-05 短时结果。  
**不采用：** Gemini 导出里的「量产 100% 配方」（材料身份写错，且把未证实的 MEK 2000 次写成已达成）。

---

## 一、先用这一套（最佳推荐）

主方向固定为：

**高分子聚酯为主的韧性底漆 + 现用高光聚酯面漆（08-11-05 或同体系 2H 面漆）。环氧只做减量对照。F2148 / VP RS 92 不进第一轮。9-12 / 9-18 环氧主体系不进第一轮。**

第一轮只做 4 组，全部锁死同一工艺：

| 编号 | 底漆 | 面漆 | 为什么做 |
|------|------|------|----------|
| BL-0 | 能复现的历史最好底（优先核实后的 08-18-04；复现不了则用 TS-3127 底漆 08-28-02 核对稿） | 同批 08-11-05 | 对照，判断后面改方有没有超过历史 |
| BL-1 | **中心样 08-18-04** | 同批 08-11-05 | 首选验证 |
| BL-2 | 08-18-05（固化剂比例对照） | 同批 08-11-05 | 只改底漆交联，不改面漆 |
| BL-3 | 在 BL-1 基料上降低 S1268，用柔韧聚酯按**树脂固体**补足，并按羟值 / 固化剂有效含量重算 | 同批 08-11-05 | 验证「少环氧」是否真有用 |

放行顺序：先选出 **干态 0T 不裂、100℃ 水煮 2 h 不分层、百格 0T + 酒精 30 min + 3M 粘 3 次不掉** 的组合，再上客户 80℃ 长时浸泡、颜色 / 光泽、TPV·PVC 胶粘。

---

## 二、指标（客户终验 vs 第一轮快筛）

客户终验以《黑色亮条性能要求》（25.5.29）为准。硬度官方是 **HB 无划痕**；你关心的 2H 记为加严项，不替代客户门禁。

| 项目 | 客户终验 | 第一轮快筛（本方案） |
|------|----------|----------------------|
| 基材 | 镜面不锈钢 | 同批镜面不锈钢 |
| 前处理 | 安驰钝化液 2:1（实验记录统一写法） | 锁死 2:1，湿膜均匀，钝化后按现场既有烘干；不与涂料变量同时改 |
| 总干膜 | 28–30 μm | **28–30 μm**（底 7±1 μm + 面 21±2 μm，实测为准） |
| 硬度 | HB 无划痕 | 记录 HB；若面漆按 2H 设计，另记 2H 是否达到 |
| 干态 T 弯 | 后续酒精线要求 0T | 先 1T，再 **0T**；10× 下无可见裂纹单独记录 |
| 水煮 | 100℃ × 2 h：无起泡、发白、掉漆 | 同左，T 弯后做 |
| 80℃ 泡水 | 240 h：T 弯后分泡 5% 盐水和去离子水，3M 898 拉不掉；另 160 h 划十字（48 h + 120 h） | **第二轮**才做。快筛不过的配方不上 240 h |
| 酒精 | 百格 1 mm 处折 0T，泡 30 min，3M 粘 **3 次**不掉 | 同左。浓度客户未写死：内部统一 **75%（体积）乙醇、23±2℃、30±1 min**，记录在表上 |
| 胶带 | 3M 898（泡水）；酒精线用同批 3M | 水煮 / 泡水用 898；酒精线同批 3M，连拉 3 次 |
| 颜色 | a:0，b:0，L:23–25（靠近 23） | 第一轮记录，不作为杀配方的第一刀（附着先过） |
| 光泽 | 20° ＞90（厂内 60° 仪需换算对照） | 第一轮记 60°；过附着后再对 20° |
| 耐候 | ≥2000 h（ΔE≤3.0，灰卡 4–5，光泽保持 85%，后再测 T 弯 / 百格） | 第三轮 |
| 胶粘 | TPV、PVC 胶涂上粘合 | 第二轮：附着过线后再做湿热后剥离，并记破坏面 |
| 客户样油参考 | 底漆粘度 147 s、固含 37.6%；面漆粘度 176 s、固含 61.1% | 自配漆记录粘度 / 固含，不强制追到客户样油数字 |

**禁止：** 用总干膜约 23 μm（底 5 + 面 18）或只做沸水 2 h，就宣布满足客户要求。那只是旧对话里的内部线，本方案已改掉。

## 三、配方（湿配方基准）

称料前先核：固含、羟值、封闭剂有效 NCO / 氨基当量、批次。缺一项就先补 TDS，不按「再加点固化剂」估。

### 3.1 中心样 BL-1（首选）

湿配方，外加在已分散好的 **08-18-03 基料** 上：

| 物料 | 份（g） | 身份（按台账 / Codex 核对） |
|------|---------|------------------------------|
| 08-18-03 基料 | 100.00 | 聚酯为主的混合基料，**含 S1268 环氧 128**，不是纯聚酯 |
| TS-3102 | 2.40 | 封闭 IPDI |
| S1239 | 2.40 | SY9170 水性封闭异氰酸酯，台账约 71% |

施工：用本体系溶剂（记录中常见 R303 = 环己酮，只是溶剂）调到可刮 / 可辊粘度，记下 25℃ 涂-4 杯秒数和固含。

### 3.2 对照 BL-2

| 物料 | 份（g） |
|------|---------|
| 08-18-03 基料 | 100.00 |
| TS-3102 | 3.20 |
| S1239 | 1.60 |

### 3.3 降环氧 BL-3（算法，不是估重量）

1. 称一份与 BL-1 相同的 08-18-03，记录其中 S1268 的湿重和固体重（由基料配方回算）。  
2. 目标：S1268 固体降到 BL-1 的 **50%**（若基料里环氧已经很少，改为降到 0 做第三档，不要两档一起改）。  
3. 减少的环氧固体，用指定柔韧高分子聚酯按**固体 1:1** 补回。聚酯牌号用现用底漆主树脂，不要临时换品牌。  
4. 按新羟值总和重算 TS-3102 + S1239；保持 BL-1 的固化剂摩尔比，不要只改克数。  
5. 溶剂补到与 BL-1 相近施工粘度。

### 3.4 历史复现底漆（仅当 08-18-03 称不出时，作 BL-0）

以下从 08-28-02 扫描件拼出，**必须对照原表手写数字后再称**。合计约 206 g。

| 物料 | 扫描件读数（g） | 身份提醒 |
|------|-----------------|----------|
| TS-3127（30%） | 133.35 | 底漆主树脂分散体，固含以桶标 / TDS 为准 |
| R310 | 55 | 按台账身份用，勿照 Gemini 写成「封闭固化剂」除非台账就是 |
| S1268 | 6 | 环氧树脂 128，不是氨基树脂 |
| TS-3102 | 9.4 | 封闭 IPDI，不是稀释剂 |
| S1100（25%） | 0.5 | 按台账（常见为硅烷类促进剂）；配后 48 h 内用完 |
| XP404 | 0.3 | 助剂，按现场习惯后加 |
| XP467 | 1.0 | 助剂 |
| XP413 | 0.5 | 助剂 |

日记录（2026-08-22）曾写：TS-3127 底漆单独耐溶剂约 30 次；**配 08-11-05 后面漆后，耐酒精 0–1T OK、水煮 8 h 后 0–1T OK**。溶剂 / 酒精浓度、破坏面未补全，只能当「值得复现」，不能当已过客户 240 h / 100℃×2 h。

### 3.5 面漆（第一轮不改方）

固定 **同批 08-11-05**（或你指定的 2H 聚酯面漆同一锅）。炭黑、流平、交联比第一轮不动。  
若 BL-0～BL-3 干态 0T 已裂：停止改底漆，另开面漆交联减量，不与底漆变量混做。

### 3.6 明确不做

- 9-18 / S1070 / S1102 环氧主底漆第一轮不做。  
- F2148、F297、AEROSIL、VP RS 92 第一轮不加。  
- Gemini 文档里的底漆 42% TS-3127 + 面漆 68% S1070「量产方」不采用：S1268 / TS-3102 身份写错，且无原始过关表。

## 四、工艺（炉温与 PMT 分开记）

| 步骤 | 规定 | 记录 |
|------|------|------|
| 基材 | 同批镜面不锈钢 | 牌号、批号、是否有保护膜 |
| 钝化 | 安驰 2:1，刮涂均匀 | 配比、湿膜、晾置、烘干设定与板温 |
| 底漆施工 | 干膜 7±1 μm | 刮棒号 / 辊速、湿膜、实测干膜 |
| 底漆烘烤 | 炉温按现场常用 **280℃**；时间先对历史三点：75 / 80 / 85 s | **炉温、在炉时间、实测 PMT** 三项都写。历史对照：75 s → PMT 224℃；80 s → PMT 232℃；85 s → PMT 241℃ |
| 中心窗 | 第一轮底、面都以 **PMT 232–236℃** 为中心（对应约 80 s 档） | PMT＜228℃ 易欠固化；PMT＞240℃ 易脆、酒精拉漆。这是筛选窗，不是已证明最优点 |
| 复涂 | 底漆冷却后**同日**涂面漆 | 间隔分钟数 |
| 面漆 | 干膜 21±2 μm，总干膜 28–30 μm | 面漆同样记炉温 / 时间 / PMT（底漆等于二次受热） |
| 养板 | 23±2℃，24 h 再测 | 起测时间 |
| 试片 | 每组每条判定线 ≥3 片独立板 | 编号 BL-x-1/2/3 |

## 五、检测线

### 5.1 第一轮（当天到次日）

每片先写破坏面，再写过/不过：

1. 膜厚、60° 光泽、L/a/b、铅笔 HB（及是否 2H）。  
2. 干态 1T、干态 0T：裂纹 / 掉漆。  
3. 0T 后 100℃ 去离子水煮 2 h：起泡、发白、掉漆；3M 898 拉。  
4. 另片：百格 1 mm → 折 0T → 75% 乙醇 23±2℃ × 30 min → 3M 连拉 3 次。  
5. 破坏面四选一（可多选但主因只标一个）：面漆开裂；底 / 面界面揭开；底漆内聚；底漆 / 钢脱落见金属。

MEK 只作参考，**不能**代替水煮和酒精。

### 5.2 第二轮（仅第一轮全过的配方）

- 80℃ × 240 h：T 弯后分泡 5% NaCl 与去离子水，3M 898。  
- 80℃ × 160 h：划十字，48 h 看起泡 / 发白 / 脱落，再泡 120 h。  
- TPV、PVC 胶粘 + 约定湿热后剥离，记破坏面。  
- 20° 光泽对照。

### 5.3 第三轮

耐候 ≥2000 h 及客户其余机械项（杯突、冲击等按实验表）。

## 六、调整规则（只改一个变量）

| 看到的现象 | 主因判断 | 下一刀 |
|------------|----------|--------|
| 干态 0T 已裂 | 面漆偏脆或过烤 | 降面漆交联或降 PMT 至 232℃ 中心；不改底漆环氧 |
| 胶带后面漆走、底漆留在钢上 | 层间 | 查底漆是否过烤失重涂、复涂间隔、面漆溶剂咬底；可微调底漆交联（BL-1↔BL-2） |
| 整层见金属 | 前处理 / 底对钢 | 先复验钝化 2:1 与板面达因 / 水膜，再动 S1100 或底漆树脂，不加气相二氧化硅 |
| 煮后软、掉，干态不裂 | 欠固化或耐水差 | 提到 PMT 232–236℃；检查封闭剂用量是否按当量而不是凭感觉加 |
| 酒精掉、水煮过 | 交联或层间耐醇 | 略增交联（BL-2 方向）或查面漆；不要上 F2148 |
| 水煮掉、酒精过 | 界面亲水或环氧/聚酯配比 | 走 BL-3；仍失败再考虑硅烷，不做粉体疏水剂 |
| 底漆内聚粉化 / 被拉散 | 才允许第二轮 F2148 | 底漆 100.00 g 外加 0 / 0.10 / 0.25 / 0.50 g，预分散，观察流平与 0T |

## 七、称料前必须补齐

- 08-18-03 完整湿配方、各树脂固含 / 羟值。  
- 08-11-05 完整湿配方、批次。  
- TS-3127、TS-3102、S1239、S1268、S1100 的 TDS 与有效含量。  
- 酒精浓度若客户另有指定，覆盖本方案 75%。  
- 胶带拉掉后的破坏面照片（回答 Codex 最后一问：底留在钢上，还是连底带面见金属）。

没有破坏面照片时，仍按上表四组开做，但出报告必须补拍。

## 八、为什么这是综合后的「最佳」而不是旧对话原文

| 旧对话 / 其它稿 | 本方案 |
|-----------------|--------|
| 底 5±1 + 面 18±2 μm | 总干膜 28–30 μm，底 7±1 + 面 21±2 |
| 快筛当终验 | 快筛与 80℃ 240 h / 胶粘 / 耐候分层 |
| 把 2H 当客户硬度 | 客户 HB；2H 加严 |
| 9-18 环氧底一度进优先组 | 按你的反馈移出第一轮 |
| 08-18-04 写成纯聚酯 | 写明仍含 S1268 |
| Gemini 给 100% 量产方 | 不采用，身份与证据不够 |
