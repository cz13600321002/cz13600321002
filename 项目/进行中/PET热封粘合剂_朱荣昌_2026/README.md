# PET热封粘合剂_朱荣昌_2026

客户朱荣昌：PET 上涂热封胶，封**裸 PET** 杯子，**可揭奶茶盖**。水性、网纹辊、90℃ × 20–30 秒、不反粘、气味小。热封 **180–220℃ × 1.5 s × 0.4 MPa**。

## 锁

不重写 HS-B C0。不编份数。不写能接 / 能出货。合同不写食品接触。不合单：环氧光油、铝箔预涂热封。V1.0「越大越好」不作主推。

## 样号

- **HS-PET-W1** 主推可揭：共聚酯 + EVA + 软/硬丙（硬相加一档）+ 蜡/EBS
- **HS-PET-W1-L** 过封对照：V1.0 高软相，不报客户
- **HS-PET-W2** 对照：EAA（共聚酯未到；裸 PET 上易过封）
- **HS-PET-W3** 对照：纯丙（盖膜脱落则停）

## 可揭窗（报数用）

180℃：3.0–7.0 N/15 mm；200℃：4.0–8.0；220℃：4.0–10.0，仍可揭、不撕膜。胶留盖膜。70℃ 水 30 min 不漏。

## 下一门（不代发、不代改表）

1. 张总补盖膜厚度/电晕、杯子牌号、灌装温度；确认 0.4 是 MPa。  
2. 张总补《客户来样方案》新行（写清裸 PET、可揭奶茶、180–220/0.4/1.5s）。  
3. 寻共聚酯 / EVA / 低氨丙乳 / 蜡，入盘后再刮。  
4. 未入盘不开 5 kg。
