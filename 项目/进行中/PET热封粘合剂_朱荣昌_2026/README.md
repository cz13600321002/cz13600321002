# PET热封粘合剂_朱荣昌_2026

客户朱荣昌：PET 上涂热封胶，封 PET 杯子。水性、网纹辊、90℃ × 20–30 秒、不反粘、气味小。拉力未给。

不重写 HS-B C0。不编份数。不写能接 / 能出货。合同不写食品接触。不合单：环氧光油、铝箔预涂热封。
