# 寻样要求（库存无，先成膜再吸附）

日期：2026-09-07  
张总已锁：库存柔性双组分**无**；路径 **A**。  
本页给采购/供应商。不写本厂份数，不点 JS 牌号当能用。

---

## 要什么样

| 项 | 要 | 不要 |
|----|----|------|
| 施工 | 能刮涂在铝板上，干胶 **0.3 mm** | 网辊/线棒薄层、3–5 gsm 干复胶 |
| 成膜 | 在铝上固化或表干后**开面**仍有吸附 | 必须湿贴才能粘；表干后发硬如漆 |
| 对 PET | 未电晕白 PET 片材按上能吸住；提起、竖放不掉 | 电晕 ≥38 才合格；永久复合揭不开 |
| 可揭 | 手能拿下 PET，胶留在铝上，胶面不破 | 揭时胶被撕走、胶面烂 |
| 手感 | 固化后能弯，有弹性 | 硬板、一折就裂 |
| 温度 | 耐 80℃ 不淌、不掉；长期 40–50℃ 不边翘 | 必须 180℃ / 216℃ 烤漆窗 |
| 导热 | 先不要 | 加导热粉、报 1.5 |
| 资料 | 必须带 TDS（配比、固含、成膜条件、适用期） | 只给口头「可以吸」 |

---

## 寻样方向（只作族，不点能接的牌）

到样前不写死哪一族。供应商自报属于哪一类，并附 TDS：

1. 开面硅凝胶 / 吸附硅胶（不是导热灌封硅胶）  
2. 聚氨酯凝胶 / 柔性开面弹性体  
3. 丙烯酸凝胶或可反复贴的厚层压敏（能刮到 0.3 mm）

08-25 已核：库存无球铝、无加成型**导热**硅胶。本单要的是开面吸附，不是导热垫。有导热硅胶 TDS 也不当本单到样。

---

## 到样怎么收

- 小样即可（够刮两三片铝板）。  
- 无 TDS 视为未到，不开检查单。  
- 到样登记：供应商、品名、批号、到日、TDS 页。  
- 实验室仍要张总签发检查单后才刮 **N0 + F0-A**。

## 供应商不要寄

JS-2130 同类干复薄层；卷材高温复合胶；氟碳/大理石硬漆；带正高一类 PET 处理剂的配套；导热粉预混料。
