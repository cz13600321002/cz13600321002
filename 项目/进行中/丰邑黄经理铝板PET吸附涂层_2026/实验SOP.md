# 实验 SOP（非正式摸底）

只在开工检查单签发之后执行。不编份数。不加导热粉。不用 100#。

---

## 1. 铝板

1. 丙酮或乙酯擦两遍，晾干。不要带水。  
2. 可见油膜或氧化：240–400 目轻打磨，再除油一次。  
3. 记：是否阳极/涂层铝（未知就写未知）。

## 2. 白 PET

1. 未电晕。用前去尘去油。  
2. **不要**正高处理剂、不要电晕当本单合格条件。  
3. 记品号、厚度；没有就写未知。

## 3. N0

铝除油后直接覆 PET，赶气泡。不刮胶。立刻做一次提起（预期掉）。留下样。

## 4. F0（点名锅）

1. 按该锅 TDS 称 A:B。适用期按 TDS；超时、变浑、明显变稠则停用。  
2. 胶刮在铝上。刮刀或手刮，**目标干胶 0.3 mm**。刮完先看厚度，宁薄勿超。  
3. 路径 B（未改口）：马上覆白 PET，从中心往外赶气泡，边缘压实。  
4. 路径 A（仅已拍）：按 TDS 先让胶在铝上成膜/表干，再覆 PET。  
5. 固化/熟化只按该锅 TDS。不上康纳 180℃×8 min，不上钢壹 216℃ / 280×50s。

## 5. 测

1. 冷却后测干胶厚。超 0.30±0.05 mm 作废重刮，不准磨薄充数。  
2. 熟化满之前只记外观和厚度。  
3. 熟化后：提起、竖放、手感、手揭、失效面。  
4. 再做 80℃、50℃×24 h。  
5. 不测剥离，不报牛顿数，不测导热。

## 6. 失败怎么改（只改失效面指出的那一层）

| 失效 | 只允许 |
|------|--------|
| ① 提起就掉 | 查胶是否已硬、路径是否该改 A/B；**换点名锅**，不加厚充 tack |
| ② 整层从铝揭 | 复查除油/打磨；不换钢壹胶、不加正高 |
| 胶面破 / 胶被 PET 带走 | 路径 B 交联过强 → 回报张总改 A 或换更弹性的锅 |
| 硬、一折就裂 | 这锅不是柔性；停，再点下一只 |
| 淌胶 | 这锅耐不住 80℃；停，再点 |

不准：加 TF-729、加 JS-2130、改用 100#、把钢壹样当本单。
