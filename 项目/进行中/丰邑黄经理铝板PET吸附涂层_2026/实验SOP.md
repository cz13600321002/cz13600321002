# 实验 SOP（路径 A · 到样后才执行）

只在开工检查单签发之后执行。库存无柔性双组分时**整份不用**。  
不编份数。不加导热粉。不用 100#。不准湿贴。

---

## 1. 铝板

1. 丙酮或乙酯擦两遍，晾干。不要带水。  
2. 可见油膜或氧化：240–400 目轻打磨，再除油一次。  
3. 记：是否阳极/涂层铝（未知就写未知）。

## 2. 白 PET

1. 未电晕。用前去尘去油。  
2. **不要**正高处理剂、不要电晕当本单合格条件。  
3. 记品号、厚度；没有就写未知。  
4. 成膜完成前 **PET 不贴上去**。

## 3. N0

铝除油后直接覆 PET，赶气泡。不刮胶。立刻做一次提起（预期掉）。留下样。

## 4. F0-A（到样锅，先成膜再吸附）

1. 按到样 TDS 称料。适用期按 TDS；超时、变浑、明显变稠则停用。  
2. 胶刮在铝上。刮刀或手刮，**目标干胶 0.3 mm**。刮完先看厚度，宁薄勿超。  
3. **先成膜**：按 TDS 固化或表干。未写时间则室温 24 h。膜面指触不转印到手指、但仍有吸附再往下。  
4. 测干胶厚。超 0.30±0.05 mm 作废重刮，不准磨薄充数。  
5. **再覆**白 PET。手压或刮板从中心往外赶气泡，边缘贴实。不准在湿胶上覆。  
6. 覆后至少 30 min（TDS 另有规定则从其规定）再测提起/竖放/手揭。  
7. 不上康纳 180℃×8 min，不上钢壹 216℃ / 280×50s。

## 5. 测

1. 成膜满之前只记外观和厚度，不覆 PET。  
2. 覆后：提起、竖放、手感、手揭、失效面。手揭是验收。  
3. 再做 80℃、50℃×24 h。  
4. 不测剥离，不报牛顿数，不测导热。

## 6. 失败怎么改（只改失效面指出的那一层）

| 失效 | 只允许 |
|------|--------|
| ① 提起就掉 | 成膜后无吸附 → 这锅不合格，换寻样；不加厚、不改回湿贴 |
| ② 整层从铝揭 | 复查除油/打磨；不换钢壹胶、不加正高 |
| 胶面破 / 胶被 PET 带走 | 内聚不够或对 PET 真粘合 → 换寻样 |
| 硬、一折就裂 | 不是开面弹性层；停，换寻样 |
| 淌胶 | 耐不住 80℃；停，换寻样 |

不准：加 TF-729、加 JS-2130、改用 100#、马上覆 PET、把钢壹样当本单。
