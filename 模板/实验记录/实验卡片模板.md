# 实验卡片

按 Notion「涂料粘合剂实验记录模板」字段起草。只起草，不自动写入数据库。

| 字段 | 填写 |
|---|---|
| 实验编号 | |
| 项目类型 | |
| 实验目标 | |
| 树脂体系 | （大类 + 待确认牌号，不写质量份） |
| 助剂组合 | |

| 附着力测试 | （无数据则留空） |
| 盐雾测试 | （无数据则留空） |
| 结论 | 尚未实验 / 或写破坏面与原始值 |
| 记录时间 | |

## 打样约束

- 一次只改：牌号、表面处理、干胶量 三者之一。
- 必须预留要记录的原始值：表面张力、干胶量、烘烤、压力、熟化、剥离、水煮、破坏面。
- 没有原始值时，结论只能写「尚未实验」或「资料不足」。
