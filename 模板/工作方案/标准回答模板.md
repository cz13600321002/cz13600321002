# 标准回答

**问题：**  
**回答人 / Agent：**  
**日期：**  

```text
结论（一句话，可执行）
资料状态：现行 / 冲突 / 资料不足
引用：
- 文件 | 版本或日期 | 条款 | 原文要点
缺口（未确认前不得放大 / 报价 / 对外承诺）
建议下一步实验（单变量，写清原始值和破坏面）
```

## 填写说明

- 数字没有出处时，资料状态必须是「资料不足」，结论不得假装确定。
- 同一牌号多版本不一致时，资料状态必须是「冲突」，列出差异，不选边。
- TDS 里的典型值、建议工艺，一律标「TDS 建议」，不得写成放行规格或项目结论。
- 破坏面必须写成：胶层内聚 / PVC-胶界面 / 胶-基材界面 / 基材表层，禁止只写「没粘住」。
