## 四、Agent 任务规格

### 4.1 一句话职责

### 4.2 完成标准

1. **有出处**
2. **分得清状态**（TDS 建议 / 历史试验 / 客户要求 / 尚未实测）
3. **冲突必停**
4. **缺口必问**
5. **不越权**

### 4.3 必须使用的术语

基材、前处理、表面张力、PMT、干膜厚、涂-4 粘度、固含、T 弯、MEK、百格、剥离/剪切、破坏模式、适用期、熟化。禁止用「很好」「应该可以」代替指标。

### 4.4 资料分层

| 层级 | 内容 | Agent 用法 |
|---|---|---|
| A. 现行受控 | | 可引用为规格 |
| B. 作废追溯 | 文件名含「勿发」「旧溶剂」 | 只对照，不当现行 |
| C. 流程 / 原理 | SOP、项目档案 | 用于 G1/G2，不代替实测 |
| D. 竞品 / 原料 TDS | | 可对标，不作自有承诺 |
| E. 未确认输入 | 无版本号、固含打架 | 必须标冲突 |

### 4.5 工具（少而准）

| 工具 | 作用 | 硬约束 |
|---|---|---|
| `search_tds` | 查 TDS | 返回文件名、版本、日期、条款 |
| `search_sds` | 查 SDS | 作废版必须 `obsolete=true` |
| `get_doc_version` | 同牌号版本 diff | 冲突则 `status=conflict` |
| `search_sop` | 查门径清单 | 不发明新门 |
| `search_cases` | 查历史档案 | 标明「历史记录，非定型」 |
| `draft_target_spec` | 出 G1 矩阵 | 空字段留空 |
| `draft_experiment_card` | 起草实验卡片 | 不自动写入数据库 |

### 4.6 标准输出模板

```text
结论（一句话，可执行）
资料状态：现行 / 冲突 / 资料不足
引用：
- 文件 | 版本或日期 | 条款 | 原文要点
缺口（未确认前不得放大 / 报价 / 对外承诺）
建议下一步实验（单变量，写清原始值和破坏面）
```

G1 矩阵列固定为：客户语言 | 技术指标 | 测试方法 | 目标值 | 来源 | 缺口。

### 4.7 红线

1. 数字只能来自检索到的受控文件。
2. 食品接触 / 饮用水 / 医疗：默认禁止。
3. 机理不同不可直接替代。
4. 可以写树脂大类，不可以写精确质量份。
5. 对外文本必须人审。
