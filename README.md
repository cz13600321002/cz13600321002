## 使用说明

1. **新建文档**：按类型放入对应的 `文档/` 子目录
2. **使用模板**：从 `模板/` 目录复制所需模板，填写内容后保存至 `文档/`
3. **项目管理**：在 `项目/` 下按状态管理项目文件夹
4. **资料查阅**：相关资料统一存放于 `资料/` 目录
5. **文档归档**：完结或过期文档移至 `归档/` 目录保存

### 粘合 / 复合类问题（先走框架）

以后再遇到基材附着、迁出物、水煮掉胶：先打开 [粘合问题通用框架](文档/方案/20260905_粘合问题通用框架.md)，用 [粘合问题方案模板](模板/工作方案/粘合问题方案模板.md) 另存方案，在 [开工包](项目/进行中/粘合问题框架_2026/README.md) 勾检查单再打胶。

水煮后胶连膜从金属整层揭：先读 [水煮金属侧剥离要点](资料/行业资料/水煮金属侧剥离要点.md) 和 [PVC–金属方案 V1.1](文档/方案/20260905_PVC膜与金属板增塑剂影响克服方案.md)。
