**配套：** `模板/工作方案/粘合问题方案模板.md`；开工包在 `项目/进行中/粘合问题框架_2026/`。

**从哪几份方案收上来的：**

| 实例 | 教会框架的那一条 |
|------|------------------|
| 未电晕 PE、80℃×20 min | 低能表面靠同族互扩散，不靠把基材烤化；底涂是分子桥，必须薄 |
| PE + 金属同一配方 | 两头各要一种官能，做进同一层或分层分工；湿附着单独验 |
| TPU 涂布后流延 TPE | 先画结构、先点名两道界面；胶带合格 ≠ 复合合格 |
| TPE 0.1% 芥酸酰胺 | 迁出物铺满界面只需 mg/m²；精确解法是拿掉贴合面，不是加厚胶 |
| 擦完再预热 | 热会把小分子秒级赶回表面，白擦 |
| PVC 膜贴金属 + 增塑剂 | 同一弱边界模型，储量更大；主胶族不能照抄 PE 型 CPO |
| **水煮后胶+PVC 从金属整层揭** | 失效在金属/胶湿热面；40℃ 只预筛；P-W（转化/硅烷/薄环氧）先于改 PVC |

## 一句话

先画结构、先点名每一道界面、先查迁出物，再查表选胶。  
用 **无迁出物对照 + 失效面 + 24 h/72 h/热老化** 决定改哪一层。  
**可操作**的意思是：当天能填表、能配对照、能锁厚度/温度/验收门；不是再写一篇原理。

不要一上来调树脂比、加厚、换胶带。

## 〇、什么时候用，什么时候不用

| 用 | 不用（先停） |
|----|--------------|
| 两种（或三种）材料要靠胶/底涂/热贴合连在一起 | 基材牌号、哪一面贴合都说不清 |
| 有固定工艺窗口（如 80℃×20 min、禁止电晕、必须流延） | 窗口本身还在争论，先把窗口写成一行再开工 |
| 怀疑爽滑剂、增塑剂、油、蜡、硅在毁胶 | 只想“推荐一个万能胶”且不肯做对照 |
| 要两个基材共用一条线 | 其实是两条线、两套胶，目标要改写成“允许分配方” |

缺牌号可以开做，但结论只写相对值（达到 H0 的百分之几）和失效面，**不报牛顿数当承诺**。

## 一、固定七步（不许跳）

每天新问题按这个顺序。某一步填空填不出，就停在那一步，不要用猜测往下配胶。

```
1 画结构，给每一道界面起名
2 给每一种固体材料定性（族、表面、耐热、能不能洗）
3 列出迁出物 / 隔离剂 / 油，预判先死哪一道界面
4 查表选胶族和结构（源控制 / 隔离 / 交联 / 双锚定），不发明“新万能树脂”
5 锁工艺：谁加热、膜厚、烘烤、贴合压力、禁止项
6 下最小试验包：N0 负对照 + H0/H1 迁出物对照 + 失效面 + 时效
7 门过了才写工艺卡；门没过只允许改被失效面指出的那一层
```

对应填空文件：

| 步 | 填哪里 | 当天交付 |
|----|--------|----------|
| 1～3 | `开工检查单.md` | 结构图 + 界面表 + 迁出物表 |
| 4 | `材料与胶种预判表.md` | 主路线 / 备选 / 禁止胶族 |
| 5～6 | `对照试验矩阵.md` + `实验SOP.md` | 组别代号、厚度、温度、测什么 |
| 6 | `试验记录表.md` | 原始数据 |
| 7 | `工艺卡模板.md` | 只填通过门的那一条 |

具体化学方案用 `模板/工作方案/粘合问题方案模板.md` 另存到 `文档/方案/YYYYMMDD_….md`。

## 二、结构图（先画，再说话）

把材料从上到下写成层，箭头只标「这一步发生什么」（涂、烘、流延、热压）。  
禁止用一句话「A 和 B 粘一下」代替结构。

```
空气面 / 装饰面     （迁出物常在这里故意存在：爽滑、手感）
基材 A 本体
贴合皮层 A          （没有就写“与本体同一配方”）
   ↑ 界面 ①
底涂 / 隔离层       （没有就写“无”）
   ↑ 界面 ②
粘合剂 / 粘结层
   ↑ 界面 ③
底涂                （没有就写“无”）
   ↑ 界面 ④
贴合皮层 B
基材 B 本体
```

层可以少，界面名不能混。后面所有失效都只准写成「界面 ① / ② / …」或「某层内聚」。

### 2.1 每一道界面填一张卡

| 界面 | 上面是什么 | 下面是什么 | 矛盾（极性/热/油） | 这层该提供什么 | 失败会长什么样 |
|------|------------|------------|--------------------|----------------|----------------|
| ① | | | | | 哪一面发亮、发滑、带胶 |
| ② | | | | | |
| ③ | | | | | |

预判规则：

- 低能聚烯烃（PE/PP/TPO）对极性胶 → 缺互扩散，界面会「聚烯烃面发亮」。  
- 金属对非极性胶 → 缺成盐/螯合，金属面发亮；浸水后更差。  
- 两边都不亲 → 要双锚定或两层分工，不要找「一种分子两头都最强」。  
- 有迁出物 → **先假定贴合面那一道会死**，再谈胶够不够。

## 三、材料预判（查表，不靠感觉）

详细表见 `资料/行业资料/粘合材料与胶种预判要点.md`。这里只留开工时要用的判断。

### 3.1 基材族 → 先想到的化学

| 基材族 | 表面事实 | 先选什么咬它 | 不要先选 |
|--------|----------|--------------|----------|
| PE（尤其未电晕） | 表面能 ~31–33 mN/m，无极性点 | **PE 型 CPO**、EAA、PE-g-MAH | 环氧、硅烷当主膜、PP 保险杠 CPO |
| PP / TPO / TPV | 比 PE 略好涂，仍非极性 | **PP 型 CPO**、PP-g-MAH | 只拿 PE 型 CPO 硬套 |
| TPU | 表面能常 40–45，一般免电晕 | 酸酐、羧基、氨酯、EAA | 当未电晕 PE 来做电晕 |
| 软 PVC | 常有 20–50 phr 增塑剂 | NBR、2K PU、醋酸乙烯；先管油 | 热塑丙烯酸、SIS/SBS、PE 型 CPO 当主胶 |
| 硬 PVC / PET / 漆膜 | 极性中等 | PU、聚酯、丙烯酸氨基甲酸酯 | 当聚烯烃用 CPO 互扩散 |
| 铝 | 氧化层，怕油、怕水 | 羧基 / 酸酐 / 磷酸根 / 锆钛 | 不脱脂就涂；厚 CPO 当防锈 |
| 冷轧钢 | 油、锈、闪锈 | 脱脂 + 同上；湿附着单独验 | 把钢当铝的干净对照 |
| 流延 TPE（SEBS/SBS/TPO） | 要热焊，怕交联皮 | 热塑性聚烯烃链、接枝 MAH | 2K 面漆后再流延 |
| 橡胶（NBR/CR/EPDM） | 看含油和硫化体系 | 同族胶或酚醛增黏 | 忽略隔离剂和喷霜 |

同一条产线要服务**两种基材**：按「PE+金属」那条——一层里拼两种官能，或底涂咬金属、主胶咬高分子。目标必须写明是「同一配方」还是「允许分配方」。

### 3.2 胶在结构里的角色（先定角色，再定厚度）

| 角色 | 干什么 | 典型干膜 | 涂厚了会怎样 |
|------|--------|----------|--------------|
| 分子桥底涂 | 只负责界面互扩散 / 成盐 | **0.5～2 μm** | 内聚先裂，看起来像附着差 |
| 隔离底涂 | 挡迁出物，必须交联 | **3～8 μm** | 仍挡不住就加厚贴合皮层，不靠堆到 30 μm |
| 复合主胶 | 传力、填不平、交联抗溶胀 | **15～30 μm** | 再厚去“吃油”会先被泡软 |
| 热塑性粘结层（待熔体再焊） | 保持能再软化 | **0.5～1.5 μm** | 交联或涂厚都焊不住 |

PE 方案的「必须薄」和 PVC 方案的「主胶 15～30 μm」不矛盾：**角色不同**。开工检查单上必须勾角色，禁止只写“涂一层胶”。

## 四、迁出物预判（多数后期掉胶走这里）

### 4.1 先问四句

1. 本体里有没有故意加的小分子？（酰胺、开口剂、增塑剂、充油、硅油、蜡）  
2. 表面上有没有加工助剂？（模唇转出、压延辊、隔离纸、脱模剂）  
3. 工艺会不会加热贴合面？（预热、烘、流延、热压）  
4. 有没有「下机好、隔天/热老化差」的传闻？

有 1 或 4，按迁出物立项，不要按“胶不够粘”立项。

### 4.2 常见迁出物

| 迁出物 | 常见量 | 铺满界面大约 | 典型指纹 | 精确做法 | 假克服 |
|--------|--------|--------------|----------|----------|--------|
| 芥酸酰胺 | 0.05%～0.3% | 1～3 mg/m² | 当时尚可，**24～72 h 或 70℃ 再掉**，贴合面滑 | 贴合皮层 **0 / ≤50 ppm**，厚 15～25 μm | 加厚底涂、换油酸酰胺、酚醛“吃掉” |
| 油酸酰胺 | 同上 | 同上 | **当时就更差**（爬得快） | 同上 | 同量对换酰胺种类 |
| 软 PVC 增塑剂 | 20～50 phr | 10～50 mg/m² | 弱边界 + 胶被泡软（内聚也掉） | 贴合皮层聚合型/低 phr，**25～40 μm**；或交联隔离 | 酒精擦完再热压；DOTP 替换就宣布成功 |
| 充油 SEBS 的油 | 百分之几～几十 | 易铺满 | 和酰胺叠加，后期掉 | 贴合层少油 + 接枝 | 只加 MAH 想吞油 |
| 硅油 / 隔离剂 | 痕量即可 | 单分子层 | 整层揭、水膜不连续 | 洗掉或换膜；电晕不是第一刀 | 加大胶厚 |
| 蜡 / 喷霜 | 不定 | 薄层 | 粉面、滑 | 去掉或改到空气面 | 打磨当常规工艺 |

储量判断：界面只要一层。0.1% 酰胺在 0.1 mm 片里大约 100 mg/m²，铺满只用几毫克。软 PVC 的增塑剂储量再大两三个数量级。**所以「胶把油吃掉」几乎从来不是主路线。**

### 4.3 热和擦拭

| 做法 | 框架怎么判 |
|------|------------|
| 只热金属 / 只热已涂胶的那一侧 | 允许，优先 |
| 热会迁出的那一侧（PVC、含酰胺 TPE）再预热 | 默认有害 |
| IPA 擦后 5～10 min 内贴，且不再预热该面 | 权宜，只能去表面第一层 |
| 擦完再预热再贴 | **白擦**，可做 W1x 证明，不能当工艺 |

## 五、结构对策（按效力，写进方案时只能挑其中几条）

从上到下，能做上面的就不把希望放在下面。

| 效力 | 名字 | 操作定义（写得出数字才算） |
|------|------|----------------------------|
| 上 | 源控制 / 分层 | 贴合皮层配方与空气面分开；迁出物目标 **0 或写出 ppm/phr**；厚度写出 μm |
| 上 | 换低迁移品种 | 聚合型增塑剂、去掉酰胺、换无硅隔离 |
| 中 | 交联隔离底涂 | 3～8 μm，必须交联，热塑膜不算隔离 |
| 中 | 交联主胶 + 双锚定 | 胶族查表；NCO/OH、AN% 等写出范围 |
| 中 | 只热不迁出的那一侧 | 温度、压力、时间写进工艺卡 |
| 下 | 擦拭、短气隙、略增贴压 | 只减轻，对照里必须带 H1 原状 |
| 无 | 加厚分子桥、交联后再热焊、只看下机 | 禁止写入「克服」 |

选胶时同时选**禁止胶族**，避免实验室把抽屉里的环氧、硅烷、热熔胶全试一遍。

## 六、最小可操作试验包（默认就做这些）

组别字母全项目统一，避免每份方案自创一套。

| 代号 | 含义 | 缺了会怎样 |
|------|------|------------|
| N0 | 无底涂/无粘结层，其余相同 | 不知道「要不要这一层」 |
| H0 | 迁出物关掉或换成低迁移 | 不知道上限是胶/金属不够，还是油 |
| H1 | 现场真实料 | 没有它，方案是空的 |
| H2 | 分层或换贴合皮层（源控制） | 不知道上策有没有用 |
| B0 / B1 | 无隔离 / 有交联隔离 | 不知道中策有没有用 |
| W1 / W1x | 擦后快贴 / 擦后预热再贴 | 防止把白擦写成工艺 |
| C0 / C1 | 涂层第三组分 0% / 现用量（如酚醛） | 添加剂和迁出物不混在一锅里调 |
| P0 | 允许的正对照（如电晕、已转化膜） | 只说明方法灵敏，**不写成未处理结论** |
| M0 | 金属只脱脂，无湿底涂 | 不知道水煮掉是不是金属侧 |
| M-Si / M-Ep / M-Zr | 硅烷 / 薄环氧 / 转化膜 | 水煮从金属掉时的第一组对照 |

每组必测：

1. **过程检**：底涂是否咬住它所在的那一侧（划格或胶带）。不合格不准进入贴合/流延。  
2. **验收检**：复合用 180° 剥离（GB/T 2790 / 2791 / 8808）；涂装薄膜用胶带（GB/T 13217.7）或硬板划格（GB/T 9286）。两者不互相替代。  
3. **失效面**：V 贴合面光 / C 胶内聚 / M 金属光 / P 材料拉坏 / X 混合。  
4. **时点**：下机 2 h（只筛）、**24 h 正式**、**72 h**；含油/增塑剂/酰胺加 **70℃×24 h**。  
5. 金属件：先 **40℃ 去离子水 24 h** 预筛；现场或产品要求耐沸水时，**养满 24 h 后再 100±2℃ × 60 min 水煮**，淋凉后 30 min～1 h 内剥。自发揭 ≥10% 直接失败。  
6. 水煮从金属掉：先看硬质/无迁出物对照。**硬质过、只有软质掉 → 冻结金属，开 H2/B1。** 硬质也掉 → 再开 M0 vs M-Zr+Si。不要先加厚主胶。

判定（可操作，不靠嘴）：

| 现象 | 结论 | 下一步只准动 |
|------|------|--------------|
| H0 好、H1 差，H1 失效在贴合面且发滑 | 迁出物是瓶颈 | H2 或 B1，禁止先加厚胶 |
| H0 也差，失效在金属 | 金属清洁或底涂 | 脱脂 / P-E，不动 PVC 配方 |
| **水煮后胶连高分子从金属整层揭（M）** | 先看硬质/H0 | 硬质也掉 → P-W；**只有软质掉 → 冻结金属，H2/B1** |
| **只有软质掉、硬质水煮没有问题** | 增塑剂到金属侧（本现场已锁定） | **不准先改金属**；皮层或交联隔离 |
| 主胶是聚酯+封闭异氰酸酯 | 80℃ 常不解封；软质酯类增塑剂专泡聚酯 | **K1：金属上先解封再贴软膜**；再不够才 H2/B1；不先换腈胶 |
| 水煮边缘起泡、封边样过 | 切口进水 | 现场要否封边是产品问题；配方仍按不封边过 |
| H0 也差，失效在胶内聚 | 胶没干、没交联、或涂厚 | 干膜、NCO/OH、烘透 |
| H0 好、H2 达到 H0 的 ≥90%，72 h 再掉 ≤10% | **上策成立**，可写工艺卡 | 锁厚度与进料抽检 |
| W1 好、W1x 差 | 预热在毁擦拭 | 工艺禁止预热该面 |
| C0/C1 只在难粘侧有差别、H0/H1 一样差 | 第三组分不是迁出物解 | 不要靠酚醛吃油 |
| 24 h 好、72 h/70℃ 差 | 第二波析出或胶后熟不够 | 先看 H0 是否也掉：H0 也掉 = 胶没熟；仅 H1 掉 = 油 |

胶带：全项目锁同一牌号（PE 涂装默认 3M 610）。  
剥离：锁宽度（15 或 25 mm）和速度（100 或 300 mm/min）。换了就重开表，不和旧数比。

## 七、工艺窗口怎么锁（写得出才准开工）

从已有方案收一组**默认值**。具体项目可以改，但必须在开工检查单写「改了哪一条、为什么」。

| 项 | 默认 | 谁可以改 |
|----|------|----------|
| 清洁 | IPA 单向 2 遍，晾 ≥5 min；金属先碱脱脂 | 有隔离剂时加中性洗，水必须烘干 |
| 禁止 | 未立项的电晕 / 火焰 / 等离子 / 打砂 | P0 对照除外 |
| 烘烤 | 80±2℃ × 20 min，试样贴板，5 min 膜温 ≥75℃ | 胶厂另有固化曲线时整段替换并写明 |
| 分子桥干膜 | 0.5～1.5 μm（金属底涂 1～2 μm） | 角色改成主胶时改 15～30 μm |
| 表干 | 8～10 min 再入炉或再盖第二层 | 水性另测指触 |
| 贴合 | 优先只热稳定侧；0.3～0.6 MPa；记下秒数 | 流延按熔温 160～230℃ 另表 |
| 养护 | 出炉冷 ≥30 min，**23℃/50%RH 24 h** 才验收 | — |
| 复测 | 关键样 72 h；迁出物样加 70℃×24 h | — |
| 金属湿 | 40℃×24 h 预筛；水煮 100±2℃×60 min 为耐沸水验收 | 产品标准另有分钟数则写进检查单 |

80℃ 的正确角色永远是：赶溶剂、铺展、让 2K **起步**交联。  
它烤不化 PE，赶不走 PVC 储库，也完不成多数封闭型固化。**24 h 才是交联和迁出物的第一张真成绩单。**

## 八、验收门（没过不准写「已克服」）

对迁出物类问题，套这张门（PE 纯涂装无油时，H0 可改成 N1 主配方）：

| 样 | 24 h | 72 h 或 70℃×24 h | 失效面 / 表面 |
|----|------|-------------------|---------------|
| H0 | 基准 | 不掉或很少 | 无油膜 |
| H2 或 B1（宣称的克服） | **≥ H0 的 90%** | 相对 24 h 再掉 **≤10%** | 贴合面不明显滑 |
| H1 原状 | 对照 | 常再掉 | 不作为合格工艺 |

涂装类（无复合）：24 h 胶带 ≥90%（目标 ≥95%）或划格 ≤1 级（目标 0），72 h 下降 ≤5 个百分点。  
金属：干态目标 0 级；40℃ 浸水后 ≤1 级。  
耐沸水：水煮后不自发揭、不为大面积露金属；剥力目标 ≥ 同组干态 70%。未养 24 h 的水煮数据作废。

工艺卡只抄「过门」的那一组参数。其他组留在记录表里当否决证据。
