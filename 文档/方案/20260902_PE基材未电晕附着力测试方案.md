# 工作方案

**方案名称：** 未电晕 PE 基材涂布附着力测试与达标方案  
**编制人：** 张忠诚  
**所属部门：** 技术/实验室  
**编制日期：** 2026-09-02  
**文档版本：** V1.0  
**适用工况：** PE 基材 · **未电晕** · 涂布后烘烤 **80℃ × 20 min**

---

## 一、背景与目的

未电晕聚乙烯（PE）表面能仅约 31～33 mN/m，极性分量接近于零，水接触角通常 ≥90°，达因值多在 30～34 dyn/cm。常规涂料、油墨、胶粘剂无法在该表面上充分铺展，涂布后即使成膜，界面也几乎只有弱范德华力，划格和胶带测试极易整层剥离。

本方案针对固定工艺窗口——**禁止电晕/火焰/等离子等表面处理，涂布后强制对流烘烤 80℃×20 min**——同时解决两件事：

1. **测得准：** 建立可复现、可对比、可判定的附着力测试方法，先证明基材确实未电晕，再评价涂层。
2. **贴得住：** 在不电晕的前提下，给出可落地的底涂/单涂技术路线，使涂层在该烘烤条件下达到可验收等级。

电晕把表面能做到 38～42 dyn/cm 是行业捷径。本方案主动放弃这条路，改走 **化学锚定（氯化聚烯烃 / 接枝聚烯烃 / PEI）+ 成膜温度匹配 80℃**，用对照样把“基材问题”和“配方问题”一次拆开。

---

## 二、工作目标

1. **确认基材状态：** 入厂 PE 达因值 ≤34 dyn/cm、水接触角 ≥90°，并排除隐匿电晕、爽滑剂析出和油污干扰。
2. **锁定测试方法：** 软质薄膜以胶带法（GB/T 13217.7）为主，硬质片材以划格法（GB/T 9286）为主，两者均配统一胶带、统一揭除角度与速度。
3. **在 80℃×20 min 窗口内达标：**
   - 划格法：**≤1 级**（目标 0 级）
   - 胶带法附着牢度：**≥90%**（目标 ≥95%）
   - 烘烤后 30 min、24 h、72 h 三次测试，防止“刚出炉合格、隔天掉漆”
4. **给出可量产的涂层路线：** 推荐“薄底涂 + 面涂”为主方案，内加附着树脂的单涂为备选，并完成与电晕对照样的对比。
5. **输出完整数据包：** 原料台账、工艺卡、原始记录、失效模式照片、结论与配方锁定建议。

## 三、工作范围与内容

### 3.1 范围内

| 项目 | 说明 |
|------|------|
| 基材 | 未电晕 LDPE / LLDPE / HDPE 薄膜或片材（默认吹膜 LDPE，标称厚度 50 μm） |
| 表面处理 | **禁止**电晕、火焰、等离子、氟化；仅允许溶剂擦拭清洁 |
| 涂布 | 实验室线棒/刮棒定量涂布；记录湿膜、干膜 |
| 烘烤 | 强制对流烘箱，**80±2℃，20 min**（从关门起计） |
| 测试 | 表面能确认、附着力（划格/胶带/剥离）、失效界面判定 |
| 配方筛选 | 底涂类型、底涂厚度、面涂体系、湿膜厚度 |

### 3.2 范围外

- 不评价电晕工艺窗口本身（仅做**阳性对照**）
- 不覆盖 UV/EB 固化、蒸镀、挤出复合（除非后续变更）
- 不替代第三方 CMA/CNAS 出具的正式检测报告（本方案为研发判定方法）

### 3.3 默认试样规格

| 参数 | 默认值 | 必须记录的偏差 |
|------|--------|----------------|
| 树脂 | 吹膜 LDPE | HDPE/LLDPE 须单列批次 |
| 厚度 | 50±5 μm（膜）或 1～2 mm（片） | 实测千分尺 5 点平均 |
| 爽滑剂 | **优先无开口剂/无油酰胺批次** | 有爽滑剂必须注明牌号与添加量 |
| 尺寸 | 涂布样 ≥150 mm × 200 mm；测试区 ≥100 mm × 100 mm | — |
| 数量 | 每配方每条件 **n≥3**，关键配方 n≥5 | — |

## 四、技术原理与工艺约束

### 4.1 未电晕 PE 为什么难附着

```
PE 本体  ──弱色散力──► 涂层
         无极性基团、无微氧化层、无可反应羟基
         涂料液滴收缩、针孔、缩孔 → 接触面积不足
         80℃ 远低于 PE 熔点（LDPE 约 105～115℃）
         → 不能指望“热熔互溶”，只能靠界面化学与极薄互扩散
```

### 4.2 80℃ × 20 min 的真实含义

| 约束 | 影响 | 对策 |
|------|------|------|
| 低于 PE 熔点 | 不能靠熔融咬合 | 用与 PE 相容的聚烯烃底涂，在 80℃ 软化铺展 |
| 时间短 | 厚膜水分/溶剂排不净 | 干膜目标 3～8 μm（薄膜包装）；厚涂须验证表干 |
| 刚烘完假性合格 | 残留溶剂增塑，胶带“粘不下来” | **强制 24 h 后再做正式判定** |
| 爽滑剂热迁移 | 烘后 24～72 h 界面被油酰胺覆盖 | 选无爽滑剂基材；三次时点测试 |
| 烘箱显示 ≠ 膜温 | 薄膜悬空时膜温可能只有 60～70℃ | 试样贴玻璃板，热电偶贴膜监控 |

### 4.3 附着机制（本方案只走这三条）

1. **聚烯烃相容锚定：** 氯化聚烯烃（CPO/CPE）、PE-g-MAH、EAA/EMAA 在界面与 PE 发生有限互扩散。
2. **极性反应锚定：** 酸酐、羧基、氨基与面漆中的羟基/异氰酸酯形成氢键或共价键。
3. **超薄极性底涂：** 聚乙烯亚胺（PEI）等，干膜极薄（<0.5 μm），靠静电/氢键，适合水性体系。

不采用：电晕、火焰、砂纸打毛（会改变本方案边界）。

## 五、推荐技术路线（达标方案）

### 5.1 主方案：薄底涂 + 面涂（优先锁定）

**工艺链：**

```
未电晕 PE → IPA 擦拭 → 干燥
    → 底涂（CPO 或水性聚烯烃分散体，干膜 0.5～2 μm）
    → 表干 5～10 min（室温）
    → 面涂（与底涂相容，MFFT ≤50℃ 或已加成膜助剂）
    → 80℃ × 20 min 强制对流
    → 室温冷却 ≥30 min
    → 23℃/50%RH 养护 24 h 后正式测附着力
```

**底涂三选一（按现场溶剂许可排序）：**

| 代号 | 体系 | 适用 | 建议固含 / 干膜 | 备注 |
|------|------|------|-----------------|------|
| P-A | 溶剂型 CPO（PE 相容型，Cl 约 20～30%） | 溶剂型面漆、油墨 | 5%～15% 固含，干膜 0.5～1.5 μm | 未电晕 PE 首选；甲苯/二甲苯体系需通风 |
| P-B | 水性改性聚烯烃分散体 | 水性面漆 | 按供应商建议稀释，干膜 1～2 μm | 环保路线；须确认 80℃ 能破乳成膜 |
| P-C | PEI 水溶液 0.1%～0.5% | 水性油墨/涂料 | 极薄，几乎无可见膜 | 操作窗口窄，擦拭均匀性要求高 |

**面涂要求：**

- 最低成膜温度（MFFT）**低于 50℃**，或用成膜助剂把有效成膜温度压到 80℃ 窗口内。
- 与底涂极性匹配：PU / 丙烯酸 / 氯化橡胶 / 硝化棉等均可，但必须先做底/面层间附着力。
- 默认湿膜：线棒 6#～12#（约 6～14 μm 湿膜），干膜 3～8 μm。

### 5.2 备选方案：单涂内加附着树脂

当面涂必须一次完成时：

- 在面涂中内加 **5%～15%**（按树脂固体计）CPO 或 PE-g-MAH / EAA。
- 仍执行 80℃×20 min；单涂更容易厚边、缩孔，须把湿膜和流平一起做 DOE。
- 单涂作为降本路线，**只有主方案达标后才允许对比导入**。

### 5.3 对照设计（必须同时做）

| 组别 | 基材 | 涂层 | 目的 |
|------|------|------|------|
| N0 | 未电晕 PE | 无底涂 + 面涂 | 负对照，证明问题在界面 |
| N1 | 未电晕 PE | 主方案底涂 + 面涂 | 主评价 |
| N2 | 未电晕 PE | 单涂内加附着树脂 | 备选评价 |
| P0 | 电晕 PE（达因 40～42） | 无底涂 + 同面涂 | 正对照，拆开“配方不行”还是“没电晕” |

判定逻辑：

- N0 差、P0 好、N1 好 → 底涂方案成立，可量产评估。
- N0 差、P0 也差 → 面涂自身成膜/内聚失败，先改面涂，再谈基材。
- N1 30 min 好、24 h 差 → 残留溶剂或爽滑剂迁移，改烘道或换基材牌号。

### 6.2 试验流程（标准作业，详见项目 SOP）

```
1. 基材鉴定（未电晕确认）
2. 清洁（IPA，单向擦，晾干）
3. 涂布（线棒，记录棒号、速度、环境温湿度）
4. 烘烤（预热烘箱 80℃ → 样贴玻璃板入炉 → 关上门计时 20 min）
5. 冷却 30 min → 快速筛（仅内部参考）
6. 标准养护 24 h（23±2℃，50±5%RH）→ 正式测试
7. 72 h 复测（防爽滑剂/增塑剂迁移）
8. 失效拍照 + 界面判定（附着破坏 / 内聚破坏 / 混合）
```

### 6.3 未电晕确认（否决项）

入厂或领用时 **三项同时满足** 才允许进入涂布：

| 检测 | 方法 | 未电晕判定 | 否决 |
|------|------|------------|------|
| 润湿张力 | GB/T 14216 / ASTM D2578 达因笔 | **≤34 dyn/cm**（液膜 2 s 内收缩成珠） | ≥38 dyn/cm 视为已处理或污染极性层 |
| 水接触角 | GB/T 30693，静滴，n=5 | **≥90°** | ＜85° 需复查是否电晕/氧化/残留表面活性剂 |
| 外观与台账 | 卷材标识、电晕痕迹、气味 | 无电晕标识、无处理条纹 | 标识为“电晕/表面处理”直接剔除 |

> 达因笔本身含表面活性剂，**测试区不得再用于涂布**。接触角样亦然。须在样边测试，涂布区单独裁切。

### 6.4 清洁（不可活化表面）

1. 无尘布蘸 **异丙醇（IPA）**，单向擦拭 2 遍，每遍换干净面。
2. 禁止水洗+碱性洗（易留表面活性剂，假性提高达因）。
3. 禁止火焰、电晕、等离子“补一枪”。
4. 擦后在洁净环境晾干 ≥5 min，1 h 内完成涂布，防止落尘和添加剂析出。

### 6.5 涂布

| 项目 | 规定 |
|------|------|
| 工具 | 线棒 6# / 9# / 12#；同一 DOE 只用同一支棒 |
| 速度 | 手刮约 3～5 cm/s，一次过，不来回 |
| 环境 | 23±2℃，50±10%RH；记录实际值 |
| 底涂 | 尽量薄而匀；可见流挂、厚边作废 |
| 面涂 | 底涂表干后再涂；间隔默认 5～10 min |
| 膜厚 | 干膜用测厚仪或克重法；薄膜可用同一棒号+固含估算 |

### 6.6 烘烤（本方案的硬窗口）

| 项目 | 规定 |
|------|------|
| 设备 | 强制对流烘箱，空载校准 80±2℃ |
| 装样 | 涂层面朝上，四角胶带固定在 **洁净玻璃板** 上，禁止悬空 |
| 膜温 | 同炉放一片贴热电偶的陪试样；入炉 5 min 内膜面应 ≥75℃ |
| 计时 | **关门瞬间起算 20 min**；中途不得开门 |
| 装载 | 单层，板间距保证风道，禁止叠放 |
| 出炉 | 连玻璃板取出，室温冷却 ≥30 min 后再揭样或裁样 |
| 异常 | 膜温 5 min 内到不了 75℃ → 该炉数据作废，先修烘箱/装载 |

烘箱温度均匀性建议事先九点法确认，边角与中心差 >3℃ 时只使用中心区。

### 6.7 附着力测试方法

按基材形态选择主方法，另一方法作为辅证。

#### （1）软质薄膜（默认）：胶带附着牢度

- 依据：**GB/T 13217.7-2023**《油墨附着力检验方法》（手工剥离法为主，有圆盘剥离仪则加做）。
- 胶带：固定牌号，推荐 **3M 610** 或标准规定的 25 mm 透明胶带；**全项目不得换胶带批次混用**（新批次先与旧批次做桥接）。
- 贴合：无气泡，辊压 3 次，放置 **5 min**。
- 揭除：约 **180°**，匀速，0.6～1.0 m/s 量级（手工则同一人、同一手法）。
- 计算：毫米格纸统计涂层被揭面积。

\[
\text{附着牢度}(\%) = \frac{\text{涂层残留格数}}{\text{涂层原有格数}} \times 100
\]

#### （2）硬质片 / 较厚涂层：划格法

- 依据：**GB/T 9286-2021 / ISO 2409:2020**。
- 干膜 ≤60 μm：间距 **1 mm**；60～120 μm：2 mm；更厚不推荐本方案窗口。
- 切透至基材，6×6 格；软质 PE 片用锋利新刀片，避免基材被拽起。
- 胶带贴合后 5 min，按标准角度揭除。
- 评级 0～5 级（0 最好）。

**GB/T 9286 评级摘要：**

| 级 | 脱落面积 | 现象 |
|----|----------|------|
| 0 | 0 | 切口完全平滑 |
| 1 | ＜5% | 交叉点少量碎屑 |
| 2 | 5%～15% | 切口边缘/交叉处剥落 |
| 3 | 15%～35% | 沿切口大片或整格少量脱落 |
| 4 | 35%～65% | 大片脱落 |
| 5 | ＞65% | 严重脱落 |

#### （3）失效模式（必须写，否则等级无意义）

| 代码 | 模式 | 含义 | 下一步 |
|------|------|------|--------|
| A | 界面破坏（PE/涂层） | 未电晕典型失败 | 换底涂或加附着树脂 |
| C | 涂层内聚破坏 | 膜没干透或树脂偏软 | 降膜厚、核对着膜、改面涂 |
| T | 胶带胶转移 | 胶带不合适或涂层发黏 | 换胶带或延长养护 |
| M | 混合破坏 | 局部锚定成功 | 提高底涂均匀性 |
| I | 底/面层间破坏 | 底涂与面涂不相容 | 换面涂或延长底涂表干 |

### 6.8 时点与养护

| 时点 | 用途 | 是否作为验收 |
|------|------|--------------|
| 出炉冷却 30 min | 快速筛选 | **否**，仅内部 |
| 23℃/50%RH **24 h** | 正式判定 | **是** |
| **72 h** | 迁移/回黏复查 | 关键配方 **是** |

### 6.9 筛选 DOE（第三阶段）

固定：未电晕 LDPE、80℃×20 min、同一面涂批次。

| 因子 | 水平 |
|------|------|
| 底涂 | 无 / P-A / P-B / P-C |
| 底涂干膜 | 0.5 μm / 1.5 μm（P-C 仅浓度 0.1% vs 0.5%） |
| 面涂湿膜 | 6# 棒 / 12# 棒 |

每格 n=3。先看 24 h 胶带牢度与划格，再对 Top 2 做 72 h 和正对照 P0。

### 6.10 具体措施

1. **先证伪电晕，再谈配方。** 达因和接触角不过，整批数据作废。
2. **薄膜必须贴板烘。** 悬空烘烤导致膜温不足，是最常见的假失败。
3. **胶带牌号锁死。** 附着力测试的灵敏度往往被胶带黏性淹没。
4. **24 h 才验收。** 80℃ 短烘容易留下溶剂，30 min 数据只用于淘汰极端失败。
5. **拍照留证。** 每张样测试前后各拍，划格网格与胶带揭后并排存档。
6. **N0/P0 永不省略。** 没有对照就不能写“未电晕 PE 已解决”。

## 十一、判定标准与预期成果

### 11.1 验收标准（24 h 正式数据）

| 项目 | 合格 | 目标 | 不合格即停 |
|------|------|------|------------|
| 未电晕确认 | 达因 ≤34 且水接触角 ≥90° | 达因 30～32 | 达因 ≥38 |
| 划格（片材） | ≤1 级 | 0 级 | ≥3 级 |
| 胶带牢度（薄膜） | ≥90% | ≥95% | ＜80% |
| 72 h 相对 24 h | 下降 ≤5 个百分点，划格不降级 | 不下降 | 下降 ＞10 个百分点 |
| 失效模式 | 允许轻微 C/M | 以内聚或无破坏为主 | 大面积 A（界面光秃 PE） |
| 对照 | N1 显著优于 N0；P0 用于解释 | N1 ≈ P0 | N1≈N0 且 P0 很好（底涂无效） |

快速筛（30 min）仅用于扔掉完全没附着的配方，**不得写入合格结论**。

### 11.2 预期成果

1. 一份可执行的《未电晕 PE + 80℃×20 min》标准作业程序（见项目目录 SOP）。
2. 至少 **1 条主方案**（底涂+面涂）达到 11.1；争取 1 条单涂备选。
3. 完整原始记录、照片和失效分类，可直接转入量产工艺卡。
4. 明确告知业务侧：未电晕 PE 的附着来自化学底涂，不是来自烘烤把 PE 烤化；80℃ 只负责把底涂/面涂烘干成膜。

### 11.3 结论表述模板（收尾时填写）

> 在未电晕 PE（批次____，达因____ dyn/cm，水接触角____°）上，采用 ____ 底涂（干膜 ____ μm）+ ____ 面涂（干膜 ____ μm），80±2℃ × 20 min 贴板烘烤，23℃/50%RH 养护 24 h 后：划格 ____ 级，胶带附着牢度 ____%。72 h 复测 ____。对照 N0 为 ____，P0 为 ____。结论：____（通过 / 有条件通过 / 不通过）。

## 十二、与量产衔接的注意点

1. **实验室线棒 ≠ 凹印/柔印/辊涂。** 锁定配方后须用目标涂布方式复验湿膜和剪切。
2. **烘道停留时间**按膜温积分等效，不能只抄“显示 80℃、走 20 min”。
3. 溶剂型 CPO 上机前做残留溶剂和气味评估。
4. 复合、热封、耐摩擦是下一份方案，不在本次附着力验收内，但主配方样应留样。
