# 工作方案

**方案名称：** TPU 上涂布、烘干后再流延 TPE 的粘合方案  
**编制人：** 张忠诚  
**所属部门：** 技术/实验室  
**编制日期：** 2026-09-05  
**文档版本：** V1.8  
**实际结构（以本次说明为准）：**

```
流延 TPE
   ↑ 热熔贴合
涂层（涂在 TPU 上，80℃ 烘烤干燥）
   ↑
TPU 基材
```

**更正：** 此前按“未电晕 PE 上涂布再流延”写的评估作废于本工艺。PE 免电晕方案仍可用于别的 PE 基材项目，**不套在这条 TPU 线上。**

---

## 一句话结论

TPU 和常见流延 TPE（SEBS / SBS / TPO）本来就不亲：一边是氨基甲酸酯极性表面，一边是聚烯烃/苯乙烯弹性体。涂层的任务是当 **双面粘结层**——下咬 TPU，上被 TPE 熔体焊住。

- **能粘住的做法：** 热塑性、超薄、两亲。你现在的 **马来酸酐改性 CPO** 方向对：酸酐咬 TPU，CPO 链给 TPE 焊。酚醛只加在这层涂层里，不加进 TPE。
- **容易失败：** 只涂普通 CPO（偏 TPE、亏 TPU）、只涂纯 PU 漆（偏 TPU、亏 TPE）、2K 交联后再流延、涂层未干、TPU 上有硅油隔离剂、**TPE 里加芥酸酰胺（0.1% 也会爬界面）**。
- 胶带揭涂层 ≠ 复合牢度。以流延后 **180° 剥离 + 失效面** 为准。

---

## 一、两道界面分别怕什么

| 界面 | 材料矛盾 | 涂层该提供什么 | 典型失败长什么样 |
|------|----------|----------------|------------------|
| TPU / 涂层 | TPU 极性高，表面能约 40～45 mN/m，一般**不必电晕** | 羧基、酸酐、氨基甲酸酯、氢键 | 整层连涂层从 TPU 上揭起，TPU 面发亮 |
| 涂层 / TPE | SEBS/TPO 偏非极性，只认聚烯烃链 | 热塑性聚烯烃链，能被熔体再软化 | 涂层留在 TPU 上，TPE 面发亮 |

TPU 本身比未电晕 PE 好涂得多。这条线的难点几乎总是 **上面那道：涂层和 TPE 焊不焊得住**，除非 TPU 带隔离剂或涂层完全不亲 TPU。

80℃ 烘烤：只负责把溶剂/水赶尽，让膜能进流延机。真正的上界面焊接靠 TPE 熔体温度（常见 160～230℃）把热塑性粘结层再熔一次。

---

## 二、粘结层怎么选（按效力）

### 2.1 现用涂层：马来酸酐改性 CPO（酚醛只加在涂层里）

你的料就是 **MAH 改性 CPO**，涂在 TPU 上，80℃ 烘干，再流延 TPE。酸酐咬 TPU，CPO 链给 TPE 焊，方向对。酚醛是这个涂层里的添加剂，**不是 TPE 配方**。EAA 共混只做平行对照，不要求你改过去才能开工。

| 项目 | 规定 |
|------|------|
| 主体 | 马来酸酐改性 CPO |
| 酚醛 | 仅在涂层中，影响见 2.4 |
| 干膜 | **0.5～1.5 μm** |
| 烘烤 | 80±2℃ × 20 min，烘后须仍能热软（未交联） |
| 之后 | 直接流延 TPE |

### 2.2 备选 T-U：TPU 侧更稳

羟基或热塑性聚氨酯底涂（和基材 TPU 同族）+ **内加 8%～12% 酸改性 CPO 或聚烯烃分散体**。  
TPU/涂层界面通常优于 T-D；TPE 侧略弱于“CPO 更多”的 T-D。TPU 基材难粘、隔离剂洗不净时用。

### 2.3 不要用的

| 做法 | 结果 |
|------|------|
| 纯 PE 型 CPO、很少羧基 | TPE 尚可，**TPU 上容易整层揭** |
| 纯 2K PU / 丙烯酸交联面漆 | TPU 很牢，**TPE 焊不住** |
| 硅烷、环氧当主膜 | 偏金属逻辑，对 TPE 无益 |
| 底涂刮厚 | 内聚先裂，两边都掉 |
| TPU 不清洗就涂 | 硅油/蜡一烘上浮，TPU 界面必挂 |
| 热固酚醛 + 固化剂当主膜 | 流延温度下交联，TPE 焊不住（同 2K 面漆） |

### 2.4 在「马来酸酐改性 CPO」涂层里加酚醛，影响是什么

问的是 **涂层配方**，不是往 TPE 里加。主体已经是 MAH-CPO，酚醛是往这层超薄膜里再加的第三组分。

MAH-CPO 自己已经两亲。酚醛加上去，是在改这层膜的极性、内聚和“流延时还会不会再熔化”。

| 位置 | 只涂 MAH-CPO | 涂层里再加酚醛 |
|------|----------------|----------------|
| TPU / 涂层 | 酸酐已经够用 | **多数时候 TPU 侧再稳一点**（酚羟基补氢键）。TPU 难粘、有残留时才看得出 |
| 涂层 / TPE | CPO 链被熔体再软、焊住 | **这是风险点。** 酚醛把膜拉得更极、更硬；烷基/萜烯酚醛作增黏还可能提高初黏，普通 PF 或一交联就把 TPE 焊死 |
| 涂层自己 | 本来就薄、内聚一般 | 线性酚醛常让膜更脆，划格/剥离变成 **涂层内聚裂**（两边都像掉，其实膜自己碎了） |
| 与 CPO 混溶 | — | 部分相容。薄层里可能分相：酚醛偏 TPU、CPO 偏 TPE（有时碰巧好），或中间一条弱缝（反而差） |
| CPO 的氯 | — | 酚醛 + 热 + 残酸，容易 **变黄、放 HCl、膜发脆**，流延 160～230℃ 比 80℃ 烘干更明显 |
| 芥酸酰胺 | 不解决 | **照样不解决。** 酰胺在 TPE 里，涂层加酚醛消灭不了熔体表面那层油 |

**80℃ 烘干 vs 流延热：**

- 80℃×20 min：多数酚醛还来不及和 MAH 酯化/交联，膜往往仍热塑。  
- TPE 熔体 160～230℃：酚醛的酚羟基会和 CPO 上的酸酐往前走。**热固酚醛或加了六次甲基四胺的，流延这一下就变成半交联皮，TPE 焊不住。**  
- 所以：烘干后用溶剂轻擦或热烫，膜还应能回黏；流延后若 TPE 面发亮、涂层留在 TPU 上，先怀疑酚醛在流延时交联了。

**哪种酚醛可以留在涂层里：**

| 类型 | 在 MAH-CPO 涂层里 |
|------|-------------------|
| 烷基酚醛、萜烯酚醛（增黏，基本不交联） | 可以试，**固体 5%～10%**，先对比 0% |
| 普通 PF 线性酚醛，量 >15% | 膜脆、TPE 侧变差，不建议 |
| 热固酚醛 / 加固化剂 | 去掉。和“交联面漆再流延”是同一类失败 |

**单变量怎么验（不要和改 TPE 混在一起）：**

同一 MAH-CPO、同一干膜、同一 TPU、同一流延：

| 代号 | 涂层 |
|------|------|
| C0 | **MAH-CPO，0% 酚醛** |
| C1 | MAH-CPO + 你现在的酚醛（写出牌号和固体%） |
| C2 | MAH-CPO + 同类型酚醛，固体减半 |
| C3 | 仅当 C1 的 TPE 侧差：C0 再流延确认是酚醛在挡焊 |

看失效面，不要只看一个剥离数：

- 亮 TPU 变少、TPE 仍焊得住 → 酚醛在帮 TPU 侧，可留。  
- 亮 TPE、涂层粘在 TPU 上 → 酚醛挡了焊接或流延时交联了，减量或去掉。  
- 涂层碎、两边都沾一点 → 酚醛把膜弄脆了，减量。  
- C0 和 C1 在 0.1% 酰胺料上都差、无酰胺料都好 → 瓶颈是酰胺，不是酚醛。

一句话：在 **MAH-CPO 涂层里** 加酚醛，主要是赌 TPU 侧更牢；TPE 侧和酰胺不要靠它。先做 C0（不加酚醛）对照，比继续往涂层里加更重要。

## 三、粘合力预期（流延后）

未给 TPE 牌号前只谈机制，不报牛顿数。

| 流延 TPE | T-D 粘结层 | 交联面漆后再流延 |
|----------|------------|------------------|
| TPO / TPV | 较好～好 | 差～中 |
| SBS | 中～较好 | 差 |
| 充油 SEBS（最常见“TPE”） | 中，看油和接枝 | 差 |
| TPU（流延也是 TPU） | 较好（可考虑减 CPO、加厚 EAA，或直接热贴） | 中（极性对极性，但交联仍不如热焊） |
| TPE-E | 中（EAA 高一些更好） | 中 |

“好”：剥离时常把 TPE 或 TPU 拉变形，界面不分开。  
“中”：能复合，剥离数值一般，对熔温/线速敏感。  
“差”：大面积光板分离。

TPU 上直接流延非极性 TPE、**不涂粘结层**，多数会差——这正是你要涂层的原因。

## 四、TPU 怎么处理（一般免电晕）

1. 确认是酯型还是醚型 TPU，有无爽滑、抗粘、硅油。  
2. IPA 或 TPU 允许的溶剂单向擦；有隔离剂先中性清洗再 IPA，水要烘干。  
3. **TPU 通常不必电晕。** 电晕有时反而伤表面、引入低分子。只有达因明显偏低或油污洗不掉时再试弱电晕，并单独做对照。  
4. 涂布后 1 h 内进烘箱；烘透后尽快流延，减少助剂再析出。  
5. 流延辊温、气隙、贴压要记：同一粘结层，工艺可以让剥离翻倍或腰斩。  
6. TPU 片比 PE 耐温好，仍要防烫皱、防拉伸变薄。

## 五、怎么测

| 顺序 | 测什么 | 方法 | 算不算数 |
|------|--------|------|----------|
| 流延前 | 涂层是否咬住 TPU | 胶带或划格 | 过程检。TPU 上不合格不要去流延 |
| 流延后主数据 | 复合牢度 | 180° 剥离，15 mm 宽，GB/T 8808 / GB/T 2791 | **验收** |
| 必须写 | 失效面 | TPU 光 / 涂层内聚 / TPE 光 / 材料拉伸破坏 | 决定改哪一侧 |
| 后期 | 充油 TPE | 24 h + 72 h 或 70℃×24 h 再剥 | 防隔天掉 |

对照（同卷 TPU、同一流延条件）：

1. TPU **不涂** 直接流延 TPE（基线）  
2. T-D 烘透后流延  
3. T-U 烘透后流延  
4. 故意上交联面漆再流延（证明面漆会挡）

| 失效 | 改 |
|------|----|
| TPU 面光、涂层跟着 TPE 走 | 提高 EAA/酸改性，或改 T-U；查隔离剂 |
| TPE 面光、涂层留在 TPU | 提高 CPO 或 TPE 加接枝料；提高熔温/贴压；确认涂层是热塑性 |
| 涂层从中间裂 | 减干膜，加 EAA |
| 气泡针孔 | 没烘透 |
| TPE 拉丝、层不分开 | 界面已够 |
| 当时牢、24～72 h 或 70℃ 后再剥变差，TPE 侧发滑 | 芥酸酰胺/油析出，见第六节 |

## 六、TPE 里 0.1% 芥酸酰胺（介酸酰胺）会不会影响粘合

**会，而且正好打在涂层 / TPE 这一面。**  
0.1%（约 1000 ppm）是薄膜常用爽滑量，不算高剂量，但已经够在熔体表面铺出弱边界层。不必先到 0.3% 才开始担心。

### 6.1 它怎么破坏焊接

芥酸酰胺和 TPE 本体不相容，会往自由表面爬。流延时，贴到粘结层上的那一面熔体也是“表面”：

```
TPE 本体（酰胺还在往外赶）
    ↓ 熔体贴合
弱边界层：芥酸酰胺单分子～多分子膜   ← 0.1% 就够铺满
    ↓
超薄粘结层（0.5～1.5 μm，挡不住、也吃不掉这些酰胺）
    ↓
TPU
```

- **TPU / 涂层：** 酰胺在 TPE 里，一般不直接毁这一面。  
- **涂层 / TPE：** 酰胺降低熔体表面能，挡住 CPO 链和 TPE 互扩散。超薄粘结层没有厚度去“吞”这层油。  
- **芥酸酰胺比油酸酰胺爬得慢。** 当时剥离往往还过得去，**24 h、72 h 或 70℃ 后再掉**——这是它的典型指纹。热流延会加速后期析出。  
- TPE 若再充油，油 + 酰胺一起爬，比单加 0.1% 更狠。

### 6.1a 流延当时，酰胺是不是已经浮在 TPE 表面？

**是，贴合前就已经在表面上，不是等冷却后才开始往上爬。** 冷却后再析出是第二波，会让粘合再差一截。

两件事不要混：

| | 流延当时（熔体） | 下机以后（固体） |
|--|------------------|------------------|
| 酰胺在哪 | 已经富集在熔体/空气界面 | 继续从本体爬到界面、也爬到空气面 |
| 形态 | 热的油状液膜，分子级～很薄的一层 | 逐渐结晶成看得见的“粉/蜡”爽滑层 |
| 要多久 | 模口一出来就有；气隙里再富集，常见几十到几百毫秒 | 小时～几天（芥酸酰胺偏慢） |
| 对粘合 | 贴到涂层上的那一面已经隔着一层润滑剂 | 当时能粘的，隔天还可能再掉 |

流延时贴涂层的那一面，在进贴辊之前是**自由表面**（熔帘下表面对着空气），酰胺一样会往这里走：

```
模头     气隙（熔帘下表面 = 即将贴涂层的面）     贴辊
 │                │                              │
 模唇上已有酰胺 ──► 熔体表面继续富集 ──────────► 带着这层酰胺压上粘结层
 （它本身就是加工润滑剂，会润湿金属模唇再转到膜面）
```

0.1% 相对整层 TPE 很少，但铺满一层界面只需要大约 1～3 mg/m²。以 0.1 mm 厚的 TPE、密度按 1 计，0.1% 大约是 100 mg/m² 量级，**只要百分之几的酰胺赶到表面，就已经够铺满**。不需要“全部浮上来”。

所以：

- 问“流延时会不会已经浮在表面”→ **会，而且贴合面和空气面两边都会有。**  
- 问“是不是只有冷却后才影响”→ **不是。** 第一刀发生在热贴合瞬间；第二刀是冷却后继续爬，表现为 24～72 h 再掉。  
- 气隙越长、模温越高、酰胺越容易在模唇积一层，贴合面上的酰胺就越多。缩短气隙只能减少“气隙里新富集的那一部分”，**减不掉模口带出来的那一层**。  
- 因此共挤时贴合层不加酰胺，比“整层都加 0.1%、再靠短气隙”可靠。

### 6.2 0.1% 严重不严重

| 判断 | 说明 |
|------|------|
| 不是“加了就一定开胶” | 热熔、贴辊压力可以把一部分酰胺挤开，当时能粘 |
| 也不是“0.1% 可以忽略” | 界面只要铺满一层，剥离就按弱边界走，与本体含量不是线性 |
| 最危险的表现 | 下机合格，隔天或热老化后剥离下降、TPE 侧发滑 |
| 气隙越长越差 | 熔帘在空气里多待一会，贴合面酰胺更富集 |

### 6.3 必须做的对照（比再调树脂比更要紧）

同一台流延、同一粘结层、同一熔温：

| 组别 | TPE |
|------|------|
| R0 | **不含**芥酸酰胺（其他相同） |
| R1 | **0.1%** 芥酸酰胺（你现在的料） |
| 可选 R2 | 0.05%，看是否够爽滑又少掉剥离 |

每组：下机 2 h、24 h、72 h 各剥一次；有条件加 70℃×24 h。  
R1 比 R0 掉 **>20%**，或失效面变成 TPE 光亮发滑 → 0.1% 已构成粘合问题。

### 6.4 如何精确克服（酰胺已在熔体表面）

原则只有一句：**把芥酸酰胺从贴合面拿掉，不要用底涂去和它抢界面。**  
模口带出来的那一层，短气隙减不干净；涂层加厚也吞不掉。

#### 上策：共挤，酰胺和贴合面物理分开

```
空气面皮层   TPE + 0.1% 芥酸酰胺     ← 只在这里爽滑、离型
芯层         原 TPE（可含油，仍尽量无酰胺）
贴合皮层     无酰胺 TPE，建议加 5%～15% SEBS-g-MAH 或 PE-g-MAH
                ↓ 贴到
            TPU 上的超薄粘结层
```

规定（写进工艺卡，才能叫“精确”）：

| 项 | 规定 |
|----|------|
| 贴合皮层酰胺 | **配方目标 0，进料抽检不得检出芥酸酰胺**（或 ≤50 ppm） |
| 贴合皮层厚度 | 先定 **15～25 μm**（太薄，芯层酰胺会在 24～72 h 反扩散上来；太厚浪费） |
| 空气面皮层 | 0.1% 酰胺放这里，厚度按爽滑需要，一般 10～20 μm |
| 模头 | 贴合层走贴 TPU 的那一侧流道；换料后吹扫到贴合面 ATR 无酰胺羰基 |
| 粘结层 | 仍是热塑性酸改性 CPO+EAA，超薄，**不要为此加厚** |

单层流延、整料都加 0.1%，再靠调气隙——**不算克服，只是减轻。**

#### 只能单层时（权宜，按效力排）

1. **贴合用料去掉酰胺**，爽滑改到后道：TPE 空气面在线涂微量爽滑，或复合后再覆离型膜。粘合和离型不要放在同一层里解决。  
2. 必须留酰胺：先试 **0.05%**，R0/R1/R2 三组剥 24 h、72 h，用数据决定，不要口头说“0.1% 应该没事”。  
3. 工艺只能动“气隙新富集”那一部分：气隙尽量短、贴辊压提高、模唇定时清理（酰胺会在模唇积一层再转到膜面）。**不要指望单靠这些打平 R0。**  
4. 贴合料加接枝（MAH）只能提高“挤开弱层、焊住”的能力，**不能消灭表面酰胺**。

#### 明确不要做的

| 动作 | 为什么不是克服 |
|------|----------------|
| 加厚粘结层 | 内聚先裂，酰胺还在界面 |
| 改成交联面漆 | TPE 更焊不住 |
| 只看下机剥离 | 第二波析出没验 |
| 电晕 TPE 熔体 | 线上做不到，也解决不了模唇转出的酰胺 |
| 把酰胺换成“同量油酸酰胺” | 往往当时更差（爬得更快） |
| 用酚醛去“吃掉”酰胺 | 不消灭弱边界，热固型还会挡 TPE 焊接 |

#### 怎样才算已经克服（验收，不要凭感觉）

同一粘结层、同一机台：

| 样 | 24 h 剥离 | 72 h 或 70℃×24 h | 贴合面 ATR / 失效面 |
|----|-----------|-------------------|---------------------|
| R0 无酰胺 | 基准 | 不掉或掉很少 | 无酰胺羰基（约 1640 cm⁻¹） |
| 共挤（贴合层无酰胺） | 达到 R0 的 **≥90%** | 相对 24 h 再掉 **≤10%** | 贴合面无明显酰胺峰 |
| 单层 0.1% | 作对照，不作为合格工艺 | 常明显再掉 | TPE 侧常有酰胺峰 |

失效面用白布轻擦发滑、水膜不连续，也按酰胺残留计。  
共挤样若 72 h 仍掉、ATR 又出酰胺峰：贴合皮层太薄，芯层在反扩，加厚贴合层到 25～40 μm 再验一轮。

### 6.5 芥酸酰胺和油酸酰胺有何不同（同量 0.1%）

两者都是脂肪酰胺爽滑/离型剂，都会铺在贴合面。**差别在碳链长短和爬出来的速度，不在“一个伤粘合、一个不伤”。**

| | 芥酸酰胺（芥酸 / 介酸酰胺） | 油酸酰胺 |
|--|---------------------------|----------|
| 分子 | C22，一个双键，分子量约 337 | C18，一个双键，分子量约 281 |
| 熔点 | 约 75～80℃ | 约 70～75℃，略低 |
| 在 TPE 里怎么走 | 链更长，扩散慢 | 更小、更活，扩散快 |
| 流延当时（第一刀） | 模唇+气隙已有表面层，但铺满得相对慢 | **同浓度下分子个数更多，气隙里更快铺满**，热贴合时弱边界往往更完整 |
| 冷却以后（第二刀） | 慢，高峰常在 **1～3 天**，一旦爬满更耐久 | 快，高峰常在 **数小时～1 天**，表面层也更容易再被蹭掉、抽走 |
| 爽滑手感 | 来得晚、维持久 | 来得早、后期可能回升摩擦系数 |
| 对你这条线 | 典型：下机尚可，隔天掉 | 典型：下机剥离就比芥酸酰胺差一截 |

同是 0.1%（质量分数）：油酸酰胺摩尔浓度大约高 **20%**，再加上爬得快，贴合瞬间界面上的酰胺往往 **更多**。所以“换成同量油酸酰胺”不是克服，常常是把第一刀打得更狠。

若有人说油酸酰胺“更好”，多半是在说 **爽滑出得快**，不是说粘合更好。

还要离型、又少伤贴合，不该在这两种主链酰胺里对调，而应：

- 贴合层不加酰胺（共挤，见 6.4）；或  
- 改偏内部润滑、少析到表面的类型（如 EBS 一类双酰胺，仍要做剥离对照，不保证）。

### 6.6 预制片 + 酒精擦拭验证（你提的测法）

**可以做，而且值得做。** 它回答的是：表面那层芥酸酰胺是不是在拖后腿。  
**不能代替流延验收。** 预制片擦的是固体表面；流延时贴合面是热熔体，模唇还会再转出一层酰胺。擦拭提高了，只能证明机理，不能证明量产已经克服。

#### 这组实验能读出什么

| 结果 | 含义 |
|------|------|
| 擦后立刻热贴，剥离明显高于不擦 | 仅当 **TPE 未再预热** 时成立；表面酰胺确是弱边界 |
| 擦完再预热 TPE，提高消失 | 预热把酰胺赶回表面，擦拭作废（你指出的这一点） |
| 擦后立刻贴有提高，但仍远低于无酰胺料 | 没擦净，或贴合传热已让本体酰胺回补，或还有充油 |
| 擦和不擦差不多 | 没擦掉 / TPE 预热过 / 贴合传热已够赶回酰胺 / 瓶颈不在酰胺 |
| 擦完放 24 h 再贴，提高消失 | 酰胺从本体重新析出（预期中） |
| 无酰胺料一擦，剥离反而变 | 酒精把油/小分子也抽走了，擦拭本身有干扰，解释 0.1% 组时要扣掉这个 |

#### 操作（按这个做，数据才可比）

**1. TPE 预制片**

- 同一锅 0.1% 芥酸酰胺料，压片或预流延成片，厚度锁定（建议 **0.8～1.2 mm**），两面离型膜要无硅或先确认不污染。
- 制成后 **23℃ 放置 24 h**，让固体析出走完一轮，再分组。另留“刚下片、未放 24 h”各 1 组可作附录，不和主数据混。
- 有无酰胺料时，用同样厚度、同样热历史做对照片。

**2. 酒精怎么擦**

- 用 **异丙醇（IPA）** 最好；无水乙醇其次。不要用 75% 医用酒精（水会留下、还可能把表面弄花）。
- 无尘布蘸湿不滴，**单向擦 3 遍，每遍换干净面**，力道一致，擦贴合面整面。
- 擦完晾 **2～3 min**（看不见湿迹），**5～10 min 内必须热贴**。超时作废重擦。
- 擦完用 ATR 抽检：酰胺羰基（约 1640 cm⁻¹）应明显下降；水膜能短暂铺开。抽检过的位置不要用于剥离。

**3. 对面：TPU + 涂层**

- 与量产相同：TPU 上涂 T-D，80℃×20 min 烘透。不要在 TPE 上涂。

**4. 怎么贴（实验室代替流延）**

流延机若能“预制片当贴合层热覆”最好，条件对齐量产熔温。没有流延机时用热压，全项目锁死同一套参数，例如：

| 项 | 建议起点（按你的 TPE 再改，但改了要全表重做） |
|----|-----------------------------------------------|
| 温度 | 贴合面 **160～180℃**（接近流延、低于明显降解） |
| 压力 | 0.3～0.5 MPa |
| 时间 | 15 s（从加压算） |
| 冷却 | 保压冷到不黏再揭 |

热压会把片内酰胺往界面赶，所以“擦了立刻贴”仍可能不如真的无酰胺料——这是本试验的上限，要在结论里写明。

#### 6.6a 预热会把酰胺再赶到表面（你指出的这一点）

**对。擦完再把 TPE 预热，酰胺会在几秒到几十秒内重新铺满贴合面，等于白擦。**

室温下芥酸酰胺爬一天；预热到 80℃ 是分钟级；到流延/热贴的 160～180℃，扩散比室温快几个数量级，**预热保温的那一段时间就够重新铺满一层**。本体 0.1% 还在片子里，表面擦掉的那一点点立刻被补上。

因此：

| 顺序 | 有效吗 |
|------|--------|
| 擦 TPE → **再预热 TPE** → 贴合 | **无效。** 预热把机理验证毁掉了 |
| 擦 TPE → 室温放久 → 贴合 | 无效（慢爬回来，即 W2） |
| 先预热 TPE → 冷却到可擦 → 再擦 → 立刻贴 | 只去掉“预热当时赶到表面”的那一层；贴合再加热仍会补一点 |
| 擦 TPE → **只加热 TPU/涂层侧**，TPE 不单独预热，落下就压 | **擦拭组里唯一比较干净的做法** |
| 不擦，用无酰胺料 vs 0.1% 料，**预热完全相同** | **回答“预热条件下酰胺有没有害”的主试验** |

酒精不要擦热片：IPA 闪点低，有着火风险。预热过的 TPE 先冷到表面 **<40℃** 再擦。

**热从哪边来（锁死，写进记录）：**

```
推荐（擦拭组）：热板只烘 TPU+涂层
                TPE 擦净、不预热，对齐就压
                界面热靠接触传导，TPE 本体来不及把酰胺大举赶到表面

不要（擦拭组）：TPE 先在热板上预热 30～60 s 再贴
```

贴合要热，热量走 TPU 侧：涂层先软，再烫到 TPE 表面一层。TPE 心部温度低，反扩比“整片预热”慢一个数量级。仍会有一点界面升温，所以擦拭组的上限还是低于无酰胺料——结论里写明。

#### 必做组别（同一批涂层 TPU）

**主试验（不靠擦拭，预热可以相同）：**

| 代号 | TPE | 预热 | 目的 |
|------|-----|------|------|
| H0 | 无酰胺 | 与量产相同（可预热 TPE） | 预热条件下的上限 |
| H1 | 0.1% 酰胺 | **与 H0 完全同一预热** | 预热 + 酰胺的真实差距 |

H1 明显低于 H0 → 预热也挡不住，0.1% 就是问题。这比擦拭更接近流延。

**擦拭辅试验（TPE 禁止单独预热）：**

| 代号 | TPE | 表面 | 热怎么加 |
|------|-----|------|----------|
| W0 | 0.1% 酰胺 | 不擦 | 只热 TPU 侧，TPE 不预热 |
| W1 | 0.1% 酰胺 | IPA 擦 3 遍，5～10 min 内压 | **只热 TPU 侧** |
| W2 | 0.1% 酰胺 | 擦后养 24 h | 只热 TPU 侧 |
| W1x | 0.1% 酰胺 | 先擦再 **预热 TPE** 后贴 | 故意做坏，证明预热会冲掉擦拭效果 |
| W3 / W4 | 无酰胺 | 不擦 / 擦 | 只热 TPU 侧，看酒精干扰 |

每组 n≥3。剥离：2 h、24 h、72 h。

记录表见 `项目/进行中/PE基材附着力测试_2026/试验记录表.md` 表 F。

#### 判定（先看这个，再写“可以提高”）

**先看 H0 / H1（主结论）：**

- H1 比 H0 低 ≥20%，或 TPE 侧发滑 → 预热条件下酰胺仍在害粘合；量产按 6.4 共挤，不要指望擦拭。

**再看擦拭（只解释机理）：**

- **W1 比 W0 高，W1x 掉回 W0 附近** → 你说得对：擦有用，但 TPE 一预热就前功尽弃。  
- **W1 比 W0 提高 ≥20%，且 W2 回落** → 冷表面酰胺能被酒精去掉；量产熔体擦不了。  
- **W1 ≈ W0**（且热只来自 TPU）→ 没擦净，或接触传热已经够把酰胺赶回界面。  
- **W4 明显低于 W3** → 酒精抽油，W1 要打折扣。

结论里必须写：**预热 TPE 会使擦拭作废；预制片擦拭 ≠ 流延。** 量产克服仍按 6.4。
