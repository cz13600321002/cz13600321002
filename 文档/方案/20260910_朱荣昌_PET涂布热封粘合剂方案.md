## 一、背景与目的

客户朱荣昌要一种涂在 PET 上的热封粘合剂，热封**裸 PET** 杯子，作**可揭奶茶盖**。工艺窗：网纹辊；烘烤 90℃、20–30 秒；热封 **180–220℃ / 0.4 MPa / 1.5 秒**；不反粘、气味小，最好水性。拉力客户没给数字，但要可揭。

V1.0 按「偏永久、≥6 N/15 mm」写的，已作废作主推。V1.1 改成可揭：盖膜抓牢、杯口可控剥离、220℃ 不焊死。

目的：给出可开刮的水性可揭起步配方和工艺锁，先实验室出数。不是改 C0，也不是铝箔预涂那单。

## 三、工作目标

1. 冻一套**裸 PET / 可揭奶茶盖**水性起步配方（W1 主推可揭，W1-L 过封对照，W2 / W3 对照）。  
2. 在 90℃ / 20–30 秒内做成不反粘、低气味干膜。  
3. 在 180–220℃ × 1.5 s × 0.4 MPa 给出可揭窗和破坏面，供张总决定是否立项。  
4. 与光油、铝箔 C0 分列，月表勿写「通用热封」。

---

## 四、技术路线

裸 PET + 可揭 + 220℃ 是三件套：胶必须咬住盖膜，但不能在 220℃ 焊进杯口。奶茶还要封住热饮，揭力太低会漏。

做法：盖膜侧靠共聚酯 + 电晕抓牢；杯口侧靠**硬相 + 蜡**做成可揭面；EVA / 软丙给 180℃ 起封。共聚酯、软相不能按 V1.0 那么多，否则 220℃ 焊死。

| 组分 | 作用 | V1.1 取舍 |
|------|------|-----------|
| 水性磺化共聚酯 | 盖膜 PET 附着 | W1 必加，干基约 15%。再高容易 220℃ 焊杯口 |
| EVA 热封乳液 | 180℃ 起封、内聚 | 比 V1.0 略减，防过封 |
| 软丙烯酸（Tg −15~0℃） | 成膜、起封 | 比 V1.0 减，给硬相让位 |
| 硬丙烯酸（Tg 50~65℃） | 抗粘连、可揭、防焊死 | 比 V1.0 加；与软丙干基约 1:1 |
| 氧化 PE 蜡 + EBS | 可揭、爽滑、抗粘连 | 蜡+EBS 干基约 7%；过量 180℃ 封不住 |
| 乙醇 5–6.5% | 快干、润湿 PET | 不超过 6.5% |
| AMP-95 | pH 7.5–8.5 | **不用氨水** |

理想破坏面：**胶留在盖膜，杯口干净或极薄雾**（界面可揭）。胶整层跑到杯口 = 盖膜附着失败。焊死撕膜 = 过封。干净两界面脱、揭力 &lt;2.5 N = 没封住。

不采用：HS-B C0；R307 溶剂型 PE 线；氨中和乳液；V1.0 高软相「越大越好」配方作主推。

## 五、配方（溶液 100 g，不编份数）

牌号先按**功能 + 可买到的例子**写。库存核完再锁供应商，未入盘不开 5 kg。

目标胶液：固含 40–44%；粘度 200–350 mPa·s（25℃，2# / 60 rpm）；pH 7.5–8.5；乙醇 5.0–6.5%。

### 5.1 HS-PET-W1 主推（可揭，裸 PET 奶茶盖）

盖膜共聚酯抓牢，杯口硬相+蜡可揭。本单先刮这个。

| 2 | EVA 热封乳液 | 55%，VA 约 18–28%：瓦克 VINNAPAS 包装级 / 国产热封 EVA | 28.0 | 55 | 15.40 | 180℃ 起封 |

干基大致：EVA 38% + 软丙 20% + 硬丙 19% + 共聚酯 15% + 蜡/EBS/助剂 8%。

**W1-H 快干（烘道偏弱）：** 乙醇 6.5 g，水 3.5 g，其余不动。乙醇不超过 6.5 g。

**W1-K 防焊死（220℃ 撕膜 / 揭不开）：** 硬丙 +2.0 g，蜡 +1.0 g，软丙 −2.0 g，EVA −1.0 g。先看 220℃ 破坏面，再看 180℃ 是否还封得住。

**W1-S 补揭力（180℃ &lt;3 N 或渗漏）：** 软丙 +2.0 g，硬丙 −1.0 g，蜡 −1.0 g。先看 180℃ 和 70℃ 水不漏，再看 220℃ 是否仍可揭。

**W1-B 反粘（50℃ 压粘不过）：** 硬丙 +2.0 g，软丙 −2.0 g。再测可揭窗，防止 180℃ 掉下去。

### 5.2 HS-PET-W1-L 过封对照（V1.0 高软相，不主推）

只用来证明「软相多了 220℃ 会焊死」。不报给客户当可揭方案。

共聚酯 30% 22 + EVA 55% 30 + 软丙 50% 20 + 硬丙 48% 12 + 蜡 35% 4.5 + EBS 40% 1.5 + 乙醇 5.5 + 水 2.5 + 助剂同 W1（润湿 0.30 / 消泡 0.20 / HEUR 0.40 / AMP-95 0.15 / 防腐 0.10 / 硅浆 0.85）。合计 100 g，固含约 41.6%。

220℃ 若撕膜或揭不开，正好说明主推必须走 W1 可揭比，不能加软回到 V1.0。

| 2 | EVA 热封乳液 | 同 W1，55% | 20.0 | 55 | 11.00 |
| 3 | 软丙烯酸乳液 | 同 W1，50% | 12.0 | 50 | 6.00 |
| 4 | 硬丙烯酸乳液 | 同 W1，48% | 14.0 | 48 | 6.72 |
| 5 | 氧化 PE 蜡乳液 | 同 W1，35% | 6.0 | 35 | 2.10 |
| 6 | EBS 乳液 | 40% | 1.5 | 40 | 0.60 |
| 7 | 乙醇 | 食用级 95% | 5.5 | 0 | 0 |
| 8 | 去离子水 | | 4.9 | 0 | 0 |
| 9 | 润湿 / 消泡 / HEUR / AMP-95 / 防腐 | 同 W1 0.30+0.20+0.40+0.15+0.10 | 1.15 | — | 0.45 |

### 5.4 HS-PET-W3 对照（纯丙，库存好凑）

只作「没有聚酯 / EAA 时裸 PET 能不能挂住」的对照。**不是可揭主推**。

软丙 50% 42 + 硬丙 48% 26 + 蜡 35% 6 + EBS 40% 2 + 乙醇 6 + 水 15.5 + 助剂 2.5（润湿 0.30 / 消泡 0.20 / HEUR 0.50 / AMP-95 0.15 / 防腐 0.10 / 硅浆 1.25）。合计 100 g。

划格或热封若是盖膜干净脱落，停这路，改 W1 / W2。

### 5.5 共聚酯 30% 液（实验室自配，有 AQ 38S 粒子时）

| 步骤 | 操作 |
|------|------|
| 1 | 去离子水 70.0 g，70–80℃ |
| 2 | 慢加 AQ 38S（或等价磺化共聚酯粒子）30.0 g，300–400 rpm，至全分散、无粒子 |
| 3 | 冷至 &lt;40℃，100 目过滤，标「PET-AQ30、日期、固含」 |
| 4 | 当天或 48 h 内配 W1。不加氨、不加 R307 |

无粒子则寻 30% 成品分散体，不拿 C0 的 CPP 代替。

### 5.6 配胶顺序（W1 / W1-L / W2 / W3 通用）

1. 缸中先加去离子水、乙醇、润湿剂、一半消泡剂，200 rpm，5 min。  
2. 慢加共聚酯或 EAA，300 rpm，15 min，无颗粒。  
3. 加 EVA → 软丙 → 硬丙，各 10 min。  
4. 慢加蜡乳液、EBS，避免破乳。  
5. 加硅浆（若用）。  
6. AMP-95 调 pH 7.8–8.3。  
7. HEUR 调到 200–350 mPa·s。  
8. 余下消泡剂、防腐剂，慢速 10 min。  
9. 100 目过滤。测固含、粘度、pH、气味。  
10. 静置 2 h 看分层；分层不刮板。

禁止：高速打进大量空气；氨水；把 C0 / R307 / 甲苯兑进水性缸。

## 六、涂布与烘干（工艺锁）

| 项 | 锁 |
|----|----|
| 盖膜 | PET，涂前达因 ≥42；&lt;38 先电晕，不硬涂。记达因、膜厚、牌号 |
| 杯口试片 | **裸 PET**，与客户杯子同牌号；无客户杯则用同厚度 APET 片，并在卡上写「替代片」 |
| 实验室替代网纹 | 8# 或 10# 线棒，干涂 3.5–5.0 g/m²，称重校准。可揭胶宁薄勿厚，厚了 220℃ 易过封 |
| 客户线 | 网纹 100–150 线，8–12 BCM；先 3.5 g/m² |
| 烘干 | **膜面** 90±2℃ × 25 秒（20 秒、30 秒各一组）。热风表温不是膜面温 |
| 干膜 | 表干、无发白、无粘手；残余水分 &lt;1.5% |
| 收卷 | 冷至 &lt;35℃ 再收。实验室可垫 PE 膜；客户线以不垫也能过反粘为准 |
| 熟化 | 涂后 23℃、24 h 再热封（0 h、4 h 各抽 1 条，不替代 24 h） |

90℃ / 25 秒欠干：发白、指压粘、收卷粘连、热封气泡。先查膜面温、干涂、固含，不先改树脂。

## 七、热封与验收（可揭窗，先报数，不写能接）

热封仪：盖膜涂层面 vs **裸 PET** 杯口片，15 mm 宽。**180 / 200 / 220℃ × 1.5 s × 0.4 MPa**，各 5 条。剥离 180° 或 T 型，300 mm/min。必记破坏面。

| 项 | 方法 | 内控（报数用，不是接单标准） |
|----|------|------------------------------|
| 180℃ 揭力 | 1.5 s × 0.4 MPa | **3.0–7.0 N/15 mm**，可揭，不漏 |
| 200℃ 揭力 | 同上 | **4.0–8.0 N/15 mm**，可揭 |
| 220℃ 揭力 | 同上 | **4.0–10.0 N/15 mm**，仍可揭；**不焊死、不撕膜、杯口不变形** |
| 破坏面 | 目视 + 记录 | **胶留盖膜**；杯口干净或极薄雾。胶整层到杯口 = 盖膜附着失败 |
| 不漏 | 200℃ 封好的杯或袋，70℃ 水 30 min 倒立 | 不渗、不崩盖 |
| 反粘 | 涂面相对，50℃ × 24 h × 0.5 kg/cm² | 无粘连、无转印、无拉丝 |
| 气味 | 干膜密封罐 23℃ × 2 h | 无氨、无酯/酮；极轻醇味 1 min 内散 |
| 盖膜附着 | 划格 GB/T 9286 + 3M 610 | ≥1 级，破坏面不是干净盖膜 PET |
| 外观 | 目视 | 透明到微雾，无缩孔、无条道 |

否决（只报数，不报主推候选）：180℃ &lt;2.5 N 或渗漏；220℃ 揭不开 / 撕膜；杯口残胶拉丝；盖膜划格掉。

**通过闸：** W1 在 180 与 220 都落在可揭窗、破坏面正确、70℃ 水不漏、反粘过、无氨味 → 可报张总「值得打客户膜」。任一不过只报数，**不写能接**。

奶茶是食品场景，合同仍不写食品接触。要书面 GB 4806 再单独立项选料。
