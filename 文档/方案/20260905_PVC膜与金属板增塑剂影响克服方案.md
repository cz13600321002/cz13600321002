
## 一句话结论

水煮后胶连着 PVC 从金属上揭走，说明 **PVC/胶当时还在，被热水顶掉的是金属/胶。**  
增塑剂仍可能穿过胶层到达金属侧帮忙拆台，但第一刀不是换 PVC 手感、也不是加厚主胶。

**可操作的精确做法：**

1. **金属先做成热水拔不掉的界面**：脱脂净 + 转化膜或硅烷/环氧湿底涂（薄、交联、能螯合）。  
2. **用 H0/H1 水煮对照判断增塑剂有没有渗到金属侧**：H0 也从金属掉 → 只改金属；H0 过、H1 掉 → 再上隔离/低迁移贴合层。  
3. **水煮是验收，40℃ 浸水只是预筛。** 干态剥离好不算数。

加厚胶、只换热塑丙烯酸、水煮前胶没养满 24 h——都是假克服。

## 一、两道界面分别怕什么

| 界面 | 材料矛盾 | 该提供什么 | 典型失败长什么样 |
|------|----------|------------|------------------|
| 金属 / 胶层 | 铝、钢要极性基团咬氧化层；胶被增塑剂泡软后内聚先裂 | –COOH / –MAH / –PO4 / 硅烷；交联网络 | 整层连胶从金属上揭起，金属面发亮或有油膜 |
| 胶层 / PVC | 软 PVC 贴合面常已有一层增塑剂油膜；热压再往外赶 | PVC 相容段（腈基、醋酸乙烯、氨基甲酸酯）+ **隔离或零迁移贴合层** | PVC 面发亮发滑，胶留在金属上 |

PE 方案里 CPO 是给未电晕聚烯烃用的。**PVC 贴金属不要把 PE 型 CPO 当主胶，更不要指望薄 CPO 单独过水煮。** 主粘合走腈胶 / 2K PU；水煮过关靠金属湿底涂（P-W），不是靠 CPO 互扩散。

80℃ × 20 min 的角色和 PE 方案一样：只负责赶溶剂、让底涂铺展、让 2K 起步交联。**它不会把 PVC 焊进金属，也形不成耐沸水的金属键。** 水煮必须在 24 h 养护之后做。

## 〇、现场指纹：水煮从金属侧整层揭

这是本方案现在要解决的主问题。和「PVC 面发滑、胶留在金属上」是反的，对策也反。

```
沸水 100℃
    ↓ 沿金属氧化层爬、置换氢键/离子键
金属 | 胶     ← 这里开裂
胶 + PVC 整张揭走   （PVC/胶仍连着，所以看起来像“胶和膜一起掉”）
```

| 看到什么 | 含义 | 先改哪里 |
|----------|------|----------|
| 水煮后金属发亮、胶在 PVC 背面 | **M，湿热金属界面** | 脱脂 / 转化 / 湿底涂 P-W |
| 金属上残留一层发黏的胶，PVC 揭走 | C 或胶被水+增塑剂泡软 | 交联、减干膜、再查油 |
| PVC 面光、胶留金属 | V，增塑剂弱边界 | 才走 H2/B1，不先堆金属环氧 |
| 边缘先起泡再整张走 | 水从切口进，底涂针孔或无转化 | 封边对照 + 补转化膜 |
| 钢水煮后锈印在揭开面 | 闪锈 / 渗水腐蚀 | 2 h 内涂；钢必须转化或 P-W |

**H0/H1 水煮一眼分流（当天就能判）：**

| H0（低增塑/硬质 PVC）水煮 | H1（现用软膜）水煮 | 结论 | 下一步只准动 |
|---------------------------|---------------------|------|--------------|
| 也从金属整层掉 | 同样掉 | **与增塑剂无关**，金属湿附着不够 | M 组：转化、硅烷、环氧底涂 |
| 过 | 从金属掉 | 增塑剂（或水+油）到了金属侧 | P-W **加上** B1/H2，单改金属不够 |
| 过 | PVC 面掉 | 油在 PVC/胶 | 按增塑剂上策，少动金属 |
| 都过 | — | 现场水煮条件比实验室狠，查封边、时间、是否未养 24 h | 对表工艺 |

40℃×24 h 已从金属掉，不必先上沸水配方；先过 40℃，再上 **100±2℃ × 60 min** 水煮。

## 二、增塑剂怎么毁粘合层（对照酰胺模型）

### 2.1 三波，不要只防第三波

```
PVC 本体（20～50 phr 增塑剂）
    ↓ 不相容，往自由表面爬
弱边界层：增塑剂单分子～多分子油膜
    ↓ 热压 / 烘烤加速
粘合剂层被溶胀、Tg 下降、内聚变差
    ↓
金属底涂 / 金属氧化层
```

| | 贴合当时 | 热压 / 80℃ 烘 | 下机以后 |
|--|----------|---------------|----------|
| 增塑剂在哪 | 贴合面已经有一层（压延、收卷时析出） | 热把更多分子赶到界面，也赶进胶层 | 继续从本体扩到胶、再扩到金属侧 |
| 形态 | 油状液膜 | 热的、粘度更低，铺得更快 | 胶被增塑，边缘渗油、发黏或发软 |
| 对粘合 | 第一刀：弱边界，当时剥离就可能差 | 热压越狠，当时越像“焊住”，隔天越容易再掉 | 第二刀：24 h～数周剥离下滑 |

和酰胺同一条指纹：**下机合格、隔天或 70℃ 后再掉。** 差别是储量：0.1 mm 软 PVC、40 phr DOP，可供迁移的量是 **几千 mg/m²** 量级；铺满界面只要大约 **10～50 mg/m²**。不必“全部跑出来”。

### 2.2 谁伤得更快

| 增塑剂 | 相对分子量 | 往胶层迁 | 备注 |
|--------|------------|----------|------|
| DBP | 小 | **很快** | 尽量不用在贴合级膜 |
| DOA | 中小 | **快** | 耐寒好，贴合差 |
| DOP / DEHP | 中 | **快** | 经典问题料 |
| DINP / DIDP | 中大 | 中～快 | 比 DOP 好一截，仍会迁 |
| DOTP | 中 | 中 | 常见替代，**不能当成已克服** |
| DINCH | 中 | 中 | 同上 |
| TOTM | 大 | 较慢 | 单体里较好的一档 |
| 环氧大豆油 | 中 | 中 | 既是稳定剂也是增塑剂 |
| **聚酯 / 聚己二酸酯（聚合型）** | 大 | **慢** | 贴合级优先 |

同 phr 下：小分子、线性、与 PVC 部分相容的，爬得最快。聚合型不是“零迁移”，是把第二波拉长到可验收。

### 2.3 胶被泡软之后，测到的是假附着

| 失效代码 | 模式 | 含义 |
|----------|------|------|
| V | PVC / 胶界面 | 弱边界。PVC 面亮、滑 |
| C | 胶层内聚 | 增塑剂进胶，Tg 掉了；或胶涂厚了 |
| M | 金属 / 胶界面 | 金属没咬住，或油从胶里渗到金属 |
| X | 混合 | 局部锚定成功 |
| P | PVC 本身拉坏 | 界面已够（软膜常见“好”的样子） |

胶带揭得住 ≠ 复合牢度。验收以 **180° 剥离 + 失效面 + 时效** 为准。

## 三、如何精确克服（按效力排）

原则和酰胺方案同一句：**把易迁移增塑剂从贴合面拿掉，再让胶交联；不要用底涂去和它抢。**

### 3.1 上策：贴合面和增塑剂物理分开

```
装饰/空气面     普通软 PVC（DOP/DOTP 都可以，管手感）
芯层           原软 PVC
贴合皮层       低增塑或聚合型增塑剂 PVC；目标迁移物尽量少
                 ↓
            可选：交联隔离底涂 3～8 μm
                 ↓
            交联粘合剂（腈胶或 2K PU）
                 ↓
            金属底涂（超薄，咬氧化层）
                 ↓
            脱脂金属
```

| 项 | 规定 |
|----|------|
| 贴合皮层增塑剂 | **优先聚合型或 TOTM**；禁止 DBP、DOA 当主增塑 |
| 贴合皮层单体增塑剂 | 能做到 **0** 最好；做不到则总 phr **比芯层低 ≥10 phr**，且不用 DOP/DOA |
| 贴合皮层厚度 | 先定 **25～40 μm**（比酰胺方案的 15～25 μm 厚：增塑剂储库更大，反扩散更快） |
| 仍掉、PVC 侧 ATR 出酯羰基 | 加厚到 **40～60 μm**，或改隔离底涂 |
| 隔离底涂 | 2K PU 或交联丙烯酸氨基甲酸酯，干膜 **3～8 μm**，**必须交联**，不要热塑膜 |
| 粘合剂 | 见 3.2，**不要为此加厚** |

压延单层、整膜都是 40 phr DOP，再靠擦表面——**不算克服，只是减轻。**

没有共挤/复合条件时，退一步：整膜换成聚合型增塑剂，或贴合面先涂隔离底涂再涂胶。手感层和贴合层不要放在同一配方里解决。

### 3.2 中策：胶层交联 + PVC/金属双锚定

金属要极性点，PVC 要腈基 / 氨酯 / 醋酸乙烯。一条分子很难两头都强，所以 **金属底涂和主胶分工**，和 PE+金属的 P-D 是同一逻辑。

**主路线 A-N（推荐先做）：溶剂型丁腈（NBR）胶**

| 项目 | 规定 |
|------|------|
| 主体 | 中高丙烯腈 NBR（AN **28%～40%**） |
| 酚醛 | 可加烷基/萜烯酚醛作增黏，固体 **5%～12%**；先做 0% 对照 |
| 金属底涂 | 酸改性或磷酸酯改性薄底涂，干膜 **1～2 μm**（沿用 P-D / P-E 思路） |
| 主胶干膜 | **15～30 μm**（复合胶，不是 CPO 那种 0.5 μm 分子桥） |
| 烘烤 | 表干后 **80±2℃ × 20 min**；出炉后加压贴合或趁热贴 |
| 养护 | 23℃/50%RH **24 h** 正式剥；**72 h** 和 **70℃×24 h** 必做 |

腈胶耐油、和软 PVC 是经典配对。酚醛补金属侧和内聚；热固酚醛过量会变脆，按 TPU 方案同一条：先 C0/C1。

**主路线 A-U：2K 聚氨酯**

| 项目 | 规定 |
|------|------|
| 主体 | 聚酯型或聚醚型多元醇 + HDI/IPDI 固化剂 |
| NCO/OH | **1.05～1.20**（略过当，补一点被增塑剂消耗的交联） |
| PVC 侧 | 胶本身就能咬；难粘或油重时先上隔离底涂 |
| 金属侧 | 同 A-N 的超薄底涂；湿附着不足再加磷酸酯 **0.8%～1.5%**（对底涂固体，上限 2%） |
| 干膜 | **15～25 μm** |
| 烘烤 | 80±2℃ × 20 min 只是成膜；**24 h 后交联才算数** |

**备选 A-R：** 湿固化聚氨酯（PUR）或反应型热熔。线速快、要初黏时用。仍要 24 h / 72 h，不要只看下机。

### 3.3 金属怎么处理（直接沿用双基材方案）

| 基材 | 规格 | 清洁 |
|------|------|------|
| 铝 | 3003 / 1060，0.3～1.0 mm | 碱脱脂 + 水洗 + IPA；可选 1%～2% 稀磷酸 |
| 钢 | 冷轧 CRS | 碱脱脂 + 水洗 + IPA；可选锆/钛转化膜 |

脱脂后 **2 h 内** 涂底涂。戴手套。湿附着：40±2℃ 去离子水 **24 h** 后再划格 / 再剥离。

### 3.4 热怎么加（和“擦完再预热 = 白擦”同一条）

| 做法 | 结果 |
|------|------|
| **只预热金属板**，PVC 保持常温或仅短暂接触热辊 | 正确。胶润湿金属，少赶 PVC 里的油 |
| PVC 先烘/先预热再贴 | 增塑剂秒级赶回贴合面，等于把弱边界做厚 |
| IPA 擦 PVC → 再预热 PVC → 再贴 | **白擦。** 和 TPE 酰胺预制片同一失败 |
| IPA 擦 PVC → **5～10 min 内冷贴或只热金属** | 权宜，只能去掉表面第一层，储库还在 |
| 贴合温度越高越好 | 错。够润湿就停。常见窗口：**金属 60～90℃，线压 0.3～0.6 MPa，2～10 s** |

80℃ × 20 min 若是「胶已涂在金属上、再盖 PVC 一起烘」：PVC 整张被加热，第二波会提前。能改成「金属涂胶、80℃ 把胶烘到表干/半干，再常温或低温贴 PVC」，就改。必须一起烘时，贴合皮层和隔离底涂更不能省。

### 3.5 水煮金属侧：湿底涂 P-W（现场主路线，先做）

水煮从金属掉时，**主胶再换成更好的 NBR/PU 也常常不够**。要在金属上单独做一层热水拔不掉的皮。角色是分子桥/湿底涂，不是 20 μm 主胶。

按效力，同一主胶、同一 PVC、同一水煮，只改金属侧：

| 代号 | 金属侧 | 干膜 / 要点 | 水煮预期 |
|------|--------|-------------|----------|
| M0 | 只碱脱脂 + IPA | — | 常整层 M，负对照 |
| M-D | P-D（酸改性 CPO+EAA） | 1～2 μm | 干态可过，**沸水常不够** |
| M-E | P-E（P-D + 磷酸酯 0.8%～1.5%） | 1～2 μm | 40℃ 常过，沸水看情况 |
| M-Si | 环氧硅烷（γ-GPS）或氨硅烷 | 浸或擦 1%～2% 醇水溶液，pH 4～5，晾 10 min，80℃×20 min | 水煮金属侧首选之一 |
| M-Zr | 锆/钛转化或 1%～2% 稀磷酸活化，水洗净，再 P-E 或硅烷 | 转化膜极薄，不当油漆 | 钢/铝都优先于“只脱脂” |
| M-Ep | 环氧–聚酰胺或环氧–酚醛底涂 | **3～8 μm**，必须交联；80℃ 窗口选低温固化或加长养护 | 水煮上限对照 |
| M-Ph | 腈胶主胶里加烷基酚醛 5%～10%（C0/C1），金属仍要 M-Si 或 M-Ep | 酚醛不消灭增塑剂，只补金属 | 单独加酚醛很少能过沸水 |

**P-W 操作锁死（写进工艺卡）：**

1. 碱脱脂至水膜连续 ≥30 s；水洗至中性；最后 IPA。戴手套，**2 h 内**进下一层。  
2. 钢：无闪锈才涂；潮湿天先烘干。铝：不打砂当主工艺。  
3. 硅烷：现配现用，**4 h 内用完**；水解液发白浑浊作废。涂后须 80℃ 成膜，不能湿叠主胶。  
4. 环氧底涂：表干后再上主胶；未干就盖 = 层间油。干膜 >10 μm 容易内聚或变脆，水煮后碎在金属上，看起来像“还在掉”。  
5. **水煮前必须 23℃/50%RH 养满 24 h。** 出炉就煮，测的是没熟的胶，不是金属底涂。  
6. 水煮默认：**去离子水或蒸馏水，100±2℃，60 min**；试样竖放不贴壁、互不叠。到时取出，自来水淋凉，吸干，**30 min～1 h 内**剥。另做 30 min 快筛。  
7. 每组两块：一块 **切口不封边**（接近现场），一块胶带或蜡封边（看是界面差还是切口进水）。现场是整张揭，以不封边为准。

硅烷、薄环氧在这里是 **金属湿底涂**，不是 PE 方案里禁止的“硅烷/环氧当主膜去涂未电晕 PE”。对象不同，不要套错禁止项。

### 3.6 明确不要做的

| 动作 | 为什么不是克服 |
|------|----------------|
| 加厚粘合剂到 50～80 μm 去“吃增塑剂”或“挡水” | 胶先被泡软；水照样走到金属 |
| 只用热塑丙烯酸 / SIS / SBS 热熔 | 增塑剂是溶剂；沸水更溶 |
| 把 PE 型 CPO 当 PVC–金属主胶或唯一金属底涂 | 咬不了 PVC；**单独过不了水煮** |
| 水煮不过就加厚环氧到几十微米 | 内聚碎，仍是假附着 |
| 出炉或贴完就下水煮 | 胶没交联，H0 也会掉 |
| 只看干态剥离 / 只做胶带 | 现场是水煮 M |
| 40℃ 过了就宣布耐水 | 沸水比 40℃ 狠一档 |
| 整膜 DOTP 替换 DOP，就宣布解决 | 迁移慢一点，不是分层 |
| 隔离底涂用热塑丙烯酸 | 自己先被增塑剂溶解 |
| 电晕 / 火焰 PVC | 解决不了金属湿热；有时把油烤到表面 |
| 不脱脂、不清碱残留就上硅烷 | 硅烷粘在油或碱上，水煮必掉 |

## 四、推荐工艺链（实验室可落地）

```
金属：碱脱脂（水膜连续 ≥30 s）→ 水洗至中性 → IPA → 2 h 内
  → 转化（M-Zr，推荐钢/铝先做）或直接
  → P-W 湿底涂：优先 M-Si，不过再上 M-Ep；P-E 只当 40℃ 预筛
  → 80±2℃ × 20 min，冷却
PVC：确认贴合面；IPA 单向擦 2 遍，晾 ≥5 min（不预热）
  → H0/H1 分流后再决定是否隔离底涂 3～8 μm
主胶：只涂在金属 P-W 上（不要两边厚堆），NBR 或 2K PU，15～30 μm
  → 表干
  → 贴合：热金属 / 冷或微热 PVC，0.3～0.6 MPa
  → 若需：80±2℃ × 20 min
  → 冷却 ≥30 min → 23℃/50%RH **养满 24 h**
  → 干态 180° 剥离 + 失效面（过程）
  → **水煮 100±2℃ × 60 min** → 淋凉吸干 → 30 min～1 h 内再剥 + 失效面（验收）
  → 40℃×24 h 仅预筛；72 h / 70℃×24 h 仍做迁出物第二波
```

主胶只涂一侧。P-W 未干不要盖主胶。水煮样与干态样同批、同炉，否则不能比。

## 五、怎么测

| 顺序 | 测什么 | 方法 | 算不算数 |
|------|--------|------|----------|
| 贴合前 | 金属底涂是否咬住 | 划格 GB/T 9286 | 过程检。金属不合格不要贴 PVC |
| 贴合前 | PVC 贴合面是否“有油” | 水膜是否连续；可选 ATR 酯羰基约 **1720 cm⁻¹** | 过程检 |
| 贴合后主数据 | 复合牢度 | **180° 剥离**，15 mm 或 25 mm 宽，GB/T 2790 / GB/T 2791 | **验收** |
| 必须写 | 失效面 | V / C / M / X / P | 决定改哪一侧 |
| 后期 | 增塑剂第二波 | 24 h + **72 h** + **70℃×24 h** | 防隔天掉 |
| 金属湿预筛 | 同上 | 40℃ 去离子水 24 h 后再剥 | 预筛。不过则先别煮 |
| **水煮（本项目验收）** | 复合样 | **100±2℃ × 60 min**，不封边为主；记录是否自发揭、再 180° 剥 | **验收**。失效必须写 M/V/C |

剥离速度锁定：**100 mm/min 或 300 mm/min**，全项目同一档。不要和 PE 薄膜胶带法混用验收。

水煮操作见 3.5。自发揭面积 ≥10% 直接判该组水煮失败，不必再比牛顿数。

### 5.1 必须做的对照（比再调 NCO/OH 更要紧）

同一金属、同一胶、同一贴合温度：

| 代号 | PVC | 目的 |
|------|-----|------|
| H0 | **聚合型增塑剂** 或硬质/半硬质（低 phr） | 上限：胶和金属本身够不够 |
| H1 | 现用软膜（写出 DOP/DOTP/… 和 phr） | 真实差距 |
| H2 | 与 H1 同树脂，贴合皮层换成聚合型，25～40 μm | 验证「分层」是不是解 |
| B0 | H1 + 无隔离底涂 | 隔离层基线 |
| B1 | H1 + 交联隔离底涂 3～8 μm | 隔离层效力 |
| W1 | H1，IPA 擦后 5～10 min 内贴，**PVC 不预热** | 擦拭上限 |
| W1x | H1，擦完再预热 PVC 再贴 | 证明预热冲掉擦拭 |

H1 比 H0 掉 **>20%**，或失效面变成 V（PVC 光亮发滑）→ 增塑剂已构成粘合问题，调胶解决不了，走 H2 或 B1。

**水煮从金属掉时，先加下面这组（同一 H1 膜、同一主胶）：**

| 代号 | 唯一差别 |
|------|----------|
| M0 | 只脱脂 |
| M-E | P-E |
| M-Si | 硅烷 P-W |
| M-Ep | 环氧 3～8 μm |
| M-Zr+Si | 转化 + 硅烷（现场主攻） |

先做 M0 和 M-Zr+Si 各 3 片水煮。M-Zr+Si 过、M0 不过 → 金属侧成立，再补 M-Si / M-Ep 看能否减一步。两边都不过 → 查是否未养 24 h、主胶不交联、或切到 H0 水煮（回到 〇 分流表）。

### 5.2 怎样才算已经克服

同一胶、同一金属、同一机台：

| 样 | 24 h 干剥 | 水煮 60 min 后 | 72 h 或 70℃×24 h | 失效面 |
|----|-----------|----------------|-------------------|--------|
| H0 + 宣称的 P-W | 基准 | **不自发揭**；剥力 ≥ 干态 70%，且不是大面积 M | 再掉 ≤10% | 允许 P 或少量 X |
| H1 + 宣称的 P-W | ≥ H0 干态 90% | 同上；相对 H0 水煮再掉 ≤15% | 再掉 ≤10% | 金属面不得大面积光板 |
| H1 + M0（只脱脂） | 对照 | 常整层 M | — | **不作为合格工艺** |

边缘渗油、PVC 侧白布一擦发滑、水膜不连续，按增塑剂残留计。  
H2 若 72 h 仍掉、ATR 又出强酯峰：贴合皮层太薄，芯层在反扩，加厚到 40～60 μm 或上 B1。

水煮后金属光、胶在 PVC 上 = 没克服，不论干态多高。

边缘渗油、PVC 侧白布一擦发滑、水膜不连续，按增塑剂残留计。  
H2 若 72 h 仍掉、ATR 又出强酯峰：贴合皮层太薄，芯层在反扩，加厚到 40～60 μm 或上 B1。

未给具体 PVC 牌号、phr、金属厚度前，**不报牛顿数**。先报相对 H0 的百分比和失效面。

## 六、和原方案怎么对应（避免套错配方）

| 原方案做法 | PVC–金属这里 |
|------------|--------------|
| PE 型 CPO + EAA 超薄底涂 | **只留给金属底涂思路**；主胶改 NBR / 2K PU |
| 底涂必须薄（0.5～2 μm） | 金属底涂仍薄；**主胶 15～30 μm**，再厚就吃油失败 |
| 酰胺共挤贴合层 15～25 μm、零酰胺 | 增塑剂贴合皮层 **25～40 μm**、聚合型/低 phr |
| 擦完再预热 = 白擦 | 擦完再预热 PVC = 白擦；只热金属 |
| 酚醛加在 MAH-CPO 里不消灭酰胺 | 酚醛加在腈胶里 **不消灭增塑剂**；只可能补金属侧 |
| 24 h 验收、72 h / 70℃ 防假合格 | 原样沿用，本问题更必须 |
| 胶带 / 划格 ≠ 流延剥离 | 胶带 / 划格 ≠ PVC–金属剥离 |
| 40℃ 浸水划格 | **预筛**；本现场以水煮 60 min 为准 |
| 硅烷/环氧禁止当 PE 主膜 | 水煮金属侧 **允许** 作 P-W，对象不是未电晕 PE |

## 七、工作目标

1. 用水煮失效面确认是 **金属/胶（M）**，不是 PVC/胶。  
2. 用 H0/H1 水煮分流：先定改金属还是还要挡增塑剂。  
3. 锁定 P-W（转化 + 硅烷或薄环氧）+ NBR/2K PU，80℃ 窗口能走通。  
4. 干态 24 h 达到 H0 的 ≥90%；**水煮 60 min 不自发揭、不为大面积 M**。  
5. 40℃ 只预筛；72 h / 70℃×24 h 仍防第二波。

## 九、风险

| 风险 | 可能性 | 影响 | 应对 |
|------|--------|------|------|
| 现用膜无法改配方、不能共挤 | 高 | 上策做不了 | 强制隔离底涂 B1 + 交联胶；验收仍按时效 |
| 80℃ 对 2K 交联不够 | 中 | 24 h 假好、72 h 掉（胶没熟，不像增塑剂） | 拉 NCO/OH 对照；没熟是 C 且 H0 也掉 |
| 腈胶溶剂咬软 PVC 过深 | 中 | PVC 溶胀、尺寸变 | 表干再贴；换 2K PU |
| 钢闪锈 / 水煮锈印 | 高 | 整层 M | 2 h 内涂；M-Zr + P-W |
| 未养 24 h 就水煮 | 高 | H0 也掉，误判胶种 | SOP 卡死时点 |
| 硅烷过期水解液 | 中 | 假底涂 | 4 h 内用完，浑浊作废 |
| 把 PE 方案配方直接涂上 PVC | 中 | 全面失败 | 本文件第六节对照表 |
