**现场指纹（已锁定）：** 只有软质 PVC 水煮从金属揭；硬质没有问题。  
**现用主胶（已锁定）：** 聚酯固体份 **710 / 240 / 822 = 30 / 40 / 50**（归一 25% / 33.3% / 41.7%）+ 封闭 NCO（3175 EW 380 或 HY-1070 EW 408；一炉一支）。  
**现用烘烤（已锁定）：** 卷材，板温 **232℃**。胶在贴膜前已交联。  
**边界（已锁定）：** **膜改不了；膜上做处理剂不可行。** 不许再写 H2/B1 当主路线。  
**案例入口（与 PE 分开）：** `项目/进行中/PVC卷材贴膜水煮_2026/README.md`  
**不要参照：** PE 免电晕、CPO+EAA、80℃×20 min、TPU 流延 TPE。不是同一条产线。

**实际结构：**

```
PVC 膜（软质，含增塑剂）
   ↑ 贴合面
粘合剂层（± PVC 侧隔离底涂）
   ↑
金属板（铝 / 冷轧钢，± 金属底涂）
```

## 一句话结论

卷材板温 **232℃** = 封闭异氰酸酯已经解开，聚酯胶已经交联。硬质水煮过关，也证明交联和金属都够。  
V1.3 把第一枪写成「先解封」——**作废。** 软膜进不了 232℃ 炉，产线本来就是先烘后贴。

只剩一件事：软质增塑剂（酯类）仍能钻进**已经交联的聚酯**，水煮时把金属/胶拆掉。出炉带温越高，油钻得越快。

膜不能改、膜上不能涂处理剂，油只能从**卷材这一侧**少接、少吃。

**主路线仍是两步（先做完再谈别的）：** L1 贴辊 ≤100℃ → 不够再 G1 加密交联。  
膜侧没有第三条路。卷材侧还有没写进主路线的，见 **3.8**（底涂在金属上、冷却辊、聚酯/氨基杂化）。那不是改膜，也不是膜上处理剂。

## 一、两道界面分别怕什么

| 界面 | 材料矛盾 | 该提供什么 | 典型失败长什么样 |
|------|----------|------------|------------------|
| 金属 / 胶层 | 铝、钢要极性基团咬氧化层；胶被增塑剂泡软后内聚先裂 | –COOH / –MAH / –PO4 / 硅烷；交联网络 | 整层连胶从金属上揭起，金属面发亮或有油膜 |
| 胶层 / PVC | 软 PVC 贴合面常已有一层增塑剂油膜；热压再往外赶 | PVC 相容段（腈基、醋酸乙烯、氨基甲酸酯）+ **隔离或零迁移贴合层** | PVC 面发亮发滑，胶留在金属上 |

主胶已是 **聚酯 + 封闭异氰酸酯**，按卷材 **PMT 232℃** 烘：交联足够，硬质能过。短板只剩软质酯类增塑剂钻已固化聚酯。PE 方案的 80℃×20 min **不要套到这条卷材线**。

## 〇、现场指纹（已锁定）：只有软质才掉

| 膜 | 同胶、同金属、同水煮 | 结论 |
|----|----------------------|------|
| **硬质 PVC（H0）** | **没有问题** | 金属/胶/烘烤够用 |
| **软质 PVC（H1）** | 胶连膜从金属整层揭 | **只有软质才有此问题** = 增塑剂 |

这不是“还要猜是金属还是油”。分流表第二行已经成立。本轮 **冻结硬质膜用过的那套金属工艺**，只改软膜侧，让软膜水煮接近硬质。

```
软 PVC（20～50 phr 增塑剂）
    ↓ 热贴合 + 沸水
增塑剂穿过胶层，到金属/胶
    ↓ 水 + 油一起拆台
金属 | 胶     ← 开裂（硬质没有油，这里不开）
胶 + 软 PVC 整张揭走
```

| 看到什么 | 在本现场含义 | 先改哪里 |
|----------|--------------|----------|
| 软质水煮金属光、胶在膜背面 | 油到了金属侧（M） | **H2 贴合皮层或 B1 隔离** |
| 硬质水煮仍过 | 金属没坏 | **不准改金属当主路线** |
| 金属上残留发黏的胶 | 胶被增塑剂+水泡软 | 交联密度、减干膜，仍不换金属 |
| 软质 PVC 面光、胶留金属 | 才是 V | 仍走 H2/B1 |
| 硬质也突然从金属掉 | 金属工艺被改坏或未养 24 h | 停，对回硬质基准 |

M 组（硅烷/环氧/转化）**只在硬质也掉时才开**。现在硬质不过这个问题，开 M 组是混淆变量。

## 二、增塑剂怎么毁粘合层（对照酰胺模型）

### 2.1 三波，不要只防第三波

```
PVC 本体（20～50 phr 增塑剂）
    ↓ 不相容，往自由表面爬
弱边界层：增塑剂单分子～多分子油膜
    ↓ 热压 / 烘烤加速
粘合剂层被溶胀、Tg 下降、内聚变差
    ↓
金属底涂 / 金属氧化层
```

| | 贴合当时 | 热压 / 80℃ 烘 | 下机以后 |
|--|----------|---------------|----------|
| 增塑剂在哪 | 贴合面已经有一层（压延、收卷时析出） | 热把更多分子赶到界面，也赶进胶层 | 继续从本体扩到胶、再扩到金属侧 |
| 形态 | 油状液膜 | 热的、粘度更低，铺得更快 | 胶被增塑，边缘渗油、发黏或发软 |
| 对粘合 | 第一刀：弱边界，当时剥离就可能差 | 热压越狠，当时越像“焊住”，隔天越容易再掉 | 第二刀：24 h～数周剥离下滑 |

和酰胺同一条指纹：**下机合格、隔天或 70℃ 后再掉。** 差别是储量：0.1 mm 软 PVC、40 phr DOP，可供迁移的量是 **几千 mg/m²** 量级；铺满界面只要大约 **10～50 mg/m²**。不必“全部跑出来”。

### 2.2 谁伤得更快

| 增塑剂 | 相对分子量 | 往胶层迁 | 备注 |
|--------|------------|----------|------|
| DBP | 小 | **很快** | 尽量不用在贴合级膜 |
| DOA | 中小 | **快** | 耐寒好，贴合差 |
| DOP / DEHP | 中 | **快** | 经典问题料 |
| DINP / DIDP | 中大 | 中～快 | 比 DOP 好一截，仍会迁 |
| DOTP | 中 | 中 | 常见替代，**不能当成已克服** |
| DINCH | 中 | 中 | 同上 |
| TOTM | 大 | 较慢 | 单体里较好的一档 |
| 环氧大豆油 | 中 | 中 | 既是稳定剂也是增塑剂 |
| **聚酯 / 聚己二酸酯（聚合型）** | 大 | **慢** | 贴合级优先 |

同 phr 下：小分子、线性、与 PVC 部分相容的，爬得最快。聚合型不是“零迁移”，是把第二波拉长到可验收。

### 2.3 胶被泡软之后，测到的是假附着

| 失效代码 | 模式 | 含义 |
|----------|------|------|
| V | PVC / 胶界面 | 弱边界。PVC 面亮、滑 |
| C | 胶层内聚 | 增塑剂进胶，Tg 掉了；或胶涂厚了 |
| M | 金属 / 胶界面 | 金属没咬住，或油从胶里渗到金属 |
| X | 混合 | 局部锚定成功 |
| P | PVC 本身拉坏 | 界面已够（软膜常见“好”的样子） |

胶带揭得住 ≠ 复合牢度。验收以 **180° 剥离 + 失效面 + 时效** 为准。

## 三、如何精确克服（按效力排）

原则：**不让软质里的单体增塑剂到达已固化的聚酯/金属界面。** 232℃ 胶已经交联，加厚胶、再烘一遍都挡不住油。卷材能做的只有下面四档。

### 3.1 如何减少增塑剂影响（按效力，可操作）

```
装饰/空气面     普通软 PVC（DOP/DOTP 都可以，管手感）
芯层           原软 PVC
贴合皮层       低增塑或聚合型增塑剂 PVC；目标迁移物尽量少
                 ↓
            可选：交联隔离底涂 3～8 μm
                 ↓
            已在 232℃ 交联的聚酯胶
                 ↓
            金属
```

| 项 | 规定 |
|----|------|
| 贴合皮层增塑剂 | **优先聚合型或 TOTM**；禁止 DBP、DOA 当主增塑 |
| 贴合皮层单体增塑剂 | 能做到 **0** 最好；做不到则总 phr **比芯层低 ≥10 phr**，且不用 DOP/DOA |
| 贴合皮层厚度 | 先定 **25～40 μm**（比酰胺方案的 15～25 μm 厚：增塑剂储库更大，反扩散更快） |
| 仍掉、PVC 侧 ATR 出酯羰基 | 加厚到 **40～60 μm**，或改隔离底涂 |
| 隔离底涂 | 2K PU 或交联丙烯酸氨基甲酸酯，干膜 **3～8 μm**，**必须交联**，不要热塑膜 |
| 粘合剂 | 现用聚酯封闭胶，**不要加厚**；配合贴辊降温 |

压延单层、整膜都是 40 phr DOP，再靠擦表面——**不算克服，只是减轻。**

**本现场膜改不了、膜上处理剂不可行，一档二档关掉。** 只走贴辊降温和胶侧加密交联，见 3.5。

### 3.2 现用主胶 + 卷材板温 232℃（已交联，不再补烘）

```
开卷 → 涂聚酯+封闭异氰酸酯 → 烘道 PMT 232℃（胶已解封交联）
     → 出炉带温 → 贴 PVC（软膜不进 232℃ 炉）
     → 收卷
```

232℃ 高于所有常用封闭剂解封温度。出炉后 MEK 轻擦 20 次应当不掉；若还掉，是板温没到 232，先校炉，不要改胶。

交联完仍怕软质油：酯类增塑剂能钻进聚酯网络。出炉板温越高（贴辊还剩 150℃+），钻得越快，和酰胺「擦完再预热」同一条。硬质没油，所以同一 232℃ 水煮没事。

干膜仍按现用卷材湿膜，**不要为了水煮加厚**。

### 3.3 金属怎么处理（直接沿用双基材方案）

| 基材 | 规格 | 清洁 |
|------|------|------|
| 铝 | 3003 / 1060，0.3～1.0 mm | 碱脱脂 + 水洗 + IPA；可选 1%～2% 稀磷酸 |
| 钢 | 冷轧 CRS | 碱脱脂 + 水洗 + IPA；可选锆/钛转化膜 |

脱脂后 **2 h 内** 涂底涂。戴手套。湿附着：40±2℃ 去离子水 **24 h** 后再划格 / 再剥离。

### 3.4 热怎么加（和“擦完再预热 = 白擦”同一条）

| 做法 | 结果 |
|------|------|
| **只预热金属板**，PVC 保持常温或仅短暂接触热辊 | 正确。胶润湿金属，少赶 PVC 里的油 |
| PVC 先烘/先预热再贴 | 增塑剂秒级赶回贴合面，等于把弱边界做厚 |
| IPA 擦 PVC → 再预热 PVC → 再贴 | **白擦。** 和 TPE 酰胺预制片同一失败 |
| IPA 擦 PVC → **5～10 min 内冷贴或只热金属** | 权宜，只能去掉表面第一层，储库还在 |
| 贴合温度越高越好 | 错。够润湿就停。常见窗口：**金属 60～90℃，线压 0.3～0.6 MPa，2～10 s** |

PMT 232℃ 只给未贴膜的卷材。贴辊处另写一个温度。软膜禁止回炉。

### 3.5 本轮顺序：先 L，再 G（膜侧全关）

| 开？ | 代号 | 唯一差别 | n |
|------|------|----------|---|
| 必做 | H0 | 硬质 + 现在贴辊带温 | 每炉 1～3 |
| 必做 | H1-L0 | 软质 + 现在贴辊板温（写 ℃） | 3 |
| **必做** | H1-L1 | 软质 + 贴辊 **≤100℃**，压力相同 | 3 |
| L1 过、干态变 V | — | 太凉贴不湿，贴辊回到 L0 与 100℃ 之间 | — |
| L1 仍 M | H1-G1 | 见下：高羟值聚酯**部分**替代 + 封闭 NCO 按羟值补齐；PMT 232℃；贴辊跟 L1 | 3 |
| 可选 | 收卷板温 | 同 L1，收卷前再凉，避免热卷里继续赶油 | — |

贴辊用接触热电偶，不抄炉子 232。一次只改一列。  
#### G1 怎么改聚酯（回答：先部分替代，不要一上来全代）

对。加密交联的正经做法就是：**用高羟值聚酯替掉一部分低羟值聚酯，并按新的总羟值把封闭异氰酸酯补上去。**

交联点只由「解封后的 NCO」和「聚酯上的 OH」配对决定。

| 只改这一边 | 结果 |
|------------|------|
| 只换成高羟值，NCO 不动 | 多出来的 OH **反应不完**。交联密不了，还更亲水，水煮往往 **更差** |
| 只加 NCO，聚酯还是低羟值 | 多余 NCO 没对手，或只自聚一点，密不过来 |
| 高羟值 + NCO 按当量补齐 | 网络变密，酯类增塑剂更难钻 |

**先部分，不先全代。**

| 代号 | 聚酯固体 | 封闭异氰酸酯 |
|------|----------|--------------|
| G0 | 现用低羟值 100% | 现用（写出 NCO/OH） |
| **G1** | 低羟值 **70%** + 高羟值 **30%** | 按共混后总羟值重算，**NCO/OH = 1.10～1.20**（与 G0 同一算法） |
| G1b | 低 **50%** + 高 **50%** | 同样重算 NCO/OH |
| G1c | 高羟值 **100%** | 同样重算。只当 G1、G1b 水煮有增益、且干态/弯折还过时才做 |

PMT 仍 232℃。一次只改聚酯比，NCO 必须跟着变。  
G1 出炉 MEK 20 次应更抗擦；硬质水煮必须仍过。  
软质干态变 V（膜面光）= 网太密、贴辊温度下贴不湿：退回 30%，或贴辊略高于 L1，不要加厚。  
卷材还要弯折/T 弯：全代高羟值常常脆，所以默认 **先 30%，不要一上来 100%。**

**关掉：** H2 皮层、B1 膜面处理剂、换腈胶、膜进烘道。

### 3.8 还有哪些方法（膜侧全关，L/G 之后）

油的储库在软膜里，膜不动就消灭不了。下面都是 **让油慢一点到、或到了金属还不掉**。仍不许动膜、不许在膜上涂处理剂。

| 档 | 做法 | 和主路线的差别 | 什么时候才开 |
|----|------|----------------|--------------|
| 冷却做彻底 | 烘道后加冷却辊 / 板背冷却，贴辊和收卷都降下来 | 比只喊「≤100℃」稳 | L1 温度测不准、热卷里隔天再掉 |
| G2 换树脂骨架 | 聚酯 + 封闭 NCO **再加氨基树脂**（卷材常见三聚氰胺），或高 Tg / 高官能聚酯 | 比 G1 的 30% 高羟值共混更抗酯溶胀 | G1 不够，且硬质仍过 |
| **P1 金属侧底涂** | 在现用聚酯**下面**加一层薄的卷材底涂（环氧聚酯或耐水聚酯底漆，干膜 **4～8 μm**），两层都走 232℃ | 油把面胶泡软时，金属界面另有一层 | L1+G1 仍整层 M。**不是膜处理剂，涂在钢/铝上** |
| 贴后快冷 | 贴辊后马上冷却，缩短热态接触 | 少给第二波迁移时间 | 热卷、堆垛仍烫时 |
| 线速 | 在贴得住的前提下略加快，减少贴辊高温停留 | 工艺微调 | 与 L1 一起记，不单独当方案 |

**P1 怎么做（可操作）：**

```
金属 → 薄底涂 4～8 μm → PMT 232℃（或底涂单独一烤）
     → 现用聚酯封闭胶（面胶，管贴膜）→ PMT 232℃
     → 凉到 L1 贴软膜
```

硬质必须仍过。软质水煮若变成 **面胶内聚裂、金属上还留底涂**，说明 P1 成立（油没把金属拔光）。若连底涂一起光板，底涂选错或太薄，不要加厚面胶。

**仍然不是办法：** 改膜、膜上处理剂、加厚面胶吃油、150℃ 补交联、先换腈胶、只把 DOP 改成 DOTP。

没有「第五种灵药」。膜不动，只能 **少接（冷却）+ 少吃（织密）+ 油到了金属还有底（P1）**。

**水煮操作（软硬都用这一套，才能比）：**

1. **23℃/50%RH 养满 24 h** 才煮。  
2. 去离子水 **100±2℃ × 60 min**；竖放不贴壁。  
3. 淋凉吸干，**30 min～1 h 内**剥。自发揭 ≥10% 失败。  
4. 不封边为主。硬质对照与软质必须同炉、同锅。

### 3.6 金属湿底涂 P-W（仅硬质也掉时才开）

硬质水煮没有问题，**本轮不开 M 组**。若某天硬质也从金属揭，再按转化 / 硅烷 1%～2% / 环氧 3～8 μm 做，且必须仍带硬质对照。

### 3.7 明确不要做的

| 动作 | 为什么不是克服 |
|------|----------------|
| 硬质已过还先改金属（硅烷、厚环氧、换脱脂） | 混淆变量；硬质会告诉你金属没坏 |
| 先换成腈胶 | 232℃ 硬质已过，胶族对 |
| 再做一次 150℃「补交联」 | 产线已经 232℃，K1 过时 |
| 软膜进 232℃ 烘道 | 膜毁、油一次赶进胶 |
| 出炉不测贴辊温度就贴 | 带温是本轮变量 |
| 加厚主胶挡油 | 交联网络照样被酯泡 |
| 只用热塑丙烯酸 / SIS / SBS | 增塑剂是溶剂；沸水更溶 |
| 整膜 DOTP 替换 DOP 就宣布解决 | 软质仍有单体储库 |
| 膜上做处理剂 / 改膜结构 | **本现场不可行，已关** |
| 出炉就水煮 | 胶没熟，硬质也可能被带掉 |
| 只看干态 / 只做胶带 | 现场是软质水煮 M |

## 四、推荐工艺链（实验室可落地）

```
卷材：现用清洁 + 聚酯封闭胶 + PMT 232℃（冻结）
  → 出炉 MEK 擦 20 次应不掉（校炉）
  → 记下贴辊板温
  → L1：凉到 ≤100℃ 再贴软膜（硬质对照同带温）
  → 养满 24 h → 水煮 100±2℃ × 60 min
L1 仍掉：G1 = 高羟值聚酯先替 30% 低羟值，封闭 NCO 按共混总羟值重算到 NCO/OH 1.10～1.20。不先全代。只换聚酯不加 NCO 禁止。膜不动。
```

软硬同胶、同 PMT、同锅煮。232℃ 炉里不准有软膜。

---

## 五、怎么测

| 顺序 | 测什么 | 方法 | 算不算数 |
|------|--------|------|----------|
| 贴合前 | 金属底涂是否咬住 | 划格 GB/T 9286 | 过程检。金属不合格不要贴 PVC |
| 贴合前 | PVC 贴合面是否“有油” | 水膜是否连续；可选 ATR 酯羰基约 **1720 cm⁻¹** | 过程检 |
| 贴合后主数据 | 复合牢度 | **180° 剥离**，15 mm 或 25 mm 宽，GB/T 2790 / GB/T 2791 | **验收** |
| 必须写 | 失效面 | V / C / M / X / P | 决定改哪一侧 |
| 后期 | 增塑剂第二波 | 24 h + **72 h** + **70℃×24 h** | 防隔天掉 |
| 金属湿预筛 | 同上 | 40℃ 去离子水 24 h 后再剥 | 预筛。不过则先别煮 |
| **水煮（本项目验收）** | 复合样 | **100±2℃ × 60 min**，不封边为主；记录是否自发揭、再 180° 剥 | **验收**。失效必须写 M/V/C |

剥离本项目锁定：**25 mm 宽 × 100 mm/min**（GB/T 2790）。中途不许改档。划格、胶带只作过程检，不算水煮验收。

水煮操作见 3.5。自发揭 ≥10% 该组失败。硬质对照不过 → 整炉作废（金属被改坏或未养 24 h）。

### 5.1 必须做的对照（烘道 232℃、胶种、金属都冻结）

| 开？ | 代号 | 唯一差别 | n |
|------|------|----------|---|
| 必做 | H0 | 硬质 + 现用贴辊带温 | 每炉 1～3 |
| 必做 | H1-L0 | 软质 + 现用贴辊板温（写 ℃） | 3 |
| **必做** | H1-L1 | 软质 + 贴辊 ≤100℃ | 3 |
| L1 仍 M | H1-G1 | 高羟值聚酯 30% + NCO 按总羟值重算 | 3 |

出炉后、贴膜前 MEK 20 次：掉了先校 PMT。  
L1 接近 H0 → 过门，锁贴辊上限。L1 仍 M → G1。干态变 V → 贴辊略回升或 G1 减半。  
H0 也掉 → 停。

### 5.2 怎样才算已经克服

| 样 | 水煮 60 min | 失效面 |
|----|-------------|--------|
| H0 硬质 | 继续没有问题 | 不是大面积 M |
| H1-L0 现用贴辊带温 | 对照 | **不作为合格工艺** |
| H1-L1 或 L1+G1 | **不自发揭**；≥ 同炉硬质 90% | 金属不得大面积光板 |

未给软膜 phr、金属厚度前不报牛顿数。只报相对硬质 H0 的百分比和失效面。

## 六、和原方案怎么对应（避免套错配方）

| 原方案做法 | PVC–金属这里 |
|------------|--------------|
| PE 型 CPO + EAA 超薄底涂 | 不要替换现用聚酯封闭胶 |
| PE 的 80℃×20 min | **不要套卷材**；本线 PMT 232℃，胶已交联 |
| V1.3 的 K1 补交联 | **作废**；232℃ 已经解封 |
| 底涂必须薄（0.5～2 μm） | 金属底涂仍薄；**主胶 15～30 μm**，再厚就吃油失败 |
| 酰胺共挤贴合层 15～25 μm、零酰胺 | 增塑剂贴合皮层 **25～40 μm**、聚合型/低 phr |
| 擦完再预热 = 白擦 | 擦完再预热 PVC = 白擦；只热金属 |
| 酚醛加在 MAH-CPO 里不消灭酰胺 | 酚醛加在腈胶里 **不消灭增塑剂**；只可能补金属侧 |
| 24 h 验收、72 h / 70℃ 防假合格 | 原样沿用，本问题更必须 |
| 胶带 / 划格 ≠ 流延剥离 | 胶带 / 划格 ≠ PVC–金属剥离 |
| 40℃ 浸水划格 | **预筛**；本现场以水煮 60 min 为准 |
| 硅烷/环氧当金属主膜 | 硬质已过则 **本轮不要做**；硬质也掉再开 |

---

## 七、工作目标

1. 锁定：卷材 PMT 232℃，聚酯封闭胶已交联；只有软质水煮掉。  
2. 先写贴辊板温，做 L0/L1。  
3. L1 不够再 G1（加密交联）。膜不改、膜上不涂处理剂。

## 九、风险

| 风险 | 可能性 | 影响 | 应对 |
|------|--------|------|------|
| 膜改不了且膜上不能做处理剂 | 已锁定 | 只能 L+G | 贴辊降温 + 胶侧加密交联 |
| 80℃ 对 2K 交联不够 | 中 | 24 h 假好、72 h 掉（胶没熟，不像增塑剂） | 拉 NCO/OH 对照；没熟是 C 且 H0 也掉 |
| 腈胶溶剂咬软 PVC 过深 | 中 | PVC 溶胀、尺寸变 | 表干再贴；换 2K PU |
| 钢闪锈 / 水煮锈印 | 高 | 整层 M | 2 h 内涂；M-Zr + P-W |
| 未养 24 h 就水煮 | 高 | H0 也掉，误判胶种 | SOP 卡死时点 |
| 硅烷过期水解液 | 中 | 假底涂 | 4 h 内用完，浑浊作废 |
| 把 PE 方案配方直接涂上 PVC | 中 | 全面失败 | 本文件第六节对照表 |
