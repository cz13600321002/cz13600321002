## 张总本人（3 分钟，不代操作）

### A. 联通号必须开通 5G

手机营业厅 / 联通 App：

1. 登录本机这张联通卡的号
2. 搜「开通 5G」或进 5G 专区 → **开通 5G 功能**（不是只买流量包）
3. 若提示「终端不支持」，忽略，继续开通；Pixel 非国行名单常误判
4. 开通后等 5–15 分钟，再做下面 B/C

话术（打 10010）：`我这张号帮我开通 5G 功能，不要改套餐。手机是 Pixel，系统提示终端不支持也请开通。`

### B. 双卡隔离（只关数据，不注销 Tello）

设置 → 网络和互联网 → SIM：

1. **默认移动数据 = 联通**
2. Tello 那张：**关闭「移动数据」**，套餐、钱包、eSIM 都不要动
3. 联通：漫游开着（国内漫游）、5G 开关开着

测通 5G 后再决定要不要把 Tello 数据开回去。双卡同时开时 Pixel 常把副卡钉在 LTE。

### C. 隐藏菜单锁 NR/LTE

拨号 `*#*#4636#*#*` → Phone information → **选联通这张**：

1. Set preferred network type = **NR/LTE**（有则选 NR/LTE/GSM/WCDMA）
2. 打开 Mobile radio power 关再开一次
3. 看 IMS 页：Registered / Voice over LTE Available 为佳；未注册先做 D

## D. Pixel IMS / TurboIMS（界面开关没跳上时必做）

盘里已有旧包（2025-12）：

- [Pixel IMS 1.3.0](https://drive.google.com/file/d/16t0XsiXJlRdIBZ5WzRWlPw3agvPSq3P9/view)
- [Pixel IMS 1.2.8](https://drive.google.com/file/d/177nPIJpmMQQVdah_rGcONG5kl7fkl3E5/view)

2025-12 以后系统补丁常把旧 Pixel IMS 打残（VoLTE 能开、5G 不能）。优先用现维护的 **TurboIMS**：https://github.com/wumingleo/ims

步骤：

1. 安装 [Shizuku](https://shizuku.rikka.app/)，无线调试配对，状态「正在运行」
2. 装 TurboIMS 或能用的 Pixel IMS，授权 Shizuku
3. **只选联通卡**（不要写 Tello）
4. 把 VoLTE、VoNR、5G NR 从关拨到开（已开也关再开一次）
5. 专家/手动设置：找到 `carrier_nr_availabilities_int_array`
   - 旧值常是 `[1]`（只 NSA）
   - 删掉重建为 **1,2**（NSA + SA）。联通城域多为 SA（n78）
6. 若补丁后没流量：APN 名称「联通」，APN=`wonet`，APN 类型 `default,supl`。不行再试 `3gnet`
7. 飞行模式 10 秒，看状态栏

重启后若开关消失：不要刷机，重做 D 第 3–7 步。
