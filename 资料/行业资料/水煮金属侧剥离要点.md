# 水煮时胶+膜从金属侧剥离

**日期：** 2026-09-05  
**配套方案：** `文档/方案/20260905_PVC膜与金属板增塑剂影响克服方案.md`（V1.3）  
**已锁定：**

- 只有软质 PVC 水煮从金属揭；硬质没有问题  
- 主胶是 **聚酯树脂 + 封闭型异氰酸酯**

---

## 1. 为什么是这套胶、又只有软质掉

聚酯胶认金属、认 PVC，硬质能过，说明胶族对。  
封闭异氰酸酯要热到解封温度才交联；**80℃×20 min 对 MEKO/己内酰胺基本开不开。**  
软质增塑剂（酯类）专泡未交联或交联不足的聚酯，油+水走到金属侧，整张揭。硬质没油，热塑聚酯还能咬住。

---

## 2. 当天第一枪（只改顺序）

金属、胶种、膜配方都冻结。

| 组 | 做法 |
|----|------|
| H0 | 硬质 + 现用顺序（必须仍过） |
| H1-K0 | 软质 + 现用顺序（对照） |
| **H1-K1** | 胶只涂金属 → 烘到解封 → MEK 擦 20 次不掉 → **再**低温贴软膜 |

K1 烘温：胶厂解封温度；未知先 **150℃×15～20 min，软膜不进炉**。  
K1 过 → 主因是没交联。K1 仍掉 → 再 H2/B1。  
软膜贴上再高温烘：不作数。

---

## 3. 不要先做什么

| 不要 | 要 |
|------|----|
| 先换成腈胶 | 用好现有聚酯封闭胶 |
| 先改金属硅烷/环氧 | 硬质已过 |
| 加厚胶 | 不解封则更易被泡 |
| 软膜陪着去 140℃+ | 油一次赶进胶 |

---

## 4. 数字

| 项 | 规定 |
|----|------|
| 解封（未知时实验室） | 150±5℃ × 15～20 min，只烘金属 |
| 交联确认 | MEK 轻擦 20 次不露金属、不发黏 |
| 贴软膜 | 只热金属 60～90℃ |
| 水煮 | 养满 24 h，100±2℃ × 60 min |
| 干膜 | 15～30 μm，不因水煮加厚 |
