# 水煮时胶+膜从金属侧剥离

**日期：** 2026-09-05  
**配套方案：** `文档/方案/20260905_PVC膜与金属板增塑剂影响克服方案.md`（V1.1）  
**配套框架：** `文档/方案/20260905_粘合问题通用框架.md`

---

## 1. 这句话怎么翻译成界面

「水煮的时候胶层会和 PVC 从金属基材侧剥离」=

- 揭下来的是 **胶 + PVC 还连在一起**
- 金属板上 **大面积光亮或只有水渍/锈印**
- 失效代码 **M**（金属/胶），不是 V（PVC/胶）

PVC/胶过了沸水，金属/胶没过。先改金属侧。

---

## 2. 热水在金属界面做什么

| 机制 | 操作含义 |
|------|----------|
| 水分子顶掉氢键、羧酸盐 | 只靠 EAA/CPO 羧基的底涂，干态好、沸水掉 |
| 沿氧化层爬、切口进水 | 不封边样先掉；针孔底涂更快 |
| 胶未交联就被煮 | H0 也会掉，与 PVC 无关 |
| 增塑剂+水一起到金属 | H0 过、H1 仍 M → 要隔离，不是只换硅烷 |
| 钢闪锈、渗水腐蚀 | 揭开面有锈，先转化+2 h 内涂 |

100℃ 比 40℃ 浸水狠一档。40℃ 过了不能宣布耐水煮。

---

## 3. 当天怎么做（六步）

1. 养满 24 h 的旧工艺样，水煮 60 min，确认失效是 M。  
2. 同一主胶、同一软 PVC：M0（只脱脂）vs M-Zr+Si（转化+硅烷），各 3 片。  
3. 有低增塑膜就加 H0 水煮，按方案第〇节分流。  
4. M-Zr+Si 仍 M → 换 M-Ep（环氧 3～8 μm），不要加厚主胶。  
5. H0 过、H1 仍 M → P-W 留下，再上隔离或低迁移贴合层。  
6. 过门才填工艺卡：转化、硅烷批号、养 24 h、水煮 60 min 不自发揭。

---

## 4. 数字

| 项 | 规定 |
|----|------|
| 水煮 | 去离子水，100±2℃，默认 60 min；30 min 只快筛 |
| 养护 | 贴合后 23℃/50%RH **≥24 h** 才煮 |
| 取出 | 淋凉、吸干，30 min～1 h 内剥 |
| 自发揭 ≥10% | 该组失败 |
| 硅烷 | 1%～2%，pH 4～5，4 h 内用完 |
| 环氧 P-W | 3～8 μm，>10 μm 禁止当本方案答案 |
| 磷酸酯 | 仅 P-E，0.8%～1.5%，常不够沸水 |
| 主胶 | 仍 15～30 μm，不因水煮加厚 |
