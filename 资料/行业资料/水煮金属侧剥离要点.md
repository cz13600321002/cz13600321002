# 水煮时胶+膜从金属侧剥离

**配套方案 V1.4**  
**已锁定：** 只有软质掉；硬质过；聚酯+封闭异氰酸酯；**卷材板温 232℃**。

---

## 1. 232℃ 意味着什么

PMT 232℃ 已超过所有常用封闭剂解封温度。胶在贴膜前已经交联。  
软 PVC 进不了这支炉。V1.3 的「K1 先补交联」**作废**。

硬质过 = 交联和金属够用。软质仍从金属揭 = 酯类增塑剂钻进**已固化聚酯**，出炉带温越高钻得越快。

---

## 2. 当天第一枪

烘道 232℃、胶、金属都冻结。只改贴辊处板温。

| 组 | 做法 |
|----|------|
| H0 | 硬质 + 现在的贴辊带温 |
| H1-L0 | 软质 + 现在的贴辊板温（必须写出 ℃） |
| **H1-L1** | 软质 + 贴辊 **≤100℃**，压力相同 |

出炉、贴膜前：MEK 轻擦 20 次应不掉；掉了先校炉。  
L1 过 → 锁贴辊上限。L1 仍掉 → H2/B1。  
实验室：板烘到 232℃，**冷却到规定温度再贴**，不要用 150℃ 冒充本线。

---

## 3. 如何减少增塑剂影响

| 效力 | 做法 | 数字 |
|------|------|------|
| 一 | 贴合皮层少油/聚合型 | 25～40 μm；单体 0 或比芯层低 ≥10 phr |
| 二 | 软膜贴合面交联隔离 | 3～8 μm，MEK 不掉再贴；不进 232℃ 炉 |
| 三 | 贴辊降温 | L1 ≤100℃ |
| 无 | 加厚聚酯、补交联、DOTP 替换 DOP、擦完热贴 | — |

## 4. 不要

先换腈胶；再做 150℃ 补交联；软膜进 232℃ 炉；不测贴辊温度；加厚胶。
