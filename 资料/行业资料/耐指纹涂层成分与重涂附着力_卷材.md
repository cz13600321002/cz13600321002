# 耐指纹涂层：成分、重涂掉漆机理、卷材线处理路线

查表用，不是投料单。牌号与温度一律按本厂 TDS 或炉上实测核对，核对不一致以本厂纸为准。

**一句话结论：** 耐指纹涂层是被**故意**做成低表面能的（氟 / 聚硅氧烷 / 蜡），所以重涂掉漆是设计的结果，不是工艺没调好。要优良附着力只有四条路——**源头换可涂装型耐指纹（F）> 洗掉重做钝化（R）> 在线活化 + 桥接底漆（A+P）> 只擦溶剂（没用）**。能跟客户谈掉涂装面的耐指纹要求，就不要走 A+P。

---

## 一、先分清是哪一种"耐指纹"

两种东西都叫耐指纹，可涂装性差一个数量级。**没分清就打样 = 废样。**

| | A 类：金属卷材耐指纹膜（AFP） | B 类：电子 / 玻璃 AF 涂层 |
|---|---|---|
| 场景 | 镀锌板、镀铝锌板、不锈钢；家电背板、电脑机箱、电子支架 | 手机盖板玻璃、面板、装饰件 |
| 工艺 | 辊涂（chemcoater），卷材线一道 | 真空蒸镀 / 浸涂 / 喷涂 |
| 干膜 | **0.6～1.5 μm**（常见 0.8～1.2） | **5～20 nm** |
| 固化 | PMT 约 150～220℃ | 室温～150℃ 熟化 |
| 水接触角 | 85～105° | 110～118°（油角 65～70°） |
| 表面能 | 约 22～32 mN/m | 约 10～14 mN/m |
| 能否重涂 | 难，但有路（本文主体） | **基本不可能，必须彻底去除** |

卷材来料 99% 是 A 类。但 A 类里**含氟型**的难度接近 B 类，判定方法见第五节。

B 类典型化学：全氟聚醚硅烷（PFPE-silane），如大金 Optool DSX / UD509、信越 KY-130 / KY-1903、3M Novec 系列。遇到这类，直接写"不可重涂"，不要试底漆。

## 二、A 类耐指纹膜的主要成分

水性体系为主（家电 / 电子板几乎全是水性）。下表按固体份计。

| 组分 | 固体份占比 | 常见化学 | 在膜里干什么 | 对重涂的影响 |
|---|---|---|---|---|
| **成膜树脂** | 30～60% | 自交联水性丙烯酸乳液；水性聚氨酯（PUD）；环氧-丙烯酸；聚酯改性丙烯酸 | 成膜、柔韧、加工性 | 中性。含羧基（氨/AMP-95 中和）→ **碱可洗**，这是路线 R 的基础 |
| **无机硬相** | 10～40% | 硅溶胶（日产化学 Snowtex ST-30 / ST-O 一类）、气相 SiO₂、胶体氧化铝 | 硬度、耐污、挡住指纹油渗入 | 表面高度缩合的 Si–O–Si 几乎没有可反应基团 → **惰性面**（机理 3） |
| **钝化 / 防锈** | 2～10% | 无铬型：氟锆酸（H₂ZrF₆）、钛酸盐、钒酸盐、钼酸盐、磷酸二氢铝、单宁酸、植酸。老配方：Cr(VI)/Cr(III) | 耐蚀、白锈 | 中性。但 **洗掉 AFP 等于同时洗掉它**，必须补做（第四节） |
| **硅烷偶联剂** | 1～3% | KH-560（环氧基）、KH-550（氨基）、乙烯基硅烷 | 与锌层成化学键 | 中性，自身是好东西 |
| **润滑剂** | 1～5% | 聚乙烯蜡乳液、PTFE 微粉、硬脂酸盐、有机硅蜡 | 冲压 / 折弯润滑、耐划伤 | **重涂第一杀手。** 成膜时自动迁移到空气界面富集，形成脱模层 |
| **低表面能剂** | 0.1～2% | 含氟丙烯酸酯、全氟聚醚、聚二甲基硅氧烷（PDMS） | 真正的"耐指纹"手感、防污 | **重涂第二杀手，也是最顽抗的一支** |
| 交联剂 | 3～10% | HMMM（六甲氧基甲基三聚氰胺）、封闭异氰酸酯、噁唑啉、碳化二亚胺、Zr/Ti 螯合物 | 耐水、耐溶剂 | 过量 → 表面无残余 –OH，重涂无处成键 |
| 导电填料（导电型） | 0～10% | 炭黑、ATO、石墨 | 需接地 / EMI 的机箱板要导通 | 中性 |
| 助剂 | <2% | 聚醚硅氧烷或氟碳润湿流平剂、消泡、增稠、pH 调节 | 涂布外观 | 硅 / 氟型流平剂同样富集表面，等同第二杀手 |

**关键认知：** 蜡、氟、硅在干燥成膜过程中会**自发向空气界面迁移**。所以阻碍重涂的不是整个 1 μm 膜，而是顶部几 nm～几十 nm 的富集层。这决定了处理策略——**不一定要洗掉整膜，但必须破掉这一层，并且破完马上涂。**

## 三、重涂掉漆的四个机理（分开诊断，不要混着治）

| 编号 | 机理 | 外观表现 | 剥离破坏面 | 对症手段 |
|---|---|---|---|---|
| 1 | **润湿失败** — 涂料表面张力高于基面临界润湿张力 | 涂不满、鱼眼、缩孔、缩边 | 还没到附着力问题 | 降涂料表面张力 + 清洁（第六节 P-1） |
| 2 | **弱界面层** — 顶部氟/硅/蜡脱模层 | 涂膜完整漂亮，干态可能还过 0 级 | **整片干净剥离，涂膜背面光亮，基面仍有灰色 AFP** | 活化破层（第五节 A3～A5）或洗掉（R） |
| 3 | **无反应基团** — AFP 已全固化、硅溶胶高度缩合 | 同 2，水煮后明显 | 同 2 | 活化引入极性基 + 偶联剂成键（P-2） |
| 4 | **AFP 自身内聚 / 与锌结合弱** — 薄硬膜被涂料固化收缩拉掉 | 大块剥落、带碎片 | **剥离面露出锌光泽，并带走 AFP 碎片** | 加强涂料没用，**改走路线 R** |

**诊断只看破坏面，不看等级数字。** 百格 3 级这个数字不告诉你该干什么；"背面光亮 / 带走锌"才告诉你。每块样必须拍破坏面照片。

## 四、决策树：先定走哪条路，再谈配方

**第一个要问客户的问题：成品的涂装面还要不要耐指纹和导电？**

```
涂装面还要耐指纹/导电吗？
├─ 不要
│   ├─ 能换料 ────────→ 路线 F：直接要无耐指纹的裸钝化板（最省钱）
│   └─ 不能换料 ──────→ 路线 R：洗掉 AFP + 重做钝化 + 常规彩涂
├─ 只有背面要 ─────────→ 要求供方单面涂 AFP，或单面碱洗
└─ 涂装面也要保留
    ├─ 能影响供方配方 → 路线 F：可涂装型耐指纹（欠固化 / 无氟 / 高羟值）
    └─ 不能 ──────────→ 路线 A + P：在线活化 + 桥接底漆（并接受上限，见下）
```

**路线 A+P 的上限要提前讲清：** 干态划格做到 0～1 级可行；但**水煮 2 h、湿热 240 h 后掉片的风险显著高**于 R 和 F。不要用干态 0 级下"能出货"的结论。

## 五、路线 R（去除）与路线 A（活化）

### 5.1 路线 R — 洗掉 AFP

AFP 树脂多为含羧基水性丙烯酸 / PUD，**碱可溶或碱可解**，所以碱洗是主力，不是辅助。

1. **碱洗**：NaOH / 硅酸钠型脱脂剂，pH 12～13，浓度 2～5%，**55～65℃**，喷淋 10～30 s（按线速配段长）。
2. **刷辊**：卷材线脱脂段的 brush roll 必须开。单靠喷淋洗不净硅溶胶残留。
3. **水洗**：两级逆流 + 去离子末洗，末洗水电导 **≤30 μS/cm**。
4. **洗净验证（涂前必做）**：水接触角 **≤20°**、达因 **≥54**。洗净的裸锌面应接近完全润湿；**接触角仍 >60° = 没洗净，不要开涂。**
5. **必须重做化学转化**：硅烷 / 锆钛无铬钝化或磷化，烘干板温 ≤80℃。
6. 之后按常规彩涂：底漆 5 μm → PMT 216～224℃ → 水淬 → 面漆 → PMT 232～241℃ → 水淬。

> **最常见的翻车点：洗掉 AFP 等于把钝化层一起洗掉，耐蚀性归零。** 漏补钝化的典型症状是涂装 24 h 后起泡、盐雾几十小时就蔓延。这一步没有例外。

### 5.2 路线 A — 保留 AFP 并活化

强度递增，按需要往下选。括号内达因提升是量级参考，必须本厂实测。

| 级别 | 手段 | 卷材线可行性 | 达因提升 | 代价 / 注意 |
|---|---|---|---|---|
| A0 | IPA / 乙醇擦拭 | 仅试片 | +0～4 | **只去浮尘，去不掉键合的氟硅。单靠这个必败，可作空白对照** |
| A1 | 弱碱洗 pH 10～11，45～55℃ | 高（现有脱脂段即可） | +6～12 | 可能发花；浓度过头就变成半去除 |
| A2 | 刷辊轻磨（尼龙磨料 / Scotch-Brite 320～600 目） | 高 | +8～15 | 划痕外观、膜厚减薄、粉尘需吸除 |
| A3 | 电晕（接地背辊） | 中（金属基材需专用电极设计） | +8～14 | **衰减快**，必须在线紧接涂布 |
| A4 | 火焰（氧化焰，空气过量） | 中 | +10～20 | 板温 / 卷曲风险，薄规格慎用 |
| A5 | **常压等离子（APPJ，空气或 N₂）** | 中-高，可配 20～60 m/min | +15～25，接触角可到 <30° | 设备投入、喷头维护；宽幅需喷头阵列，否则边中不均 |
| A6 | UV / 准分子 172 nm + 臭氧 | 中 | +10～20 | 需惰性气氛罩 |

**三条铁律：**

1. **活化有时效（疏水恢复）。** 等离子 / 电晕后 1～4 h 内表面能明显回落——体相里的低分子量氟硅会重新迁移到表面。所以活化站与涂布头之间 **≤60 s**。**离线活化、隔天涂布 = 等于没活化**，这是最容易白做一轮的地方。
2. **涂前门槛**：达因 **≥42**（目标 ≥46），水接触角 **≤50°**。不到就停线，不要涂了再看。
3. **含氟型判定**：A5 做完接触角仍 >60°，判定为含 PFPE / 含氟丙烯酸型。**放弃保留路线，改 R。** 继续加底漆只是浪费样板。

## 六、路线 P — 桥接底漆（活化之后仍然需要）

单靠活化很少够。底漆要同时解决三件独立的事，**不要指望一个助剂全包。**

### P-1 让涂料润湿得下去

- 润湿剂：聚醚改性硅氧烷（BYK-306 / 307 / 333、Tego Wet 一类）**0.1～0.5%**；或氟碳型（BYK-3440、Capstone FS 一类）**0.05～0.2%**。
- 收尾溶剂走低表面张力、慢挥发：异佛尔酮、二乙二醇丁醚、Texanol、环己酮。
- **副作用**：硅氧烷过量会把问题推给下一层（面漆层间附着变差）。**只在底漆加，面漆不加或换非硅型。**

### P-2 让底漆和 AFP 面成键

- **硅烷偶联剂 0.5～2%**：KH-560（环氧基，配羟基 / 羧基面）、KH-550（氨基，配环氧 / NCO 体系）。**先预水解**：醇/水 95/5、醋酸调 pH 4～5、熟化 30 min 再入漆，直接倒桶效果打折。
- 有机钛酸酯 / 锆酸酯（TC-114、NZ-12 一类）0.3～1%。
- 活化后表面有 –OH / –COOH 时，底漆带 HMMM 或封闭 NCO，固化时直接共价接上。
- 面对硅溶胶为主的无机面，**环氧-聚酯 / 环氧-酚醛骨架的亲和性优于纯聚酯**。

### P-3 把应力解耦

- 底漆做低模量高延伸，减少固化收缩把 1 μm 薄 AFP 整层撕掉（机理 4 的诱因之一）。
- 底漆**薄涂 3～6 μm**，不要靠厚度找安全感，厚涂只是积应力。

### 候选底漆骨架（按试验优先级）

| 代号 | 骨架 | 加料 | 膜厚 / PMT | 适用 |
|---|---|---|---|---|
| **P1** | 环氧-聚酯 / HMMM | 1% KH-560 + 0.2% 氟碳润湿剂 | 5 μm / PMT 216～224℃ | 首选，对硅溶胶面亲和好 |
| **P2** | 含羧基聚酯 + 封闭 NCO（BL 3175 或 TS3102/HY-1070） | 1% KH-550 | 5 μm / PMT 232℃ | 柔韧、T 弯好 |
| P3 | 氯化聚烯烃（CPO） | — | 3～5 μm | **只在确认弱界面是蜡 / 聚烯烃型时用，对氟硅无效** |
| P4 | 2K 水性 PU + 氨基硅烷 | — | 5 μm / 低温 | 低温线、不能上高 PMT 时 |

> **P2 的前置核对（对齐本厂已有结论）：** BL 3175 SN 不加催化剂约需 **PMT 241℃** 才充分解封，本厂炉温已锁 **232℃**；TS3102（HY-1070，IPDI 五聚体，供应当量 ≈408）与 3175（≈380）**不是 1 kg 换 1 kg，同 NCO 摩尔要多称约 7%**。走 P2 前先确认有无锡催化剂，不要为此改炉温。详见 `资料/行业资料/PVC卷材胶原料羟值与NCO.md`。

## 七、路线 F — 最优解：改耐指纹本身（源头）

如果能影响钢厂 / 耐指纹涂料供方，这是**唯一能同时拿到附着力和水煮稳定性**的路。向供方提"可涂装型 / 可重涂型耐指纹"，技术要求写死：

1. **去氟、去 PDMS 流平剂**；蜡降到 ≤1%，或改用内润滑树脂。
2. **羟基过量设计**：羟值 40～80 mgKOH/g，交联剂欠量，固化后留残余 –OH 给第二层反应。
3. **欠固化（B-stage）**：AFP 固化 PMT 从约 200℃ 降到 **160～175℃**，固化度 60～80%，表层留活性基团；重涂后在**第二道炉**完成全固化。卷材线天生两炉两涂头，这是**零设备投入**的做法，优先谈这一条。
4. 加 2～3% 环氧硅烷做自偶联。
5. 表面能设计目标 **≥38 mN/m**。

**代价要和客户讲明：** 这是用一部分耐指纹性能换可涂装性。先确认成品的耐指纹要求落在哪一面、用什么方法考核（人工汗液 / 指纹油擦拭次数），再定让多少。

## 八、卷材线布置

### 8.1 在线一体（有耐指纹涂头，最佳）

```
开卷 → 缝合 → 碱洗/脱脂 → 水洗 → 钝化(硅烷/锆钛) → 干燥
  → 耐指纹辊涂（欠固化 PMT 165±5℃）→ ★不水淬
  → 底漆辊涂 3～5 μm → 炉 PMT 224℃ → 水淬
  → 面漆 → 炉 PMT 232～241℃ → 水淬 → 收卷
```

两个要点：**耐指纹欠固化**（留活性基团），**耐指纹后不水淬**（水淬会冲走表层亲水基并促进再疏水）。

### 8.2 离线重涂（来料已是成品耐指纹板，最常见）

```
开卷 → 碱洗（pH 按路线 R 或 A1 定）→ 刷辊 → 水洗×2 → 去离子末洗
  → 热风干燥（板温 ≤80℃）→ ★达因在线检测站
  → 等离子/电晕/火焰活化 → ≤60 s → 底漆辊涂 → 炉 → 水淬
  → 面漆 → 炉 → 水淬 → 收卷
```

两个要点：**达因检测站放在活化之后、涂布之前**，不合格就停线；**活化到涂布 ≤60 s**。
走路线 R 时，在"去离子末洗"后面补**钝化 + 干燥**段。

## 九、检验与判定

| 项目 | 方法 | 判定 |
|---|---|---|
| 涂前表面能 | 达因笔（梯度液）≥3 点 / 水接触角 | 保留路线：达因 **≥42**、接触角 ≤50°；去除路线：达因 **≥54**、接触角 ≤20° |
| 划格附着 | GB/T 9286（ASTM D3359） | **0 级**；1 级须评审 |
| T 弯 | 彩涂 T-bend | ≤2T 无脱落 |
| 杯突 | GB/T 9753 Erichsen 6 mm | 无剥离 |
| MEK 双擦 | ASTM D5402 | 面漆 ≥50 次 |
| **沸水** | 水煮 2 h，取出 1 h 内划格 | **0～1 级，无起泡发白** |
| **湿热** | 40℃ / 100%RH × 240 h | 无起泡，划格不降级 |
| 中性盐雾 | GB/T 10125 | 按客户；划线蔓延 ≤2 mm |
| 破坏面 | 目视 + 照片（必要时显微） | **必须逐样记录**，按第三节判机理 |

> **最严的一关是水煮和湿热，不是干态划格。** 低表面能界面干态经常能过 0 级，水煮 2 h 整片掉。**干态 0 级不构成可出货的结论。**

## 十、排查表

| 现象 | 最可能原因 | 先做什么 |
|---|---|---|
| 涂不满、鱼眼、缩孔 | 润湿不足 / 油污 | 先测达因、先查清洁。**不要先加润湿剂** |
| 干态 0 级，水煮整片掉，涂膜背面光亮 | 弱界面层（氟/硅/蜡，机理 2） | 活化升到 A5；无效改路线 R |
| 剥离面露锌、带走 AFP 碎片 | AFP 自身内聚或与锌结合弱（机理 4） | **别再加强涂料**，改路线 R |
| 活化当天好、隔天差 | 疏水恢复 | 活化→涂布 ≤60 s，禁止离线存放过夜 |
| A5 后接触角仍 >60° | 含氟型 AFP | 判死保留路线，改 R |
| 边部好中间差（或反之） | 活化 / 碱洗宽幅不均 | 查等离子喷头阵列、喷淋覆盖；达因至少测 3 点 |
| 洗净后涂装 24 h 起泡、盐雾速蔓延 | 漏补化学转化 | 补钝化段 |
| 水煮后发白但不掉 | 底漆亲水过头（润湿剂 / 中和胺过量） | 降润湿剂，换氟碳型低添加量 |

## 十一、打样对照矩阵（建议第一轮）

同一批基材、同一面、同一炉、同一刮棒 / 涂头。

| 样号 | 前处理 | 底漆 | 要回答的问题 |
|---|---|---|---|
| AF-0 | 原样，不处理 | P1 | 空白：到底有多差 |
| AF-1 | IPA 擦 2 遍 | P1 | 证明溶剂擦没用（省掉后续争论） |
| AF-2 | 弱碱 pH 10.5 / 50℃ / 30 s | P1 | 碱洗单独贡献 |
| AF-3 | AF-2 + 600 目轻磨 | P1 | 机械贡献 |
| AF-4 | 等离子（或火焰） | P1 | 活化单独贡献 |
| AF-5 | 碱洗 + 等离子 | P1 | 叠加效应 |

每样记录：达因 / 接触角（涂前，3 点）、干膜、炉设定与膜面温度分开写、划格、**水煮 2 h 后划格**、破坏面照片。

**判定规则：** AF-R 是上限参照。若保留路线（AF-5 / AF-6）的**水煮后**结果达不到 AF-R 的 80%，不要推保留路线，直接向客户提路线 R 或 F。

## 十二、仍缺、打样前尽量补

- 来料耐指纹的**供方与型号**、是否含氟 / 含硅、干膜厚度、是否导电型、是否单面涂。
- 成品对**涂装面**的耐指纹与导电要求（考核方法、哪一面）。
- 现有卷材线有没有：刷辊段、等离子 / 电晕 / 火焰工位、达因在线检测、两炉两涂头。
- 碱洗段实际 pH、温度、喷淋段长与线速（算出实际接触时间）。
- 第二节各组分的占比是量级参考，**本厂不具备 AFP 配方权时不要按它反推来料**；判定来料只用接触角 + 等离子响应（第五节）。
