# 高附加值化工品：适合我们生产的品种筛选

- **整理日期**：2026-09-09
- **筛选依据**：对照本仓库已有业务（普乐美热封 / 卷材涂料 / 未电晕 PE 附着 / 酯溶 CPP / 家电抗指纹 / 2K 面涂），不是按"行业最热"排序
- **能力画像（从现有方案与周报还原）**：配方复配、酯溶/溶剂型胶粘剂与涂料、超薄底涂（1～2 μm）、80℃低温烘烤、PE/铝/钢多基材附着、小中试到百公斤级放量；**没有**烯烃聚合、电子级超净、万吨级树脂合成装置

---

## 一、先排除：不适合我们直接生产

这些是行业高附加值赛道，但属于"炼化/半导体材料巨头的游戏"，我们没有装置、催化剂、洁净车间和认证周期，硬上只会烧钱：

| 品种 | 为什么不适合我们 |
| --- | --- |
| MDI / TDI | 万华级一体化装置，单套投资数十亿，寡头垄断 |
| POE / EVA 树脂本体 | 茂金属催化剂 + 高压装置，万华刚打通 20 万吨级工业装置 |
| LCP / PEI / PEEK 树脂合成 | 金发、SABIC 级特种工程塑料聚合，千吨级起步且客户认证极长 |
| 光刻胶、电子特气、电子级氢氟酸 | 洁净度、金属离子 ppb 级，日本系卡住制高点 |
| 超纯 PFA、电子特气 | 氟化工全产业链 + 半导体认证 |
| LFP 正极、湿法隔膜基膜 | 电池材料重资产，客户绑定头部电芯厂 |
| PA12 单体/聚合 | 全球 CR4=99.5%，万华才刚做到 4 万吨 |

**原则：我们不造树脂，我们用树脂做配方。**

---

## 二、适合我们的：沿现有工艺往高附加值下游走

判断标准只有三条：①现有溶剂/复配/涂布能力能落地；②客户认证周期以月计而非年计；③单价和毛利明显高于普通热封/卷材大货。

### 首选 1：未电晕 PE + 金属 双基材超薄底涂（已在做，优先做成产品）

- **对应现有工作**：`PE型CPO + EAA` 超薄底涂（P-D / P-E），80℃×20min，目标 1～2 μm
- **为什么高附加值**：未电晕 PE 附着是包装、家电、铝塑复合里的老大难，能做到"同一配方打 PE 和金属"的供应商极少，售价可以按解决方案而不是按公斤卖
- **下游**：软包装复合、铝塑盖材、家电装饰件、未处理 PE 瓶/膜印刷底涂
- **下一步**：把实验室五组开刮做成可售牌号（酯溶、无甲苯、氯含量写清），不要停在方案阶段

### 首选 2：铝塑复合 / 电池软包用热封胶（EAA 路线的延伸）

- **能力匹配**：EAA（乙烯–丙烯酸，AA 6%～12%）本来就是铝箔挤出复合的标准热封层；我们已在底涂里用 EAA，热封主业也是这条链
- **为什么现在值**：新能源铝塑膜（电池软包）和储能软包对热封强度、耐电解液、绝缘的要求远高于普通食品盖材，单价高一个数量级
- **注意**：食品接触不要写进合同（仓库周报已有这条红线）；电池软包要单独做耐电解液、剥离力、绝缘测试，不要拿食品热封数据去报
- **现实路径**：先做"非食品、工业盖材 / 软包中试料"，再谈电芯厂二级供应商，不要幻想直接供宁德

### 首选 3：家电抗指纹 + 卷材高附着面涂（现有产线升级，不是新产品类）

- **能力匹配**：已有抗指纹（303 LF）、卷材、环氧光油、2K 面涂（–NCO / –OH）
- **为什么还能做高附加值**：家电和卷材大货在内卷，但"抗指纹 + 未处理基材附着 + 低温快烘"组合仍然稀缺；海外客户（印度 PVC 贴镀锌/铝、越南、墨西哥、韩国）要的是能贴住、能出货的配方，不是新树脂
- **升级方向**：把 P-E（酸改性 CPO + 磷酸酯）嵌进卷材/抗指纹体系，做成"免电晕、可过湿附"的出口牌号

### 次选 4：动力电池包 / 储能壳体用聚氨酯胶粘剂与导热结构胶

- **能力匹配**：已有 2K 面涂的 –NCO / –OH 交联经验；电池包聚氨酯解决方案是万华、巴斯夫在推的下游，但**胶粘剂配方**本身是中小企业能做的层
- **为什么相关**：AI 数据中心储能、液冷机柜、电池包底护板，需要结构胶、密封胶、导热胶，而不是 LFP 粉体
- **门槛**：UL / 阻燃 / 老化认证要花钱，但比建正极厂便宜两个数量级
- **建议**：等首选 1～3 有稳定出货后再开，不要并行铺太开

### 次选 5：光伏胶膜用底涂 / 助粘剂（不要去做 POE 树脂）

- **能力匹配**：POE/EVA 胶膜厂需要提高与玻璃、背板的粘结，常用酸改性聚烯烃底涂、硅烷、EAA 类助粘——正是 CPO/EAA 配方能力的邻域
- **不要做**：POE 本体、EVA 本体（卫星化学、万华的装置级生意）
- **风险**：光伏胶膜产能投放快，助粘剂也会跟着卷；只做差异化（低温、无甲苯、薄涂）才有利润

## 四、和每日简报的对应关系

每日跟踪里出现的"热门品种"，对我们的正确读法是：

- 看到 **POE/EVA 涨价** → 关心胶膜厂会不会来要助粘/底涂，而不是自己聚合
- 看到 **金发 LCP/PEI、液冷 UQD** → 关心算力机柜、液冷管路的密封胶和附着底涂
- 看到 **万华电池包聚氨酯** → 关心能不能做配套结构胶，而不是抢 MDI
- 看到 **铝塑膜 / 软包** → 直接对上我们的 EAA 热封主业
