# 粘合材料与胶种预判要点

**日期：** 2026-09-05  
**配套：** `文档/方案/20260905_粘合问题通用框架.md`（V1.1，含水煮金属侧）  
**用法：** 开工时查表填 `项目/进行中/粘合问题框架_2026/材料与胶种预判表.md`。表里没有的组合，先拆成「每一侧单独选」，再决定是否同一配方。

---

## 1. 单侧：基材要什么官能

| 基材 | 要的化学 | 典型形态 | 备注 |
|------|----------|----------|------|
| 未电晕 PE | 聚乙烯链互扩散 | PE 型 CPO、EAA、PE-g-MAH | PP 型 CPO 常不够 |
| PP / TPO | 聚丙烯链互扩散 | PP 型 CPO、PP-g-MAH | 保险杠料走这里 |
| TPU | 酸酐 / 羧基 / 氨酯氢键 | MAH-CPO、EAA、TPU 底涂 | 先查硅油隔离剂 |
| 软 PVC | 腈基 / 氨酯 / VAC；先抗增塑剂 | NBR、2K PU | 不要 PE 型 CPO 当主胶 |
| 硬 PVC、PET、ABS、漆面 | 极性匹配 + 可交联 | 2K PU、聚酯、丙烯酸氨基甲酸酯 | 看爽滑和脱模剂 |
| 铝 | 羧基 / 酸酐 / 磷酸根；**水煮还要共价/螯合** | EAA、酸改性 CPO、磷酸酯 ≤1.5%；水煮加硅烷或 3～8 μm 环氧 | 碱脱脂；40℃ 预筛；沸水单独验 |
| 钢 | 同上 + 防闪锈 | 同上；**锆钛转化优先** | 2 h 内涂；水煮见锈印先停 |
| 流延 TPE | 能被熔体再软化的聚烯烃链 | 热塑性 MAH-CPO、SEBS-g-MAH | 交联皮 = 焊不住 |
| 硫化橡胶 | 同族或酚醛增黏 | NBR/CR 胶 | 喷霜当迁出物处理 |

## 2. 双侧组合：先选哪条主路线

| 侧 A | 侧 B | 主路线（先做） | 备选 | 禁止先做 |
|------|------|----------------|------|----------|
| 未电晕 PE | 涂料/油墨 | PE 型 CPO:EAA = 70:30，干膜 0.5～1.5 μm + 羟基丙烯酸或 2K PU 面涂 | 单涂内加 CPO | 环氧/硅烷主膜 |
| 未电晕 PE | 铝/钢 | 酸改性 CPO + EAA（P-D）；湿附着再加磷酸酯（P-E） | 允许分配方时金属走环氧 | 只拿普通 CPO；P-E 当「只保 PE」的配方 |
| TPU | 流延 TPE | MAH-CPO 热塑性 0.5～1.5 μm，80℃ 烘干后再流延 | TPU 底涂内加 CPO 分散体 | 2K 交联后再流延 |
| 软 PVC | 铝/钢 | 金属超薄底涂 + NBR 或 2K PU 主胶 15～30 μm | 湿固化 PUR | 热塑丙烯酸、SIS/SBS、PE 型 CPO 主胶 |
| 软 PVC + 水煮从金属揭，硬质过，聚酯封闭胶，**PMT 232℃** | 铝/钢卷材 | **贴辊降温 L1 + H2/B1**；胶已交联 | — | 150℃ 补交联；先换腈胶；软膜进烘道 |
| 软 PVC | 软 PVC | NBR 或 2K PU；两侧都有油则先隔离 | 聚合型增塑剂同质热贴 | 擦油当永久工艺 |
| PET/漆膜 | 金属 | 2K PU 或聚酯胶 + 金属底涂 | 环氧只在金属侧 | 把 PET 当 PE |
| PP | 金属 | PP 型酸改性 CPO + 金属官能 | 分配方 | PE 型 CPO 硬套 |
| TPE（含酰胺） | 任何粘结层 | 共挤贴合层零酰胺 15～25 μm + 接枝 5%～15% | 后道涂爽滑 | 加厚粘结层吃酰胺 |
| 软 PVC（含增塑剂） | 任何胶层 | 贴合皮层聚合型/低 phr 25～40 μm，或交联隔离 3～8 μm | 整膜换聚合型 | 加厚胶吃油 |

「同一配方服务两种基材」时：把两行「要的化学」写进**同一层超薄底涂**，再用面涂/主胶锁极性点。写不进同一层，就改目标为分配方，不要假装一套胶两头都最优。

## 3. 迁出物：储量、指纹、对策

| 迁出物 | 典型量 | 铺满界面 | 当时 | 24～72 h / 热老化 | 精确 | 假克服 |
|--------|--------|----------|------|-------------------|------|--------|
| 芥酸酰胺 | 0.1% | 1～3 mg/m² | 常还能粘 | **再掉**，面滑 | 贴合层 0 / ≤50 ppm | 加厚、酚醛、换油酸酰胺 |
| 油酸酰胺 | 0.1% | 同上 | **更差** | 掉得更早 | 同上 | 同量对换 |
| DOP/DBP/DOA | 20～50 phr | 10～50 mg/m² | 弱边界 | 胶泡软，C 也出现 | 分层 + 交联胶 | 擦完预热、只换 DOTP |
| DINP/DOTP/DINCH | 20～50 phr | 同上 | 略好于 DOP | 仍迁 | 仍要分层或隔离 | 宣布已环保即已粘牢 |
| TOTM / 聚合型聚酯 | 同等 phr | 慢 | 较好 | 慢滴 | 贴合级优先 | 当成零迁移 |
| 白油 / 石蜡油（充油 TPE） | 高 | 易铺满 | 看贴压 | 后期掉 | 贴合层少油 | 只加 MAH |
| 硅油 | 痕量 | 单分子 | 整层揭 | 不变或更差 | 洗或换膜 | 电晕当第一刀 |
| 蜡、喷霜 | 不定 | 薄层 | 滑、粉 | 再析出 | 改到空气面 | 打磨常规化 |

热：只热稳定侧。擦完再预热迁出物侧 = 白擦。

## 4. 厚度与角色（抄进工艺卡）

| 角色 | 干膜 | 固含经验 | 失败若涂厚 |
|------|------|----------|------------|
| 分子桥（CPO/EAA） | 0.5～1.5 μm | 施工 5%～8% | 底涂内聚裂 |
| 金属底涂 | 1～2 μm | 8% | 同上；闪锈不是涂厚能补 |
| 交联隔离 | 3～8 μm | 按固含算湿膜 | 热塑隔离会被增塑剂溶解 |
| 复合主胶 | 15～30 μm | 按胶种 | >50 μm 去吃油 → 先泡软 |
| 待流延粘结层 | 0.5～1.5 μm | 稀 | 厚或交联 → TPE 面光 |

## 5. 工艺默认值（改了要在检查单写理由）

| 项 | 默认 |
|----|------|
| 清洁 | 高分子：IPA×2，晾 ≥5 min。金属：碱脱脂 + 水洗 + IPA，2 h 内涂 |
| 烘烤 | 80±2℃ × 20 min，贴板，5 min 膜温 ≥75℃ |
| 2K | NCO/OH = 1.05～1.15（抗增塑剂可到 1.20）；24 h 后才算交联 |
| CPO:EAA | 70:30（PE 或双基材底涂） |
| 磷酸酯 | 对底涂固体 0.8%～1.5%，上限 2%；只保聚烯烃时不加 |
| 涂层内酚醛 | 烷基/萜烯，固体 5%～10%，先 C0 |
| 贴合 | 0.3～0.6 MPa；实验室热压 15 s 量级 |
| 流延 | 熔体 160～230℃，记辊温/气隙/贴压 |
| 养护 | 冷 ≥30 min → 23℃/50%RH 24 h |
| 胶带 | 3M 610，同批号；贴 5 min，约 180° 揭 |
| 剥离 | 15 或 25 mm；100 或 300 mm/min；全项目一档 |
