## BL 3175 SN（科思创 TDS）

| 项 | 值 | 算法里怎么用 |
|----|-----|--------------|
| 供应 | 约 **75±2%** 于溶剂油 SN 100 | 固含只用于核对桶，**不算两次当量** |
| 封闭 NCO（供应基准，典型值） | 约 **11.1%** | 与下一行是同一件事 |
| 当量（供应基准，典型值） | 约 **380** g / eq | `n_NCO = W_供应 / 380` |
| 游离 NCO | ≤0.2% | 室温不当 2K 用 |
| 卷材解封（科思创原文量级） | 不加催化剂约 **PMT 241℃** 才充分；固体树脂上加 **1% DBTL** 约 **224℃** | 本厂已锁 **232℃** 且硬质水煮过 → **不改炉温、不补烘**。只在鉴定表写清本厂有没有锡催化剂 |

换算核对：`4200 / 11.1 ≈ 378`，与 380 一致。  
**不要**再用 `380 / 0.75`。那是把供应当量又除了一次固含。

## TS3102（本厂说替代 3175）

公开检索不到可靠 TDS。**禁止把 3175 的 380 / 11.1% 抄到 TS3102 上。**  
「替代」只表示同一类封闭脂肪族 NCO，**不是 1 kg 换 1 kg**。

称量前从本厂桶或 TDS 抄齐：

| 项 | 本厂必须写出 |
|----|----------------|
| 供应固含 % | |
| 封闭 NCO%（写清：供应基准还是固体基准） | |
| 或供应当量 EW | `EW = 4200 / 封闭NCO%`（% 用 11 表示 11%） |
| 解封 / 建议 PMT | 仅作对照。本厂仍锁 **232℃**，硬质已过则不改炉 |

规则：

1. **一炉、一组对照只用一支 NCO。** G0 用 3175，G1 仍用 3175；G0 用 TS3102，G1 仍用 TS3102。  
2. 换 NCO 牌号 = 新变量，不是 G1。要另开对照，且硬质必须同胶同炉仍过。  
3. 同一锅里 **3175 与 TS3102 不得混加**。  
4. TS3102 当量未抄 → 可以做 L0/L1（现用哪桶用哪桶），**不准配 G1**。

## 对 G1 的含义

交联点几乎全在 **710 的 OH** 和 **封闭 NCO**。240 / 822 羟值太低，替来替去几乎不增加交联。

G1：用 710 **替掉低羟值固体的 30%**，再按三种聚酯总羟值，用 **本炉这一支 NCO 的当量** 重算到 NCO/OH 1.10～1.20。  
只加 710、NCO 桶不动 → 禁止。
