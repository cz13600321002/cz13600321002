## BL 3175 SN（科思创 TDS）

| 项 | 值 | 算法里怎么用 |
|----|-----|--------------|
| 供应 | 约 **75±2%** 于溶剂油 SN 100 | 固含只用于核对桶，**不算两次当量** |
| 封闭 NCO（供应基准，典型值） | 约 **11.1%** | 与下一行是同一件事 |
| 当量（供应基准，典型值） | 约 **380** g / eq | `n_NCO = W_供应 / 380` |
| 游离 NCO | ≤0.2% | 室温不当 2K 用 |
| 卷材解封（科思创原文量级） | 不加催化剂约 **PMT 241℃** 才充分；固体树脂上加 **1% DBTL** 约 **224℃** | 本厂已锁 **232℃** 且硬质水煮过 → **不改炉温、不补烘**。只在鉴定表写清本厂有没有锡催化剂 |

换算核对：`4200 / 11.1 ≈ 378`，与 380 一致。  
**不要**再用 `380 / 0.75`。那是把供应当量又除了一次固含。

## TS3102 = 惠佑 HY-1070（本厂 TDS）

文件：`资料/行业资料/HY-1070_封闭型异氰酸酯固化剂_TS3102.pdf`  
厂家：广东惠佑化工。本厂内部名 **TS3102**。

| 项 | TDS | 算法里怎么用 |
|----|-----|--------------|
| 化学 | 封闭型多异氰酸酯，**IPDI 五聚体**（不是 3175 的 HDI） | 换牌号 = 换骨架，不是 G1 |
| 固成份 | **70±2%** | 只核对桶，不算两次当量 |
| NCO（理论） | **10.3%** | 按 **供应基准** 用。若惠佑书面是固体基准，停，改 EW |
| 供应当量 | `4200 / 10.3 ≈` **408** | `n_NCO = W_供应 / 408` |
| 粘度 | 2000～4000 cps / 25℃ | — |
| 解封温度 | TDS 写 **100℃** | 本厂仍锁 **PMT 232℃**，硬质已过则不改炉、不补烘、软膜不进炉 |
| 宣传 | 写了耐水煮、耐黄变 | **不是本项目验收**。软质水煮仍以本厂同锅数据为准 |

同 NCO 摩尔时，供应克数比：`408 / 380 ≈ 1.07`。TS3102 要比 3175 **大约多称 7%**，不是 1 kg 换 1 kg。

规则：

1. **一炉只用一支。** G0 用 3175，G1 仍用 3175；G0 用 TS3102/HY-1070，G1 仍用这一支。  
2. 换 NCO 牌号（HDI ↔ IPDI）= 新变量，另开对照，硬质必须同胶同炉仍过。  
3. **3175 与 HY-1070 不得混加。**  
4. 10.3% 若被本厂改判为固体基准：EW = 4200 / (10.3 × 0.70) ≈ 582，必须改表再称。默认按供应 10.3%、EW 408。

## 对 G1 的含义

交联点几乎全在 **710 的 OH** 和 **封闭 NCO**。240 / 822 羟值太低，替来替去几乎不增加交联。

G1：用 710 **替掉低羟值固体的 30%**，再按三种聚酯总羟值，用 **本炉这一支 NCO 的当量** 重算到 NCO/OH 1.10～1.20。  
只加 710、NCO 桶不动 → 禁止。
