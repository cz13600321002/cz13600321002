# PE 附着力测试引用标准清单

**用途：** 支撑 `文档/方案/20260902_PE基材未电晕附着力测试方案.md`  
**日期：** 2026-09-02  
**说明：** 本清单只列方法名称与在本项目中的用法，实施以现行有效标准文本为准。

---

## 1. 附着力（涂层 / 油墨）

| 标准号 | 名称 | 本项目用法 |
|--------|------|------------|
| GB/T 9286-2021 | 色漆和清漆 划格试验（等同 ISO 2409:2020） | 硬质片材主方法；薄膜辅测。0～5 级，合格 ≤1 级 |
| ISO 2409:2020 | Paints and varnishes — Cross-cut test | 与 GB/T 9286 对照 |
| ASTM D3359 | Standard Test Methods for Rating Adhesion by Tape Test | 与客户或出口报告对照时使用 Method B |
| GB/T 13217.7-2023 | 油墨附着力检验方法 | **PE 薄膜主方法**（手工剥离 / 圆盘剥离 / 划格） |
| ISO 4624 | 拉开法附着力 | 仅当涂层足够厚、需定量力值时选用，本窗口默认不做 |

## 2. 表面能 / 是否电晕

| 标准号 | 名称 | 本项目用法 |
|--------|------|------------|
| GB/T 14216 | 塑料 膜和片 润湿张力试验方法 | 达因液判定未电晕（接收 ≤34 dyn/cm） |
| ASTM D2578 | Wetting Tension of Polyethylene and Polypropylene Films | 与达因笔方法对照 |
| GB/T 30693 | 塑料薄膜与水接触角的测量 | 水接触角 ≥90° 作为未电晕辅证 |

## 3. 环境与取样

| 标准号 | 名称 | 本项目用法 |
|--------|------|------------|
| GB/T 9278 | 涂料试样状态调节和试验的温湿度 | 养护与测试环境 23℃ / 50%RH 的依据 |
| ISO 3270 | Temperatures and humidities for conditioning and testing | 同上 |
| GB/T 13452.2 / ISO 2808 | 漆膜厚度测定 | 有测厚条件时记录干膜 |

## 4. 胶带与印刷相关（选用）

| 标准号 | 名称 | 本项目用法 |
|--------|------|------------|
| GB/T 7707 | 凹版装潢印刷品 | 胶带种类可参考其附录（若与油墨客户对齐） |
| GB/T 2792 | 压敏胶粘带 180° 剥离强度 | 评价胶带本身，不替代涂层附着牢度 |

## 5. 实验室执行约定（非国标，但必须锁死）

| 约定 | 内容 |
|------|------|
| 胶带 | 默认 3M 610，全项目同一批号 |
| 烘烤 | 80±2℃，关门计时 20 min，试样贴玻璃板 |
| 膜温 | 入炉 5 min 内膜面 ≥75℃ |
| 验收时点 | 23℃/50%RH 养护 24 h；关键样 72 h 复测 |

## 6. 使用注意

1. GB/T 9286 明确：划格是抗脱离的经验方法，**不是附着力绝对值**。本项目同时给出失效模式，避免只报一个等级。
2. GB/T 13217.7-2023 已代替 2009 版液体油墨胶带法，薄膜类优先用 2023 版。
3. 购标准文本走正式渠道；本仓库不存放标准全文。
