# 工作方案与 Agent 编写规范

**生效日期：** 2026-08-24  
**适用范围：** 本工作文库全部新建方案、Agent 规格、研发技术问答  
**文档版本：** V1.0  

---

## 1. 强制格式

从本日起，新建文档必须套用对应模板，章节顺序与标题保持一致。

| 类型 | 模板 | 成品目录 |
|---|---|---|
| 工作方案 | `模板/工作方案/工作方案模板.md` | `文档/方案/` |
| Agent 任务规格 | `模板/工作方案/Agent任务规格模板.md` | `文档/方案/` |
| 标准回答 | `模板/工作方案/标准回答模板.md` | 对话或方案附件 |
| G1 矩阵 | `模板/实验记录/G1指标矩阵模板.md` | 方案附件 |
| 实验卡片 | `模板/实验记录/实验卡片模板.md` | 只起草 |

命名：`YYYYMMDD_文件名称.扩展名`。

范例（第一份按此格式写成的正式方案）：

`文档/方案/20260824_研发技术资料Agent任务规格.md`

## 2. 十三章不得删

一、背景与目的  
二、工作目标  
三、工作范围与内容（第一用户、覆盖范围、做/不做）  
四、任务规格（职责、完成标准、术语、资料分层、方法、输出模板、红线）  
五、资料/依据清单  
六、高频任务  
七、验收评测  
八、实施方案（阶段用交付物，不用日历工期）  
九、人员安排  
十、资源需求  
十一、风险分析与应对  
十二、预期成果  
十三、变更记录  

某章不适用：写「不适用」和原因，禁止直接删章。

## 3. 研发资料状态

引用任何 TDS / SDS / 档案前，先查：

`资料/规范标准/20260824_受控技术资料清单.md`

| 状态 | 含义 | 用法 |
|---|---|---|
| 现行 | 当前可引用 | 可作对内规格来源 |
| 冲突 | 同牌号多版本不一致 | 列出差异，停止下结论 |
| 作废 | 旧日期勿发、旧溶剂勿发 | 只追溯 |
| 对标 | 竞品或原料厂家 TDS | 可比较，不作自有承诺 |
| 历史 | 项目档案、旧 TDS | 标明年份，非定型 |

## 4. 评测

涉及研发 Agent 的改动，必须重跑：

`资料/规范标准/20260824_研发Agent黄金评测题.md`

通过：20 题中正确引用或正确拒答 ≥ 18；编造 CAS / 闪点 / 强度则整批不通过。
